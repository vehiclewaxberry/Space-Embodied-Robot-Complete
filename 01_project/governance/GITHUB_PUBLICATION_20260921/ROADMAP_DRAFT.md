# 航天服务星具身智能机械臂机器人：硬件路线图

**Space Service Robot with Embodied Intelligence** 将沿“数字设计闭合 → 地面装配 → 受控上电与联调 → 环境适应性”的顺序迭代。近期验收对象是可装配、可上电的地面工程样机；当前起点为R6H数字装配、R5E候选选型、R2/R3线束与主机接口、未安装的R7板卡布局，以及尚待验证的热控与推进方案。

下表中的验收要求是下一阶段拟采用的标准，不是当前PASS。测试电压、电流、温度、持续时间、故障响应和裕度等数值，需在相应器件/工况冻结后写入同版试验计划，执行前确认，不能在看到结果后再选择门槛。

| 顺序 | 工作包与现有缺口 | 应交付内容 | 地面阶段验收要求 |
|---|---|---|---|
| 0 | 冻结首版地面样机构型 | 版本化的装配、原理图/PCB、实体BOM、线束表和负载/试验工况；每项标为实物、替身、预留或未纳入 | 每个上电支路和安装实体有唯一责任来源；所有影响本轮装配/上电的UNKNOWN已解决或通过明确断开/替身方案移出本轮工况。飞行相关UNKNOWN仍保留在账 |
| 1 | 完成核心机械布置（M01–M03） | 在R6H基础上完成AUX/STOP水平布局、支架、孔位、紧固和装配顺序；处理小间隙、净余肉及支承输入 | 新增/变更实体与BOM一一对应；检查声明姿态中的非预期重叠、接触面和工具空间；完成连续装入/拆卸验证。R07第六边A/B若承担本轮载荷，必须绑定接触刚度/预紧输入并校核，不能沿用未确认参数 |
| 2 | 落实电路与PCB候选（E01） | 将R5E候选逐项转成受控功能ECO；处理R305、有效电容、阈值、载流与保护协调；更新PCB和实体采购BOM | 逐位号核对原理图、PCB、器件封装与采购表；虚拟接口/孔位单列。ERC/DRC及专业检查无未处置错误；替代件、偏压后电容和相关温度/电流条件有明确依据。候选属性不能代替实际变更 |
| 3 | 完成制造线束与主机接口（E02–E03） | 真实两端连接器/针脚/端子、线材与屏蔽、切长公差、应力释放、装配检验表；冻结B601逐关节硬件版本与主机接口电路范围 | 逐网导通、极性、绝缘与屏蔽端接按预定标准验收；装配后连接可达且无夹线/拉脱风险。主机、停止接口和驱动之间的电压/通信/故障语义一致；不将R3逻辑针脚直接当作OEM针号 |

| 6 | 完成材料、质量与工艺账（M04、M02） | 每个地面实体的材料/MPN或受控图纸、工艺、公差、实际质量来源；装配质量/质心账；必要的结构校核 | 软件默认质量不进入实测账；PCBA、线束与复合部件按真实质量来源处理。总质量与分项账闭合到预先声明的不确定性；地面支承、紧固和搬运工况有依据。数字材料库赋值不能替代实物材质或工艺检验 |
| 7 | 推进接口与真实硬件分阶段闭合（PR01–PR02） | 跟踪现有9项OEM缺口和12项工作单；冻结候选型号、尺寸/质量、孔位、电气/流体/热接口；更新储箱/管路/喷口及羽流空间设计 | 首版地面样机建议先验收无加压、无点火的接口/质量替身及电气边界，并明确其非真实推进性能。真实推进总成须在OEM资料与专项试验计划齐备后单独验收；布局占位、推力窗口筛查和功能电缆不构成推进系统完成 |
| 8 | 整机地面装配与受控联调 | 实物装配记录、偏差闭环、通断/保护/热试验、B601主机通信与停止验证、试验后复查 | 在冻结的地面范围内，完成可重复的装入、上电、规定负载运行、停止、断电与检查流程；全部结果绑定同一版CAD/ECAD/BOM/线束和实际硬件修订。未完成项、替身和不适用项均在验收记录中显式列明 |

机械、器件与线束设计可以并行推进，但首次上电必须使用已闭合的接口和保护边界。分支试验先于整机带载，单板通过不能自动升级为整机通过；热和功耗模型也必须跟随实际电路/装配修订。

地面样机首轮验收的范围建议明确为：本体与机械臂的可装配结构、MAIN/AUX/STOP及主机接口、真实制造线束、受控电源与停止路径、地面散热，以及清楚标识的推进接口替身。太阳翼补能、轨道任务持续时间和真实推进性能不以台架电源或替身验收代替，继续作为独立未完成项管理。

地面验收通过后，再开展任务环境适应性：材料放气、真空热与热循环、振动/结构、电子辐射及其他适用项目。具体载荷与验收等级由任务和产品要求确定。热辐射设计通过不等于电子抗辐射通过，地面B601驱动联调通过也不等于具备在轨资格。

路线图的进度以已完成的设计更改和可追溯验收记录更新，不以文件数量、模型外观或仓库名称判断完成度。工作范围内未安排新的控制研究、动力学研究或学习算法实现。参照 [当前设计状态](DESIGN_STATUS.md) 和 [现有未完成项](00_release/OPEN_ITEMS.md) 逐项推进。
