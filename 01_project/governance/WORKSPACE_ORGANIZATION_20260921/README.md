## 体积和保留原因

清理前可读快照为 **118,807 个文件、49,706,814,226 B（49.71 GB）**，其中根 `.git` 为 **13.87 GB**，根 Git 以外为 **35.83 GB**。数字来自[清理前盘点](INVENTORY_SUMMARY.json)，不含本整理目录自身的新增文件，也不包含无法读取的内容。

仍有 **10 个深层临时/pytest 目录访问受限**，因此盘点是可读范围的下限。没有改变权限或删除这些目录；异常路径在盘点 JSON 中逐项记录。

以下大对象保留有具体理由：

- 根 Git/LFS 对象和第三方独立版本库承担历史与恢复职责，不做历史重写或对象清理。
- 约 775 MB 的 `full_project_catalog.sqlite` 保存原文、合并映射与恢复记录，不能当作普通可再建索引丢弃。
- R1/R4 和旧工程包中的原生零件仍是 R6H 上游引用；退出当前方案的构建脚本也可能仍被 R6H 导入。
- ZIP、donor、`__cadgen__`、哈希绑定的输入和历史负结果，不能仅凭名称、日期或同哈希移除。
- 活动工具运行环境仍服务现有设计链；19 个有实际引用的缓存项和116个再生成证明不足项本轮保留。

详见[大文件审阅](LARGE_REDUNDANCY_REVIEW.md)与[缓存审阅](CACHE_REVIEW.md)。本轮明确可安全清理的项目已经处理；剩余大体积对象若继续压缩，应先逐包迁移消费者与恢复合同，再另立精确清单。
