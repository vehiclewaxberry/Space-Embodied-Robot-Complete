## 1. 五类文献版图

- **A 捕获控制（密集）**：凸规划软捕获（2019 制导、2024 凸化、2026 Transformer
  热启动）、RL/脉冲神经网络操作、实验室实验（2017/2022）。方法饱和，纯控制无空位。
- **B 捕获后消旋（密集，2020–2026 连续产出）**：柔性附件大挠度消旋建模（2023）、
  非刚性目标自适应消旋（2024）、惯量不确定 RL 消旋（2026, Acta 在刊）。
  共同点：**默认任务可行，研究怎么做**；无人研究执行器容量何时使任务根本不可行。
- **C 同时捕获-消旋（已确立的小生境）**：Virgili-Llop & Romano 2019（奠基，
  轨迹优化+HIL）、双臂 2021/2022、Seamless 2024、双 agent 协同 2026。
  全部是"给定任务设计轨迹/控制器"。
- **D 柔性捕获（活跃）**：刚柔耦合建模与轨迹优化（2024）、振动抑制（2018/2025
  双观测器）、ANCF 综述（2023）。全部关注**如何控制柔性系统**；
  无人研究**捕获瞬态中柔性模型保真度如何选择/何时失效**。
- **E 任务级决策（综述级 + LLM agent 爆发）**：权威综述 2021/2025；
  SpaceMind（2025 MCP 架构版 + 2026 自进化版）、KSP LLM 操控（2024/2025）、
  SAGE 语言条件安全轨迹（2025）、GUIDE（2026）。共同缺陷：**决策不接地在
  经过验证的动力学证据链上**（无 gate/裁决可追溯性）。

## 2. 两项存在性检查（корpus 内结论）

1. **"capture-detumble feasibility boundary"——корpus 内未见。** 最近邻
   Virgili-Llop 2019 回答"给定任务如何设计成功轨迹"；MPC 动量反配平 2025
   回答"如何实现零冲量接触"。**无人把捕获-消旋当作 (μ, ω̂, 执行器容量) 参数
   空间上的存在性问题并绘制不可行边界**——sim_10 的四区域图（F1）在该口径下
   是新的。风险提示：feasibility map 在轨道交会/燃耗领域有同名概念，写作时须
   明确"post-capture stabilizability feasibility"限定。
2. **"strategy selection under momentum constraints"——部分覆盖。** 2020
   "Coordination of thrusters, reaction wheels, and arm in orbital robots"
   做执行器协同分配（最近邻）；MPC 2025 做动量反配平控制。但**冻结执行器预算下
   跨策略类（被动/速度匹配/动量预置/捕获后消旋）的可行域对比与选择判据**未见
   ——这是 sim_12 的空位，且必须回答"轮组仅 8% 容量的预置换多少边界改善"这类
   定量问题才与 2020/2025 拉开差距。

## 4. 三个交付的定位（对照最近邻逐一差异化）

- **Paper 1**（主线，Acta Astronautica）：*考虑柔性附件耦合的非合作航天器捕获
  任务可行域*。差异化：vs Virgili-Llop 2019（存在性映射 vs 单任务轨迹设计）、
  vs MPC 2025（预算约束可行域 vs 控制器设计）、vs 消旋文献 B 类（何时不可行 vs
  怎么消旋）、vs 柔性文献 D 类（边界对柔性的敏感性 + 保真度判据 vs 振动控制）。
  证据链已齐：sim_10 F1-F4 + sim_09 操纵度退化 + sim_11 带宽收敛 + 退化链 Gate。
- **Paper 2**（方法学，Multibody Syst. Dyn. / JSV 口径）：*捕获瞬态的接触带宽与
  模型保真度选择*（理想冲量不适定性 + 带宽判据 + FFR/ANCF 域边界 + e15 式认证）。
- **比赛 demo**：Physics-grounded mission agent——差异化 vs SpaceMind：
  **每个 EXECUTE/ABORT 决策引用一个冻结机器裁决 JSON 字段**（可追溯、可复现），
  而非 VLM 置信度；SpaceMind 解决"agent 如何组织任务"，我们解决"agent 如何知道
  任务在物理上值不值得执行"。

## 5. 最大撞车风险 Top3 与规避

1. **Virgili-Llop & Romano 2019**（C 类奠基）：引言必引、方法节明确"我们不设计
   轨迹，我们回答轨迹是否存在"；把他们的 HIL 结果用作我们边界图上的一个已验证点。
2. **MPC momentum counter-balanced & zero-impulse contact 2025**（arXiv
   2512.09213）：与 sim_12 动量预置直接相邻——规避=我们做容量约束下的策略类
   对比与可行域漂移（含 8% 轮组预置的定量上限），不做控制律；引用其作为 S3
   策略类的实现存在性证据。
3. **SpaceMind 2025/2026**：demo 叙事撞车——规避=把"机器裁决背书的决策"作为
   核心主张并在 demo 中现场展示 gate JSON 溯源；不与其比 agent 架构。
