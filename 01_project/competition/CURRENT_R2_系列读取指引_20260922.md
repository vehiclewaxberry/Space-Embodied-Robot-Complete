# CURRENT_R2_* 系列读取指引

**建立：2026-09-22。本文件只做读取导航，不修改任何原文件、不改写任何裁决、不升级任何科学或工程结论。**

## 为什么需要这份指引

`01_project/competition/` 下有三组以 `CURRENT_` 开头的多版本文件。文件名宣称自己是「当前」，但每组都同时存在 7 份，且**同组内 `as_of_date` 完全相同**（均为 2026-08-28）。仅凭文件名、日期或版本号**无法判断该读哪一份**。

更关键的是：下面第 1 组经逐键比对，证实**版本号最高的那份并不是内容的超集**。

## 第 1 组：AUTHORITY_DELTA（V2–V8，7 份）

### ⚠️ 核心发现：V8 不是完整替代品

| V4 → V5 | 0 | 0 | 累积 |
| V5 → V6 | 0 | 0 | 累积 |
| V6 → V7 | 1 | 0 | 累积 |

**V3 独有、V4–V8 全部没有的两个键：**

1. `authority_additions_and_navigation_corrections`
2. `unresolved_owner_and_system_bindings`

`unresolved_owner_and_system_bindings` 记录着 **5 项未决绑定，全部为 `false`**：


这五项在 V4 之后的任何版本中都不再出现。**任何只读 V8 的人会完全看不到它们。**

`authority_additions_and_navigation_corrections` 则记录了 D04 B601 夹爪局部几何候选的来源路径、字节数与 SHA-256，`classification` 为 `PENDING_OWNER_REVIEW`。

### 读取建议

- **要最新增量** → 读 `CURRENT_R2_AUTHORITY_DELTA_V8.json`
- **要完整未决项清单** → **必须同时读 `V3`**
- 全部 7 份的 `review_status` 均为 `PENDING_OWNER_REVIEW`，`as_of_date` 均为 2026-08-28
