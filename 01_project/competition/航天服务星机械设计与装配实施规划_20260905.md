# 航天服务星与 B601 机械臂：机械设计、装配和具身任务实施规划

日期：2026-09-05。规划依据：用户要求以完成产品为目标重新规划，不以历史 Gate、比赛期限或旧流程限制作为新计划的前置条件。本文件是本轮新规划，不修改历史资产或结果。

**下一阶段的目标：形成同一配置的参数化整星总装、可加工装配的工程文件、完成联调的实体工程样机，以及与实装配置一致的机器人数字模型。**

## 1. 总体取舍与完成定义

建议首版沿用 B601 六轴执行机构，允许重新设计母线结构、臂根安装、支承/保持释放机构、末端接口、翼根及线束布置。将 12U 级作为总体尺度目标；严格标准部署器适配与任务优先的 12U 衍生构型应在第一个工作包中明确选择。以下路线推荐任务优先的完整服务星工程样机作为首轮实现目标，不将任何未经计算的放大尺寸预先定为最终值。

一个关键规则是：**总体包络由完整机器人、保持释放机构、太阳翼及内部设备共同确定。** 先比较少量完整布局方案，以工作能力、可装配性、收拢/展开可靠性、质量和制造复杂度选择一个，随后进入详细设计。若必须适配指定部署器，则用它的具体接口要求作为方案筛选输入；不能把外包络问题一直留到出图以后。

“完成”分成三个可直接检查的产品状态：

| 产品状态 | 必须交付 |
|---|---|
| 数字机械样机完成 | 唯一主原生总装；真实关键实体与接口；收拢/释放/展开/工作状态；运动与线束检查；逐件质量；可编辑参数；装配图、BOM 与制造图 |
| 实体工程样机完成 | 加工采购件可装；保持/释放/展开能运行；驱动与传感器接通；尺寸、质量、摩擦/间隙等实测；整机任务演示与故障停机验证 |
| 飞行产品完成 | 在前两项基础上，完成特定任务的发射接口、材料与机构环境适应性、环境试验和可靠性工作；试验等级来自实际任务 |

首轮按前两项组织实施，并在设计时保留飞行产品所需的接口、材料、热与环境设计考虑。CAD 检查和实体测试各自回答不同问题：是否符合设计要求，以及是否能在预期使用条件下完成任务。[NASA 产品实现](https://www.nasa.gov/reference/5-0-product-realization/)

## 2. 首个工作包：总体骨架与机器人安装联合设计

这是立即应开始的设计工作。输出必须是一套可查看、可调整、可比较的整机装配模型。

**先写一页设计输入表。** 至少明确任务对象及抓持界面、目标惯量/相对运动范围、末端工具、臂工作区域、母线包络方案、供电与驱动设备、相机/F/T 安装、制造手段及首版实体试验形式。区分已测、厂商数据和用于设计扫掠的假设值。未知输入采用明示区间，不靠补一个数宣称完成。

然后建立参数化骨架，统一 S 星体系、臂根、各关节、末端 TCP、相机、力传感器、翼根和分离界面坐标。主参数至少包括母线长宽高、框梁位置、臂根平移/转角、完整关节姿态、支承站位、翼根站位、设备安装面及维护通道。

用同一完整臂、末端、保持装置及设备集合，比较 2–3 个布局，例如前端根部/沿侧收拢、侧置根部/沿纵向收拢、为工作区调整母线截面的方案。方案比较至少包含完整收拢尺寸、连续设备舱、承力拓扑、初始释放路径、太阳翼避让、活动线束空间和加工装配难度。选定一个主方案后停止扩展并行构型，详细零件围绕该方案推进。

首包交付六件内容：

1. 设计输入表与布局选择记录。
2. 一套可驱动的总体骨架和完整低细节总装。
3. 收拢、解除保持、初始展开、完全展开、工作姿态五种状态。
4. 臂根与收拢保持点的载荷路径图。
5. 线束活动区、翼扫掠区、设备/工具/维护保留空间。
6. 后续需设计的零件清单、接口尺寸表和初步质量预算。

这里允许设备用明确的采购包络表示；决定碰撞、安装或承载的几何应有足够细节，不用坐标轴代替连杆，也不以总包络块代替实际可用内舱。

## 3. 设计和装配的主工作包

| 顺序 | 工作包与责任 | 具体工作 | 完成条件 |
|---|---|---|---|
| WP01 | 总体/主CAD | 完整布局、坐标、安装、状态、参数骨架 | 所有主要部件有位置；选定一套布局；安装变换固定；收拢及初始释放有可检查模型 |
| WP02 | 主结构/臂安装 | 框梁、端框、承载桥、M3R、定位与紧固、工具通道 | 从臂根到主结构的真实连接可追踪；安装孔/定位/紧固可装；初步载荷下刚度与强度有依据 |
| WP03 | 收拢与释放机构 | 承载支承、接触垫、保持装置、驱动/弹簧、释放确认、地面复位 | 保持载荷分流明确；机构脱开后不阻挡首段运动；释放反馈和复位操作可实现 |
| WP04 | 臂/末端/线束/感知 | 夹爪与工具接口、传感器/相机、连接器、线束固定与活动段、驱动安装 | 末端可安装标定；全范围线束无过拉/夹挤/扭转累积超限；驱动与传感器具有布线和散热空间 |
| WP05 | 翼与内部设备 | 翼根/铰链/锁扣、展开线束、设备板、轮组/电源/计算机/推进等安装 | 展开顺序明确；臂翼互不侵入；设备能装能拆；必要散热与视场/喷流避让成立 |
| WP06 | 整机验证与设计收敛 | 完整运动检查、关键载荷/结构/柔性分析、公差、质量/CG/I、故障工况 | 每个要求有结果；不满足项落实到具体零件修改，修改后重查受影响部分 |
| WP07 | 制造与分总成装配 | 材料工艺、二维图、公差、标准件、采购BOM、检验、工装、分总成首装 | 加工图可供制造；关键分总成试装可运行；实测差异已回写设计 |
| WP08 | 整星装配与具身任务联调 | 按装配顺序整合、标定、模型更新、观测到动作闭环 | 同一实装配置完成代表任务；模型、驱动、标定和机械版本一致 |

WP02、WP03、WP04 必须密切联合。WP05 在 WP01 接口明确后可并行；WP06 从 WP01 起穿插进行，在详细设计收敛后完成整机复核。不能把强度、线束或装配工具可达性全部推迟到 WP06。NASA 的产品集成方法将装配策略、接口检查和子系统相互作用一起规划，这也是此工作包安排的依据。[NASA 产品集成](https://www.nasa.gov/reference/5-2-product-integration/)

## 4. 三项必须先解决的设计耦合

**承载、支撑和释放。** 收拢状态的载荷由保持点/支承/HDRM 传入所连接主结构，并到分离界面；展开状态的操作反力通过臂根、转接与承载桥进入母线。应明确两种状态的分流关系、刚度、公差和接触预紧，不能假设都经同一串联路径，也不能默认关节减速器独自承担保持载荷。是否需要一个或多个主动释放点由载荷、运动和故障分析决定。

**运动、线束和其他展开件。** 线束的真实外径、最小弯曲半径、扭转能力、余长、固定点、插拔方向和应力释放应与每个关节一起设计。首个解除保持动作、臂与太阳翼谁先展开、失电后的机构状态，都需要通过完整序列选择；不能由零件看起来分离就认定路径安全。

**布局、质量和动态性能。** 每个实际安装组件独立计质量，设备替换预算块时避免重复。目标质量本身不是在轨关节重力负载；接触反力和关节需求应由目标惯量、相对运动、接触过程、臂动作及停机策略推导。结构刚度、姿态资源、功率、传感器视场及计算设备布局共同影响任务能力。

航天机构材料、润滑、表面处理与环境适应性需要在设计中考虑，不能等结构定型后再整体替换。[NASA 小航天器结构、材料与机构](https://www.nasa.gov/smallsat-institute/sst-soa/structures-materials-and-mechanisms/)

## 5. 参数化与模型交付规则

选择一个能够稳定编辑、重建、装配和出图的原生 CAD 作为主设计源。允许其他内核用于检查或转换，但各软件不分别维护一套不同的机械结构。

每个关键零件具有零件号、修订、材料/工艺、主要参数、接口、所属总装和质量来源。紧固与定位特征要能追溯到装配接口。至少检验几组设计参数扰动后，模型能够重建、接口随动且没有意外自由度或悬空引用。正常装配接触和机构配合需明确定义，不能一律当干涉，也不能将所有小穿透当正常。

由这套主装配派生可视几何、碰撞几何、机器人拓扑、质量惯量和坐标参数。不同用途可以有不同精度，但都要能对应到同一物理部件与姿态；简化模型要保留所需包络与接触特征，并说明误差。

## 6. 实体装配与最小验证任务

建议先做机械臂/末端、保持释放、太阳翼、内部设备四类分总成，再进行整星首装。总体顺序初案为：主结构与臂根接口 → 内部设备和主线束 → 机械臂及末端传感器 → 保持机构与翼根/翼 → 外覆盖件。具体顺序由安装路径和工具空间调整；每次封闭前检查线束、紧固与连接器，并保留拆卸返修路径。

试制优先件是臂根/支承/HDRM 接口样件和线束活动段样件。这些试装可在详细设计后期提前完成，用实际摩擦、间隙、插拔和弯曲行为修正 CAD，再加工整星主结构。不要仅凭外观样机决定承载结构。

最小工况集合必须覆盖：保持、解除保持、初始展开、完全展开、典型抓持、工作区边界、臂翼最近位置、线束最不利姿态、携载运动、释放，以及断电/失联/受阻后的停止和保持。接触允许区、最小净间隙、速度/力/位姿要求和误差裕量在具体试验前写清。

记录实测尺寸、质量、关节零位、间隙/回差、摩擦、夹爪力、机构释放/展开行为、线束反力和驱动限制。地面试验需要与其负载匹配的支撑/卸载工装；它提供部件与系统工程证据，自由漂浮动力学另由相符条件的模型或试验验证。

## 7. 具身智能接口从首轮机械设计开始

TCP、相机、F/T、编码器、限位和释放确认传感器的安装、刚度、视场、线缆与标定操作空间纳入 WP01–WP04。驱动器与计算机的供电、热路径、通信和时间同步同时进入设计。这里要确定的是接口、性能需求与可实现的安装位置，后续算法可以并行迭代。

首个端到端任务按由易到难的序列完成：识别静止目标 → 规划可达接近姿态 → 检查几何与物理约束 → 低速接近和抓持 → 接触反馈/保持 → 释放；随后再扩展运动目标与抓后稳定。第一轮固定基座或卸载条件下的演示，不能被称为已经证明自由漂浮捕获性能。

最终交付的机械版本、BOM、机器人模型、驱动配置与标定文件相互对应。智能策略能够获得当前可达域、碰撞几何、关节限制、末端状态和接触反馈；不能只收到一个视觉漂亮但没有物理接口的网格。

## 8. 首轮实施节奏与人员并行

第一个短周期只完成 WP01 及 WP02–WP04 的联合初案。若使用一周冲刺，其日程可作为工作分解目标，而非保证完成的工期：第 1 天整理设计输入/骨架；第 2–3 天比较完整布局；第 4 天确定根部、支承/释放与线束方案；第 5 天输出主方案总装、关键路径和需试制接口。

之后按三个连续增量推进：关键机械子系统详细设计 → 完整数字样机与图纸 → 分总成和整星首装联调。加工采购周期单独排入，按实选供应件和工艺报价确定，不与 CAD 完成日混同。

可并行的四项责任为：总体与主CAD、承载/机构与制造、线束/航电/感知接口、分析与数字模型。各负责人共享同一接口表和主装配，不独立改变对方安装面。每次集成会议只处理具体装配问题、设计修改与验证结果，确保投入持续转化为可用部件和完整装配。

**下一项具体行动：启动 WP01“完整服务星总体骨架与 B601 安装联合设计包”，在一套主装配中首先打通臂根—保持支承—释放路径—活动线束—设备空间这组耦合。**
