## 3. 本轮形成的控制预开发设计

### 3.1 Unified R2 8DOF 到锁夹爪 6R 的静态适配

在诊断状态中显式设置：

```text
qP    = [0.03575, 0.03575] m
qdotP = [0, 0] m/s
```

六个转动关节与两个移动关节的上下限均从哈希固定的 Unified R2 URDF 解析，当前 8DOF
诊断构型逐关节在限，结果同时发布上下限余量；任何后续配置越界都会 fail-closed。

仅计算质量分块、零动量机械连接和约化质量：

```text
A6     = -Hbb^-1 Hbm,6R
Mred,6 = Hmm,6R - Hmb,6R Hbb^-1 Hbm,6R
```

结果：

```text
min eig(Hbb)       = 4.879428619e-1
min eig(Mred,8)    = 5.467395717e-4
min eig(Mred,6)    = 5.473773446e-4
linear momentum residual  = 1.748e-18 kg·m/s
angular momentum residual = 3.635e-18 N·m·s
```

该探针没有调用 `advance()`。将两个 P 通道广义力置零并不等于锁止，所以力矩级传播仍需
含 2P 约束反力的求解器；当前结果只证明速度级/静态接口可用，不证明任务性能。

### 3.2 末端 DLS / resolved-rate 基线

在冻结 CTRL-01 模型的单状态、非接触诊断上完成 C0/C1/C2/C3 确定性探针。
CTRL-01 的 `REPEAT` 负结果、关节限位/任务冲突和 C3 反作用补偿无效结果全部保留；
REORG04 后当前配置与旧 Gate 的规范化哈希不同，因此不声明旧试验逐位复现。

### 3.3 双翼 14 模态柔性静态筛查

按 `[LEFT 7 modes, RIGHT 7 modes]` 固定顺序，分别使用左右翼的 `Gamma_t/Gamma_r`，
对 LOW/NOMINAL/HIGH 三个参数角点计算：

```text
K eta = f_rom - Gamma_t a_S - Gamma_r alpha_S
```

并逐翼通过五类重构算子检查位移、弯曲斜率、铰链相对转角、扭转角和翼尖挠度。
在本轮自定的非零、未绑定任务轨迹/执行器/捕获载荷的 S 坐标系静态诊断加速度下，
最大限值占用为 0.705582%（LOW/LEFT，弯曲斜率）。越界负测按
`FAIL_CLOSED__NO_LINEAR_ROM_EXTRAPOLATION` 拒绝。

该结果不继承 E23/Round4 PASS，不覆盖展开瞬态、接触、间隙、完整星—臂—目标时域耦合
或飞行鉴定。

### 3.4 动量锚点与执行器输入

C5 只绑定 E23 provisional 诊断场景：22 kg@0.5°/s 与 150 kg@3°/s；明确不等同于、
也不继承 sim_10 的 22 kg@3°/s 刚体任务可行域锚点。

已建立 6R+2P、逐关节 19 项执行器测量 intake。连续/峰值输出、速率、加速度、饱和、
死区、延迟、电流和热参数全部保持 `null + MEASUREMENT_PENDING`，禁止零填充。
URDF 的 50/200/15 速度字面量被明确标为 `unit=UNDECLARED`、模型专用且非硬件有效。

## 5. 唯一合法的下一机械入口

若 Owner 决定继续 Option A，必须明确签发 ODR-60 中的精确 token：

```text
AUTHORIZE_OPTION_A_FIXED_ENDPOINT_M01_TRAJECTORY_SEARCH
```

该 token 只选择有界研究分支，不绕过静态预检、运行时内存准入或任何 fail-closed Gate。
随后必须依次闭合 execution mount、collision frame、三阶段 M01 scene、实际对象/配对宇宙、
motion certificate、clearance policy 和 pair oracle，才可执行一次 bounded M01 path search。
若单次运行前可用物理内存低于 6 GiB，还需要本次运行专用且不可复用的：

```text
ACCEPT_SINGLE_RUN_LOW_MEMORY_RISK
```

只有机械 handoff PASS 后，控制研究才能进入 collision/harness constrained controller、
capture supervisor 和完整闭环；RL/VLA 仍须等待 Dynamics-Control-SAFE 联合 Gate。
