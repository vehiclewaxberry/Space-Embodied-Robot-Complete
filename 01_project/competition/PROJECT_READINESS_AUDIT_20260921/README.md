## 1. 当前目标与合理项目定位

当前工程目标是可装配、可参数化、可验证并支撑论文复现的服务星与B601六自由度机械臂，近期以数字设计和地面工程样机为目标，尚未采购。既有比赛期限不再作为进度门槛。

核心研究问题是：自由漂浮条件下，抓取前的动作与接触选择如何影响抓取后的动量、基座稳定性、柔性振动及轮组/推进资源，如何让具身候选生成受到独立物理可行性判断约束。下一阶段建议以一个明确定义的接近—接触—保持任务为核心，先建立确定性基线、版本一致的数字身体和完整证据，再评价学习方法带来的增量。

建议公开描述：**“面向捕获后可稳定性的自由漂浮空间机械臂研究：数字工程候选、物理模型与保守决策验证。”** 暂不使用“完成的航天服务星”“已实现自主在轨装配”“可直接实装B601”“完整数字孪生”等超出证据的表述。

## 3. 公开说明中必须纠正的四处口径

1. **质量与版本分开。** 旧Unified R2为31.022864807 kg；WP03现行497实例中已分配小计20.705235166 kg、283实例未知；R6H 1153实例没有整星完整质量。三者不是同一配置的相互替代值。部分WP03旧说明仍写20.716839 kg/167未知。
2. **sim12排名已局部重发。** 2026-08-29的GS2 V2替代旧排名适用结论：24格为9 UNKNOWN、15 UNSAFE、0 ROBUST_SAFE。不能无条件继续写“A→S1、C→S3a最优”；也不能由这24格推断全部任务永远不可行。保留原16格历史及新重审原因。
3. **父级HOLD与子包PASS并存。** 后续动力学、柔性、接触与MuJoCo候选确有进展，但尚未汇合为当前整星的新系统裁决。既不能说完全没做，也不能拼接多个PASS成为整星PASS。
4. **R6H/R5E与旧HANDOFF分别判断。** R6H/R5E现行指针匹配，但旧WP10前滚的9项证据仍有working_revision哈希失配；本机sim10四个冻结输入有两项失配。公开复现必须修复版本化绑定，不能跳过校验或改写旧结果来制造一致。

## 6. 推荐公开方式

建议保留当前研究工作区和完整Git历史作为本地来源库，另建**经过筛选的公开研究快照**。不直接把整盘目录ZIP或原`.git`历史推上去。公开快照记录原HEAD `669ce052…`、未提交工程快照的文件哈希和来源映射，保留必要负结果，历史链接不会假装仍是同一提交图。

- **Git源码仓库**：自有程序、参数/合同、BOM与接口摘要、必要小型结果、公开可用文档、来源与失败索引。
- **LFS/Release**：允许再分发的当前CAD/STEP/网格、完整原生引用包、离线查看器和固定版证据附件；包含SHA256和适用范围。按实际套餐与当前限制控制附件大小。
- **来源登记**：论文题录/DOI、第三方仓库URL/commit、OEM链接与获取校验；没有许可时不直接再分发原文或模型。
- **本机留档**：凭据与环境转储、私人输入、安装器、运行库、恢复SQLite、完整第三方镜像、未核权全文。留档不意味着删除，也不意味着可忽略负结果。

可先发布“研究开发中的候选版本”，无需等到航天鉴定全部完成；但本节P0公开问题应先处理。发布副本需通过无商业CAD的轻量校验、具名科学场景复现、以及可选Windows CAD重建三层检查。每层明确依赖与成本，避免一键脚本覆盖封存Gate。

本轮产物是可接续的审计包，**不是已经去敏、授权或可直接推送的公开包**。没有创建GitHub仓库、上传文件或提交更改。
