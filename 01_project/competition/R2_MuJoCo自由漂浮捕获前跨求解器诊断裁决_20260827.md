## 3. 模型与三 lane 裁决

模型读取并哈希绑定 accepted B601 URDF、Unified R2 URDF、CURRENT R2 动力学/任务度量/时域控制包、父 HOLD Gate 与外审证据，不改写任何 accepted 资产或历史 Gate。Unified R2 基线为 19 link、18 joint、6R+2P，总质量严格为 `31.022864807342987 kg`；`spacecraft_bus` 使用 `servicer_free`，零重力，由 MuJoCo 独立积分基座位置、四元数和 twist。

三条 lane 的语义冻结如下：

| lane | 冻结语义 | 工程裁决 |
| --- | --- | --- |
| `LOCKED_2P_REDUCED_6R` | 2P 从自由度中移除并固定在 `qP*=[0.03575,0.03575] m` | 可与现行理想消元 6R 模型做严格动力学对照；没有 2P 约束反力输出 |
| `LOCKED_2P_EQUALITY_6R2P` | 保留 2P，以 MuJoCo equality 锁定 | 只允许称 `MUJOCO_SOFT_EQUALITY_LOCK_DIAGNOSTIC`；**不是精确刚性 KKT**，必须报告漂移和约束功 |
| `FREE_2P_ZERO_FORCE_NEGATIVE_CONTROL` | 保留 2P、`tauP=0`、不加 equality | 用于证明“零驱动力不等于锁止”，不得把自由响应删除或解释为异常噪声 |

所有 V1 geom 均关闭碰撞亲和性，接触数量必须保持为 0。由此只能证明“本轮没有启用碰撞/接触”，不能生成 `minimum_clearance_verified`、`collision_free`、`contact_force_valid`、`capture_success` 或 `target_attached`。

## 4. 本轮诊断链

机器 Gate 应覆盖：

1. 源 pin、精确环境、确定性转换、三 lane、自由根与非接触保护；
2. 全树名字/父子/轴/原点/限位、逐 link 质量/质心/惯量、B601 子树和 FK；
3. 无量纲质量阵、Jacobian、bias、6R/2P 与基座加速度交叉；
4. 零/非零线动量、非零角动量、6R 内力矩和 2P 解锁五类自由漂浮守恒运行；
5. `C0_UNCONTROLLED_5D_REFERENCE`、`C1_CONTROLLED_5D`、`C0_UNCONTROLLED_6D_REFERENCE`、`C2_CONTROLLED_6D` 四组 12 ms 运行；
6. timestep、单位重参数化、关节轴、link mass、任务权重、2P equality、自由根、碰撞亲和性、源锁和权限升级负控。

线动量 `P`、关于固定惯性原点的角动量 `H_O`、动能与 `∫tau_R^T qdot_R dt` 必须由逐 link SI 账本独立计算。MuJoCo 的子树质心角动量不能替代固定原点 `H_O`；混合 `rad` 与 `m` 的矩阵必须按冻结 DG1 尺度无量纲化后才能进入范数 Gate。
