# Route-C V9F 终局机械设计与后续仿真入口裁决

## 1. 当前总裁决

本轮已按 ODR-58 的有界授权完成唯一异构被动备选构型 V9F 的源级数字样机、独立运动学证明、局部载荷路径实体检查和九构型质量/惯量回灌。终局结果不是 Release，而是一个可复现的硬负结果：在当前 Route-C 评估器采用的 M01（STOW→RELEASE_CLEAR）直线关节空间路径中点，Link-4 下游线束段与 Link-3 vendor 本体发生 `-10.729480332 mm` 的原始实体穿透；加入 `6.583916665 mm` 跟踪/安装/热/网格降额后，门控间隙为 `-17.313396997 mm`。

该见证由红队修复前的参考评估器和 P0 优化评估器在独立冷进程中复算，43 个结果节点、19 个 binary64 数值逐位一致，结果指纹相同。由于一个必经当前路径姿态失败即可否决当前候选，剩余穷举被有依据地终止，未生成完整 Mission Coverage Gate，也没有任何正向信用。V9F 因此裁定为 `REJECTED_UNDER_CURRENT_FROZEN_MANDATORY_M01_EVALUATION`；Route-C/TMG-4 PASS 未签发。

这个负结果只证明“当前 V9F＋当前 M01 路径模型不能通过”，不证明所有可能的 6-DOF 替代路径或所有被动外置线束架构均不可行。M01 自身的轨迹权威仍为 `MISSING`，替代路径搜索未获授权、也未执行。ODR-58 的主候选、同构修复和唯一异构 fallback 额度均已用尽，剩余机械几何候选预算为 0。

## 3. V9F 机械构型

构型名称：

`CHAINLESS_TELESCOPING_TROMBONE_CASSETTE__R55_EXTERNAL_ANNULAR_FOLLOWER__LINK4_MOVING_TROLLEY`

核心设计由以下部分组成：

1. Link-3 固定根颈、主脊梁、公共支承毂和三支路环轨鞍座，建立连续可拆载荷路径。
2. 两条四级刚性嵌套伸缩腿和一个随动 U 形鞍座，用纯平移吸收 J4 一侧长度变化；实体不缩放、不柔性变形。
3. 固定桥接段和外置 R55 环形导向器，用反向弧长变化补偿伸缩侧长度变化。
4. Link-4 随动小车定义精确移动边界，之后的线束与导管全部归属 Link-4。
5. 上游 J1/J2/J3 及下游 J5/J6 保留现有导向、夹持、应变释放和连接器支承，冻结 B601 URDF 与关节限位不变。

### 3.1 J4 精确被动运动律

对 J4 关节变量 `q4`（rad）：

```text
x_C(mm) = -205 - 27.5·(q4 + 0.15)
β(rad)  = 20° + (1.57 - q4)
L_trom  = 2·(x_F - x_C) + π·sqrt(23² + 50²)
L_ann   = 55·β
dL_trom/dq4 = +55 mm/rad
dL_ann/dq4  = -55 mm/rad
```

因此交换子系统总长度恒定为 `595.300259711981 mm`。独立计算的全采样长度极差为 `1.136868×10⁻13 mm`，随动端 FK 闭合残差为 `6.512×10⁻14 mm`，两处切向连续误差均为 `0°`。

## 5. 局部载荷路径与装配顺序

### 5.1 已实体化的连续路径

`R55 环形导向器 → 三个可拆鞍座 → 三根轴向短柱 → 三个 Y 形支臂 → 公共毂 → 主脊梁 → 根颈 → Link-3 候选安装面`

该路径的源几何存在性已通过：13/13 个要求实体均存在、有效且质量为有限正值，14/14 个声明接口在哈希锁定三角网格的轴对齐包围盒检查中为零正分离；支承链候选质量为 `436.854233 g`。包围盒相交或相切不证明实体接触连续性，因此这些结果只确认源级构件与接口链存在，不是间隙、强度、屈曲、紧固件或模态合格证据。

### 5.2 推荐装配顺序

1. 校验 B601、M3R、夹爪、Solar R2、Unified R2 和 ODR-58 输入哈希，不匹配即停止。
2. 安装 bus 穿舱支架、基座环和 J1 半约束导向器，完成固定端连接器与第一道应变释放。
3. 自基座向末端依次安装 J2 导向、Link-2/Link-3 通道和 J3 载体；保持夹具编号与 CSV 登记一致。
4. 在 Link-3 候选安装面装根颈、主脊梁、公共毂和三支路鞍座；未定义根部紧固件前不得施加结构放行标记。
5. 安装两组四级伸缩腿、U 鞍座和硬限位；确认所有级为刚性平移，禁止用实体缩放模拟行程。
6. 安装固定桥、185° 环形导向器、随动器和 Link-4 小车；在 q4=0 对准精确 FK 随动端。
7. 安装 J5/J6 导向、腕部应变释放和数据/功率连接器分支。
8. 按中心线 JSON 和夹具 CSV 检查每个 bore 轴、位置、宿主 link、夹具类型和接口说明。
9. 手动低速执行任务限定 q4 行程，检查小车限位、每级搭接、线束擦碰和卡滞；全硬件 q4 范围禁止据此放行。
10. 在获得 P08 安装线束扭转载荷、紧固件定义、材料许用和环境载荷后，再执行结构/摩擦/寿命鉴定。

## 7. 评估器红队、精确反例与穷举终止

旧 V9F 快速运行在以下验证代码问题被发现后中止：

1. 动态 J4 线束和伸缩硬件对自身宿主 Link-3 的碰撞可能漏检。
2. 空比较集可能以无穷大形成伪 PASS。
3. 快速模式未明确声明非权威，且把未执行的加密计算误写成收敛信息。
4. FK、接口异常审计、J4 硬限位和有限值完整性未全部绑定到几何 verdict。
5. 同段硬件豁免范围大于已注册的局部 section/arclength 接口窗口。

修复仅限验证逻辑，没有改变 V9F 几何、路线、阈值、任务状态或冻结资产。随后建立了隔离输出、源/运行器前后哈希、staging/published/compared 三图一致、重复 JSON 键和非有限数拒绝的运行溯源框架；该框架经四轮独立红队后通过。
