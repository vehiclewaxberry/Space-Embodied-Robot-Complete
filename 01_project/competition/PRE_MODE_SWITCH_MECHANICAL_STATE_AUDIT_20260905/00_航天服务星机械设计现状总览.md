## A3 可以保留什么，必须纠正什么

本次没有重跑优化。独立使用 accepted URDF、原 STL 和**已存姿态**重算 28 条包络，尺寸最大差约 **2.84×10⁻¹³ mm**，inside 判别一致。A3 数值尺寸可以作为对应模型/姿态的研究结果保留。

但下列解释不能继续使用：

1. **0/16 找到解只说明该搜索未得到候选**，不是完整姿态空间的全局不可能证明；而所谓 full system 实际仍不含全部 M3R、保持机构和线束附件。
2. **A3.4 的 229 个 station 是凸包顶点分箱**，没有做三角形与切平面相交。全长对应 390 个分箱，其中 161 个没有保存。仅看局部 width 的“3 行超宽”不能说明固定外包络可行；已有 229 行中，按同一 ±113.15 mm 边界检查绝对位置，Y/Z 至少一向越界的有 **85 行**。
3. A3.4 完整臂在该记录姿态下尺寸为 **388.83336 × 283.30055 × 261.38177 mm**。逐站宽度较小不能消除全局越界，也不能通过各站独立居中获得一个固定装配。
4. A3.3→A3.4 重新居中改变了基座安装平移；交接中还混用了 CAND_2_FIT 与 CAND_5_THIN 的间隙数字。不同子集的最优解也不能拼成一个物理构型。
5. “0°余量”是优化边界设置，不等于六轴全部到硬止挡。原 CAND_0_THIN 逐轴余量读回否定了该解释。
6. 旧 80.3 mm 通廊居中时理想两侧各约 73 mm，不是一块连续 146 mm 航电舱；更不能继承给完整臂重优化后的不同姿态。分区体积的重叠和 corridor 定义也需区分，不能把 8638.2 cm³ 当作已验证净设备空间。

完整方法、数值口径与独立复算记录见 **`04_A3_METHOD_AUDIT.md`** 及 `a3_*` 附表。原始 FAIL 和 Gate 本次均未修改。

## 机械与具身智能的工程关系

当前四条链都已有中间资产，但尚未同配置闭合：

- **承载链**：收拢发射时，臂保持点/支承/HDRM → 所连接主结构 → 分离界面；展开操作时，机械臂根部安装接口 → M3R/承载桥/框梁。两种状态的实际载荷分配与拓扑都需在同一配置中绑定，还缺真实对偶面、紧固预紧、载荷与支撑验证的整体证明。
- **运动链**：收拢保持 → 释放 → 初始脱离 → 机械臂和太阳翼展开 → 工作姿态。静态包络、单 pair 结果或局部通道证明不能覆盖全链。
- **产品化链**：零件几何 → 材料/制造 → 安装/公差/紧固 → 图纸/BOM → 装配可达性 → 检验/试验。现有 CAD 和局部解析结果不足以宣称制造完成。
- **机械—模型—决策链**：同一配置几何与质量 → 动力学/接触 → 控制/碰撞后端 → SAFE/Sim13。测试和 fail-closed 成果可复用；尚不能宣称已获得可执行的整星具身操作能力。

R2 原终裁仍是 `TERMINAL_CLOSURE_EXECUTED__GATE_A_NOT_PASSED__TMG4_TM6_INTERNAL_BLOCKERS_REGISTERED__NO_RELEASE_CREDIT`。后续增量必须并列读取：Sim13 五个后端已有关闭证据和 20/20 Gate，但 full TMG6 未重发；不能继续简单说“五个后端全没做”，也不能说“机械交接已通过”。详见 **`05_AUTHORITY_AND_EMBODIED_HANDOFF.md`**。
