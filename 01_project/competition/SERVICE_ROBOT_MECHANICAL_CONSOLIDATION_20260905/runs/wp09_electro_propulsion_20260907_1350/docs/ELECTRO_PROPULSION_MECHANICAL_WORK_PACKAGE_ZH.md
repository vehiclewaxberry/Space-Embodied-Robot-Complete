## 4. 24 V机械臂支路的明确接口

建议将支路按功能登记为：电池配对端与可断开连接 → 支路保护/电流测量 → 覆盖约定输入范围的稳压DC/DC → 机械臂驱动器；再生能量由已验证的电源吸收能力或独立吸收/回送装置处理。实际顺序与器件由电气设计核定，机械设计应分别保留这些器件的体积、散热面、插拔空间和可替换接口。当前没有可直接用于定型的B601持续/峰值电流与回馈包络。

PDU-200的24 V选项是降压路径，资料要求电池电压相对输出有严格大于1.5 V余量，故24 V稳压要求输入 **>25.5 V**。BPX 8S的24–33.6 V范围及建议23.6–32 V范围都包含不能满足这一条件的低电压段。不得仅据“28.8 V标称电池”判断全工作范围兼容；不得并联CH1/CH6假设电流自动均分。[PDU-200原厂选项表，Rev4.5](https://gomspace.com/wp-content/uploads/2025/09/gs-osf-nanopower_pdu200_OSF_-_1021197_-_1_-_45_-_1.pdf)，[PDU-200原厂数据表，Rev2.6](https://gomspace.com/wp-content/uploads/2025/09/gs-ds-nanopower-p60-pdu200-26.pdf)

A3200主电源为3.3 V域，其磁力矩器PWM/H桥功能不等于机械臂驱动。A3200载体需保留与电机高电流导线的端口/线束责任边界，不以共用机械载板推出可共用电源、信号地或散热路径。[A3200原厂资料，Rev2.0](https://gomspace.com/wp-content/uploads/2025/09/gs-ds-nanomind-a3200_1006901-2.0.pdf)

此支路在真实负载数据到位前，`driver_selected`、持续/峰值电流、再生吸收能力、保险额定值及电源通电兼容性均保持未确定。机械候选可以建立参数入口和安装责任，不能自行填充典型电流后宣称电气收束。

## 5. 几何与装配检查的交付要求

每个工作项应交付源文件/厂家图版本与哈希、坐标系和单位、实际BOM和实体角色、参数化源、独立导出的STEP、原生装配及依赖清单，并将未知接口与具体实例关联。`PHYSICAL_GEOMETRY`、厂家外廓参考和服务/运动禁入体需要可分辨显示；每个器件实体只有一个质量归属。资料无密度/实际质量时保持未分配，不从显示颜色或实心代理体积生成整星质量。

独立检查应从当前源STEP和真实变换开始：核对实体数、孔轴/通孔、座面、标准件尺寸与接触；对承载件核实删料范围并保留原有孔槽；对邻件做有界材料相交和最小距离检查。工具检查必须说明是在最终装配状态，还是移除了明确登记的设备/热垫后的安装状态。插头实际配对几何、锁扣操作及电缆应力释放需要单列，Ø4/Ø8圆柱工具代理不代表所有真实工具都能使用。

原生文件应在保存后关闭重开，复核实际组件ID、文件路径/哈希、变换、实体数及单位；装配固定姿态通过不等于运动配合、全行程碰撞或实物初装通过。完整三态装配如尚未合入本轮局部候选，应明确保留“局部候选未集成”状态。本轮合同当前均标记未集成WP08，实际执行结果以最终机器记录为准。

## 6. 推进与工程结论的边界

VACCO资料可支持0.3U的542 g湿质量、44 N·s总冲、五个推力器及外部安装研究。原图4×19°是正视图内的图样角，不能直接生成五路三维力向量或羽流半角。供应商整体设备是采购候选，本轮不根据外形图设计承压腔、壁厚、焊缝、内部管路、阀座或喷嘴内部。[VACCO原厂资料](https://www.vacco.com/images/uploads/pdfs/MiPS_standard_0714.pdf)
