# 既有材料模型的惯性读取任务

只读封存参数包中 306 个明确有材料质量的实例，对 237 个唯一 STEP 源提取局部质心和惯性。材料为既有铝 2700 kg/m³ 或钢约 7850 kg/m³ 模型；不对 B601 整臂、CIC 厂家平均重量、设备外形、胶层或规划预算赋密度。没有几何创建/修改，按 CAD 技能的无可视变化例外不生成新截图。

输出全部写入本 mechanical_inertia 目录。原 STEP、原生 CAD、封存参数包、URDF 和历史 Gate 均只读。调用同一 OCCT BRep 几何内核读取 STEP，先验证导入为有效正体积闭合实体，再记录默认积分以及两档自适应积分；默认模型质量与历史账本作同方法比对，发现偏差保留为真实差异。数值收敛差不是制造公差或严格误差上界。

输出局部坐标采用源 STEP 的毫米坐标，经显式转换成为米；局部 COM、关于 COM 的惯量按 SI 输出。使用既有三态变换旋转惯量，并以平行轴定理得到关于 S 原点的惯量。固定构型只作为坐标验证，不建立运动树，不将部分材料小计宣布为整星质量或动力学模型。

每批仅一个自有几何子进程，结束即释放内存。复用封存护栏的代码副本：启动可用内存至少 2048 MiB，运行可用至少 512 MiB，子进程树工作集采样上限 1400 MiB，同时保持 Windows Job 分配限制；不放松门槛，不启动 SolidWorks，不终止未知用户进程。
