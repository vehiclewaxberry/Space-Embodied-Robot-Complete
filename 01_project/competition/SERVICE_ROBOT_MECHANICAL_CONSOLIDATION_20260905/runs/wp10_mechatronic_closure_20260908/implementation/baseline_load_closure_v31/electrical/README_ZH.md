# V31 B601 DM 负载与电气参数包

日期：2026-09-11。范围：机械臂六轴＋夹爪的 24 V 支路。按用户已授权的公开资料与显式假设推进；本包不修改原始工程源，不操作 CAN/串口或实物。

本轮把“型号、默认配置、物理参数、任务功耗”拆开记录，并提供可以被任务相位计算调用的函数。它解决负载输入的定义和来源问题；实机任务负载谱尚未测得，不能宣布容量或散热已经定型。

| 输入 | 本轮结果 | 可用于什么 |
|---|---|---|
| 关节型号 | 官方 SDK 绑定 joint1–3 为 DM4340P，joint4–6 和 gripper 为 DM4310 | 公共参考架构，共七轴；不是实机铭牌回读 |
| 供电 | Seeed 推荐 24 V、15 A 外部供电 | 测试供电参考；360 W 不是任务上界、实测峰值或连续负载 |
| 手册物理值 | 原样登记两族的额定、峰值、电阻、电感和减速比，并绑定页码与本地 SHA256 | 文献条件；不跨硬件修订合并 |
| 电机参数导出 | 读取官方示例 Rs、Flux、Gr、GREF、UV/OV 等 | 追溯差异；不写回硬件、不当实机校准 |
| 任务输入 | 60/120/240/360 W 四档总臂支路运动平均功率扫描；保持、待机、夹爪独立未知 | 条件敏感性，标签 `DESIGN_SENSITIVITY_NOT_MOTOR_PREDICTION` |
| 实机负载 | 母线电流、回生能量、保持功耗和损耗图均为 null | 待采集和条件绑定，不能用零替代 |

## 源资料存在的具体差异

- DM4310 手册为电机 V1.1、说明书 V1.0（2023-11-16），第 9 页相电阻 0.65 Ω；Seeed 导出为 0.599754 Ω。
- DM4340P 本地说明书为 43 页 V1.0，封面日期仍为 `2025.xx.xx`；第 4 页为 9/27 N·m、相电阻 0.88 Ω，Seeed 导出为 0.610635 Ω。独立网页读取的厂家署名 14 页手册在第 11 页给出同组参数。
- [达妙当前产品目录](https://www.dmbot.cn/index.php?c=category&id=22)同时列出旧 DM4340P 9/27 N·m 和 V1.1 的 12/40 N·m。较新规格不能自动赋给当前 B601。
- 两份继承手册的原 GitHub 原始 URL 本次 web 查询为 404；本地文件与已有 SHA256 一致。来源可追溯不等于当前线上受控版可用。
- 手册额定/峰值电流表没有给出足以统一母线电流、相电流 RMS 和相峰值的完整定义。不得将各轴电流表直接相加作为母线容量。
- 默认 `KT_Value=0` 不等于物理扭矩系数为零；`TMAX/VMAX` 是协议映射范围。公共 Flux/GREF 推出的 Kt 只存为条件诊断，不进入实际电流预测。

## 计算接口

`load_model.py` 全部使用 SI，只有能量输出为 Wh：

```python
from load_model import evaluate_axis_power, phase_energy_Wh, sampled_bus_metrics
# 未提供损耗或相电流时，母线结果为 None。
r = evaluate_axis_power(torque_output_Nm=0, omega_output_rad_s=0, bus_voltage_V=24)
# 360 W 持续 10 s 是 1 Wh；只代表输入情景。
assert phase_energy_Wh(360, 10) == 1
```

功率平衡：`P_bus = tau_out*omega_out + P_gear + Σ(R_phase I_phase_rms²) + P_core/mechanical + P_driver + P_electronics + dE_internal/dt`。

所有项必须采用同一输出轴与时间窗。稳态才可显式假设内部储能变化率为零；静止保持的轴机械功可以为零，但铜耗、驱动和电子待机仍存在。不得把平均扭矩与平均速度的乘积当成一般运动下的平均机械功，应逐样本计算乘积再积分。

负母线功率表示对回生通道的要求，并不证明装置能够完成制动或电池接收了能量。积分分别记录支路消耗与返回的电能，不先相互抵销。`battery_recovery_credit_Wh` 保持 null。采样峰值取决于带宽，函数不自动宣称测得了真实瞬态峰值。

母线相位计算每一相位只能使用一个总臂支路功率。若运动/保持功率已包括夹爪，则不可再次叠加夹爪；只有明确排除夹爪时才另加。主机、相机和外部控制器功耗在根任务卡另记。

## 复现

在本目录运行 `python build_load_package.py` 和 `python -m unittest -v test_load_model.py`。构建仅依赖标准库和包内快照，不联网、不加载旧 CAD/KiCad、不触发旧仿真。输入 SHA 改变会拒绝构建；带数据的采集模板不会被覆盖。

测试包括：保持态有功耗、相电流不等于母线电流、负轴功并非必然回生、未知输入不填零、储能变化不可遗漏、单位换算、正负能量分账、缺失样本及非单调时间拒绝。测试验证计算合同，不验证真实 B601 或供电链能力。

采集方法见 `BUS_CAPTURE_PLAN_ZH.md`。源码来源、URL 与 SHA 见 `SOURCE_MANIFEST.json`。
