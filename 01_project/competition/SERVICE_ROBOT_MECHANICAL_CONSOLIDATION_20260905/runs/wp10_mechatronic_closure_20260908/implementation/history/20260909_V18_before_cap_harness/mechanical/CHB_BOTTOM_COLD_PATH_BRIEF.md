# CHB 底部短路径与双侧导热臂（当前候选 V7）

本次替换原 +Y 高位 CHB 热座：厂家 CHB 完整体转为底部水平安装，S 基面(-25,0,-96.15) mm，引脚向 +Z。原实例 ID U202_CHB 保留，当前电气图对应 U203，不新增重复电气位号。

底板上一体加工58×62台座、两根L导热臂；台座面z=-96.353，TSP1800ST名义厚0.203。立柱x[-54,4]、|y|33..47，横臂z[-82,-58]，端面|y|96.297。甲板开60×96窗口，原底板六组夹紧点保留。侧壁增加58×24接耳，内面|y|96.5；两处0.203厚TIM填实冷指与壁座间的名义间隙。装配基准直接定义于S，禁止再叠加旧局部安装板变换。

新增8枚M3×20名义螺钉与2片侧壁TIM：4枚从外底安装CHB，4枚从两侧外壁紧固冷指。复用已检索的Würth 4123 53 20（ISO10642）公开尺寸，厂家CHB STEP孔轴48.26×50.8优先用于名义定位，图纸48.3舍入差每侧0.02保留。TIM孔Ø4.5，项目通孔Ø3.4，螺纹简化；有效啮合、公差、预紧及防松尚未验收。

底部M3×20名义进入CHB基面2mm；侧壁M3×20名义进入冷指3.147mm，项目孔深5mm，距名义孔底1.853mm。装配顺序为太阳翼展开、设备与PCB安装前完成底部和侧壁紧固，再向中央上方接线。折叠帆板会遮挡侧壁工具域，不给折叠状态工具可达信用。

三处TIM已同时改用Henkel TSP1800ST。厂家2018年11月TDS给出25psi典型面积热阻0.28K·in²/W（包括两侧接触界面），旧TSP1600S为0.75。其ASTM D149典型击穿由5500Vac降为3000Vac，属于热性能与绝缘材料性能的取舍，不能称全面升级。金属螺钉跨过TIM，组件并不因此电气隔离。TSP3500的0.254mm片在同25psi下为0.43；Q2500为0.30但不绝缘，均未选作本次CHB垫。

25psi=0.17236893N/mm²，按净垫面积计算，CHB垫需总平均承压力557.524N（理想四钉均分139.381N），每侧垫234.455N（理想两钉均分117.227N）。这些不是已证明的实际预紧力或装配扭矩；名义0.203mm厚度也不是25psi压缩厚度。实际压缩、面形、压强分布、螺纹承载、防松与热循环后预紧需验证。模型同时保留10/25/50/100/200psi公布数据点的敏感性，不将10psi当作最低压力保证。

厂家放气表所列TML0.23%、CVCM0.05%、测试固化条件N/A只对应其材料筛选；不能称为NASA对采购批次或整星的认证。[原厂TDS](https://datasheets.tdx.henkel.com/BERGQUIST-SIL-PAD-TSP-1800ST-en_GL.pdf)、[放气表](https://dm.henkel-dam.com/is/content/henkel/product-sheet-nasa-outgassing-5011-products-a4)及本地SHA见sources/COLD_TIM_SELECTION.json。原TSP1600S实体与2.5mm网格105.141870°C反例保留于history/20260909_cold_path_TSP1600S_thermal_failure，360W臂任务和105°C限值未降低。

热计算保持360W臂任务与1W制动偏置，85%效率敏感性对应63.706W CHB损耗。原单侧与新底板单面热失败均保留。三板非等温模型使用同状态STEP局部遮挡，并允许反向导热；两侧金属臂、TIM压紧、涂层、其它设备热源和任务环境必须逐项绑定。有限方案计算不等于轨道热试验、制造或飞行放行。
