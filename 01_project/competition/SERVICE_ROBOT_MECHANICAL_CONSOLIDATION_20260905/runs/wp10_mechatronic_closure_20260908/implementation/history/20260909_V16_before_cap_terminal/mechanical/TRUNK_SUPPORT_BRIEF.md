# 连续主干线四站支撑实际改件

在当前V9三态893实例源表基础上，替换四夹具和四旧高支柱；保留功能线始末端与OD6/R21曲线。坐标为S系mm。四站轴为(-95,1.5,45)、(-30,1.5,-2)、(25,1.5,-2)、(65,-40,-2)，末站沿−Y，其余沿X。

各夹具12mm轴向长、24mm宽，Ø7分型孔包围两片径向0.5mm的衬套几何。夹盖4mm厚；低位座6.5mm高直接贴甲板z−8.5。高位座沿设备间走廊设4mm厚立柱及32×8×3底脚，柱/脚直接承载于甲板；两块项目载板在x[-111.5,-78.5],y[-15.5,-6.5]窗口作边缘避让，保存厂家设备几何和原载板孔系。高位夹具下表面z40，端螺钉顶z49。

两颗M3×14高位夹具螺钉、六颗M3×20低位螺钉及两颗M3×12底脚螺钉采用沉头名义包络，复用现有来源的M3垫圈和螺母；甲板新增8个Ø3.4孔。螺钉形状用于安装占用检查，不代表已经绑定标准件料号、螺纹、强度等级或防松方案。衬套仍是材料/压缩量待定的安装空间，不授予夹持力、绝缘、耐磨或放气合格结论。

装配顺序：完成甲板及载板局部开孔/边缘避让的设计审查后，先装支座、下衬套、线束、上衬套和盖，再装电池；这是数字装配顺序，未授权制造或通电。验收须检查源哈希、只在指定窗口减料、实际支座/紧固件接触、与全部三态近邻的穿透及电池间隙，不以删除旧实例或省略载板获取通过。释放支路和顶端穿孔的应变释放仍单独开放。整机质量、热、结构与连续线束运动必须重新评估。

首轮真实反例：高位脚架与驱动连接器穿透460mm³；新添悬臂局部填回一颗螺钉通孔而产生5.15638mm³穿透。已将高站轴移到x−95，连同底脚/甲板孔/两载板避让窗口同步移动；并在支座整体合并后重开通孔。原反例留存于history/20260909_trunk_first_geometry_counterexample，必须由复检裁决修复是否成立。
