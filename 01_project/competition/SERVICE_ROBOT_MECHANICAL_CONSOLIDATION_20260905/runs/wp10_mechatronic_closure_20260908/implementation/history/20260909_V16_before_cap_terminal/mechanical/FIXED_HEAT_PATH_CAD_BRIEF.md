# 固定热出口：当前 WP10 候选改件

设计问题是把现有 CHB 和三路制动电阻的热量送到暴露固定外表面。继承 WP06 的两块真实剪力壁及其原孔阵、2 mm 承压叠层，在同一实体上加工内安装台、跨隙导热凸台和外散热板；替换原可拆侧盖。原873封存父本保持。

S系，单位mm。外表面保留y=±113.15，面尺寸344×180，暂选8厚；不增加展开机构。CHB原90×90×4座位于(96,100.5,44)，局部+Z向舱内。三电阻改为独立72×60×6座，−Y侧x=−128/−50/104、z=65.075、背面y=−89.5，OEM旋转使原X向S+Z、原Y向S+X、原Z向S+Y。TIM型号和原厂STEP沿用本候选已核实来源，新增结构不以包络替代原厂件。

内安装台与壁、外板为整体加工候选，消除额外干接触热阻；TIM仍需实际压紧。原壁螺钉的头部和装配工具通道须在外板逐一避让。原两盖的连接件必须明确保留、改件或移除。CHB窗口需移动DUAL线束夹完整组S(+6,−10,0)mm，改两孔和相应两条线束。先进行真实bbox与局部实体复核，公差余量不能由零交叠推断。

核验：两壁单一有效实体；外面实际净面积；TIM接触面积及零体积交叠；整体转换矩阵与原S系一致；父873三状态的静态干涉与未覆盖对象清单；实际质量增量；源引用哈希；STEP快照。热计算保留外热流、翼遮挡、效率及温度反例。未补齐物理输入前不得赋予整机热验证或制造放行。
