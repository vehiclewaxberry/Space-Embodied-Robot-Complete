# 电池舱推进线束与双孔夹具修订

同WP10候选继续改件。新RRC包络的+Y边界27mm，导航设备-Y边界54mm；两条OD6、中心线R21路线置于中间走廊，水平轴线y34/48、z59mm。原PROP_PWR起点及单路夹具保留，先做三维相切S弯升高并减小Y，再经双孔夹具和原甲板护圈；PROP_DATA原起点在电池内，改到S(45,34,59)功能交接位置。两个模块侧末端仍为原(144,48,-65)与(140,56,-45)。所有这些端点均无厂家针脚绑定；数据线新增起点不是导航盒插座，仍需上游真实端接。

双孔夹具改为x65…95、y29…53、z52…66mm，水平Ø8孔轴位于y34/48、z59。底座/盖各厚7mm，螺柱孔Ø3.4位于(72,41)、(88,41)。两支柱外径12/内径3.4，z=-8.5…52；名义M3杆从z=-17.5…72.5。原8个垫圈/螺母按原来源迁移，顶部上移14mm。甲板增加两孔，旧孔全部保留。夹具管孔与螺柱孔名义最近余肉1.3mm需实际实体验证；护套、夹持力、材料、螺纹、防松、强度、工具空间和公差未获信用。

保持8mm孔径作为已有支撑包络设计参数，不据此声称选定了护套型号。旧PWR夹具及所有未改功能保留。验收采用实际STEP、局部基准与source SHA绑定；检查路线/电池/导航、两路线互相、路线/夹具、支柱/甲板/拉杆以及所有变化邻域。零距离仅对事先列出的承载面允许，支路接续不得整件豁免。静态几何通过不等于全线束或机电闭环。
