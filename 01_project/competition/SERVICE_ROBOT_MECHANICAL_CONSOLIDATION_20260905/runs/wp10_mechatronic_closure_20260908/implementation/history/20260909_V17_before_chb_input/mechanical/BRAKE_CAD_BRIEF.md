# 三路制动电阻局部装配设计

目标：把实际电气位号 RB301–RB303 对应的三只 LPS0300H1R00JB 安装到一块可参数化承载热板。文件保持在当前 WP10 活动候选，尚未获得 873 整星总装安装信用。

单位 mm；板下表面中心为原点，XY 为板平面，+Z 指向电阻。板 150×160×6；电阻中心依次 (-37.5,-37)、(37.5,-37)、(0,37)。框架连接孔位 (±67,±72)，Ø4.5；其全星框架配合尚待总装绑定。

优先检索 step.parts 的 LPS300、Vishay LPS 300，均返回零结果。Vishay 数据表链接实际提供厂家 STEP，已取代包络。模型自身五个实体有效，但导入记录有一个 unresolved reference 诊断，保留原始日志。原始模型底面 Z=-0.2，导热面 56×51；放置时以这个真实面为基准，禁止用外壳 Z=0 错置导热片。

真实材料选 BERGQUIST SIL PAD TSP Q2500（Q-PAD II），厂家厚度0.152，项目裁切56×51，三片，明确选择无PSA压敏胶版本；不是此前的0.127猜测值，也不是电气绝缘材料。材料选择对应 Vishay 指定的 Q-PAD II 推荐。50psi的典型阻抗0.22°C·in²/W只用于条件热计算，压紧/寿命/真空行为未知。

安装孔存在来源差异：2021数据表给57间距、Ø4.2；公开STEP的上方安装凹槽轴为Y=-28.2745623577/+28.2254376423，间距56.5。板用4.5×6、沿Y方向的通槽容纳这项偏差；此适配不把数据表与3D视为同修订验证。M4螺钉/锁紧垫圈需适当防松及扭矩，暂未以假硬件实体计入装配完成。

交付：brake_carrier.step.py / .step、brake_tim.step.py / .step、brake_resistor_installation.step.py / .step。源中刚性基准将TIM底面贴板上面，并将各电阻底面贴TIM上面。独立OCC检查正体积、板/膜/电阻零重叠、三处2856mm²接触、孔位和最小电阻间距；生成并检查快照。不能据此宣布热排出、传感器贴装、紧固件、整星集成或制造放行完成。
