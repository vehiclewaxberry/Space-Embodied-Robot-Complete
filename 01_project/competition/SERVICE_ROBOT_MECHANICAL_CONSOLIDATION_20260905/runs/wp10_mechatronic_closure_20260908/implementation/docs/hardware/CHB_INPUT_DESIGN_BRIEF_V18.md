# WP10 CHB 输入端接板，V18

2026-09-09；同一 WP10 候选的 B03 实际改件。V17 已按 696 文件归档。原 965 实例及 873/99 父本保留。

采用局部输入端接板，24×60×1.6 mm，S 中 x=-63..-39，y=-30..30，z=-81.3..-79.7。底视图针位按厂家 STEP 变换落位：1=(-49.13,-17.78)、2=(-49.13,-7.62)、4=(-49.13,+17.78) mm。1/4 针径2±0.1，2针径1±0.1；V12 p10 端子伸出5.3±0.5 mm。实际 STEP 的圆柱段和端头不完全等于图纸极限尺寸，分别保存证据。

项目孔径选择：功率针成品PTH Ø2.4/铜盘Ø4.8；控制针PTH Ø1.4/铜盘Ø3.0。这些不是 Cincon 推荐数值。最大针径下名义直径间隙为0.3mm；孔、针位置和镀后尺寸公差未闭环。端接板分配双面各70µm铜；不继承C203密封侧单面铜限制，因本板不位于电容密封面。板材和载流/焊接工艺仍未合格判定。

每个功率针提供独立的主馈电焊孔(x=-57，Ø3.0/盘5.5)和电容焊孔(x=-42，Ø1.8/盘3.5)，y均同功率针。主馈电走线5.5mm，电容支线3mm。主馈电孔为几何分配，导线型号/应力消除未绑定；不得据此判20A接口完成。控制焊孔(-57,-7.62)，Ø1.4/盘3.0，归属现有隔离开关网络；不短接到输入返回。各电气端由现有系统网表绑定，不凭重复针号认定铜连通。

板通过CHB输入侧两处既有M3贯通嵌件固定，避免电气针脚承担板重；这是项目选择，非厂家强制要求。两处孔轴取STEP x=-49.13,y=±25.4。嵌件上端金属座面为S z=-83.95，壳体最高名义面-83.45；设计PEEK阶梯垫柱伸入孔口，OD4/ID3.2，台肩OD7，下端-83.95、上端-81.3。M3×8螺钉从板顶向下，线程用标称包络表示，不能把它与OEM内螺纹的小径实体重叠误判为制造干涉，也不能因此判预紧合格。保留既有底部螺钉，检查两端伸入距离。

先生成原生PCB、同源STEP及装配，验证针位/孔位/板厚/端头余长、与965源实例的局部干涉及铜路断线反例。C203导线采用已选55A0111-18-9；曲线和保持结构必须有空间证据后才进入真实装配，未生成路线不填已布线或裁线值。
