2026-09-09。同一工程候选；原 873组件/99位号父本保留。当前增加端接板、两个垫柱和两个螺钉，共5个实例；三态源清单由965增至970，原965行逐项相同。此次生成11件局部STEP，尚未生成970件完整原生SolidWorks总装。

## 实际设计

CHB电气位号U203，对应既有机械实例U202_CHB。新板为24×60×1.6mm，S坐标x=-63..-39、y=±30、z=-81.3..-79.7。双面各70μm铜，芯板1.44mm、两面阻焊各0.01mm；FR4供方、Tg、热/真空性质与公差未冻结。

| 模块针 | 原系统网络 | 实际端接 |
|---|---|---|
| 1 / +Vin | WP10_PRECHARGED_PLUS | Ø2.4模块针孔；Ø3主馈孔；Ø1.8 C203正引线孔 |
| 2 / ON-OFF | WP10_CHB_ENABLE | Ø1.4模块针孔和控制线孔；未短接输入返回 |
| 4 / −Vin | WP10_INPUT_RETURN | Ø2.4模块针孔；Ø3主馈孔；Ø1.8 C203负引线孔 |

输入端接板只覆盖1/2/4针；原系统其余输出针保留。它没有替换完整U203符号，MCP建立的空白板项目原理图不是新的整机原理图。整机真值仍是 `ecad/wp10_system.kicad_sch` 及其同源网表。J201.2/Q204.S的输入参考回线、主馈线和C203导线实体仍需绑定。

孔径和铜盘是项目计算选择，**不是Cincon推荐尺寸**。[厂家V12 p10](../../sources/cincon_chb500w.pdf)给出针径及伸出；[V13应用笔记](../../sources/chb500w_application.pdf)要求输入低阻抗、低电感和就近电容，但未给数值化PCB孔/铜盘、最大输入线长或针脚承重能力。孔位方向、标准件8针与-PC选件区别均按对应资料核对。

板经输入侧两处既有M3嵌件固定。项目PEEK阶梯垫柱高度2.65mm、内径3.2、杆外径4、台肩外径7；两个M3×8标称螺钉从板顶向下。支撑端头座面取OEM STEP嵌件几何，不让电气针承担设计板重。厂家模块安装扭矩未直接移用为PEEK夹持扭矩。螺钉/内螺纹仍为简化几何，有效啮合、预紧、防松和PEEK蠕变未验证。
