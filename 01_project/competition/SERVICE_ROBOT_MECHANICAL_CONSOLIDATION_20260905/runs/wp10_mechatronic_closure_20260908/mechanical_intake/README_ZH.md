# 当前机械装配到动力学的参数接入口

本包把已封存的 WP09 三态原生装配转换为可解析的机械输入清单。它完成几何身份、坐标与单位的接入，保留缺失的质量分布和运动树；**当前 873 实例尚不能直接作为完整航天动力学、实机控制或强化学习部署模型。** 本次未加载 CAD、调用 OCC/COM、运行仿真或修改既有 URDF/Gate。

核心交付是 [PARAMETER_PACKET.json](PARAMETER_PACKET.json)，附 [逐实例表](INSTANCE_INTAKE.csv)、[43 个责任归属的补全工作表](OWNER_CLOSURE_WORKLIST.csv) 和 [物理输入缺口](PHYSICAL_INPUT_GAPS.json)。所有路径和 SHA 来源均写入参数包，引用既有资产，不另复制或修改零件。

| 当前证据 | 已交付内容 | 仍不能由它推出的结论 |
|---|---|---|
| 三态各 873 个叶实例、10 个单位变换容器 | 2,619 个固定构型位姿；读取实际冷重开 SW16 并比对源位姿 | 容器不是动力学 link；三个固定姿态不是关节运动树 |
| 43 个质量责任归属 | 873 个身份全部有归属，三态是同一套硬件 | 归属完整不等于每个 link 都有惯性参数 |
| 306 个候选材料质量 | 体积 × 已声明密度模型，保留算法与源 SHA | 不是实物称量、制造公差或整星真实质量 |
| 84 个 CIC 各 3.6 g 厂家平均重量参考 | 整个 CIC 单元平均质量身份，不给玻璃包络赋密度 | 成形互联未完整建模，平均重量不等于逐件保证值 |
| B601 的 10 个 link 被整臂 4.5 kg 参考覆盖 | 整臂 owner 质量只出现一次，不平均分配 | 10 个 link 的质量、COM 和惯量仍缺，不能用 4.5/10 补零 |
| 472 个仍无数值质量的物理/代表实例、1 个纯预留体积 | UNKNOWN 保留为 null；纯预留体积不转成零质量刚体 | 预留体积和旧预算不能被当成真实设备 |

因此，旧账本的 **400 个数值覆盖 = 306 个材料模型 + 84 个 CIC + 10 个整臂覆盖 link**；本包实际可直接读取的逐实例质量数是 **390 个**。872 个物理/代表硬件均缺完整的本地 COM 与关于 COM 的惯量，当前完整刚体参数集合为 0。另有运动树未绑定，总计 873 条物理输入拒绝原因。整星质量、COM、惯量保持 null；材料小计 7.872303367396381 kg、整臂 4.5 kg、CIC 组 0.3024 kg 分列，不作“整星总重”粗加。

## 单位、坐标和质量归属规范

采用列向量约定 `p_S = R_S_local p_local + t_S`，所有旋转无量纲、右手正交；源位移为 mm，输出为 m。只转换 4×4 变换的前三行第四列，不能将整个矩阵乘以 0.001。原生 SW16 的前 9 项依照已封存写入器为列主序旋转、9–11 项为米、末四项为 `[1,0,0,0]`。父容器必须为单位变换，叶位姿只应用一次。

转换白名单包括 `mm→m: 10^-3`、`mm³→m³: 10^-9`、`kg/mm³→kg/m³: 10^9`、`kg·mm²→kg·m²: 10^-6`。惯量必须声明参考点为质心和表达坐标系，检查对称性、半正定和主惯量三角不等式。旋转误差验证容差是数值比较门槛，不是装配角度公差。

每个物理量都有 `estimate`、`unit`、`identity`、`standard_uncertainty`、`distribution`、`degrees_of_freedom` 等字段。没有校准、厂家保证区间或统计模型时，不确定度、分布、自由度和相关组保留 null；数值估计不因此变成精确值。设计公差不自动当成独立均匀分布，本包未执行 GUM 或蒙特卡洛不确定度计算。

`validate_mass_selection` 拒绝“整臂 + 自己的 link”“整组 CIC + 84 个 CIC 子项”和重复令牌。返回允许仅说明所选项没有这一类重复记账，**不授权混合材料、厂家参考、旧预算相加为整星真质量**。局部包围盒只可作场景筛选和尺寸检查，不能作为 COM、均匀密度实体或完整碰撞证明。

当前源 `product_role` 中仍有历史标记，而且前面板、GSE 接口和备选推进包络会出现在同一设计场景。本包将 `included_in_flight_hardware` 保留 null；后续必须明确飞行、地面样机和 GSE 的构型清单，不能根据零件名自动删重或计入整星。当前 MiPS 包络/支架也不能自动继承 C-POD 等后续候选的质量和安装参数。

## 如何使用与补齐

读取 JSON 后先执行 `validate_packet_integrity(packet)`；其检查 873 个身份、43 个归属、三态、单位字段与源/SI/实际冷重开位姿的一致性。需要完整刚体参数时执行 `physical_readiness(packet)`，当前必须返回 false。不能删去 UNKNOWN 或用零/包围盒中心替换，使检查器变成通过。

实际补全工作按对象推进：

1. 对已有 306 个材料质量的几何，按相同材料和体积算法从源实体抽取局部质心与二阶矩，再验证刚体变换、平行轴定理及误差范围。本次没有代为抽取，因此仍是明确待办。
2. 对 B601 DM，绑定与供货版本匹配的关节树、轴、零位、限位、减速/电机映射和逐 link 惯性；将现有已接受的模型作为单独有来源的比较对象，逐项核对当前机械安装，不改写其历史裁决。
3. 对胶层、层压板、线束、紧固件和设备，先冻结实际料号/材料/配置。需要厂家数据或测量的清单见逐 owner 工作表；有体积但没有已选材料的胶层也不填密度。
4. 对推进总成，绑定最终受控供货型号、安装坐标、干湿质量及推进剂变化下的 COM/惯量；同时替换或明确保留当前候选包络，不以公开候选的参数冒充当前实物。
5. 对完成的刚体，建立装配连接到真实运动 link 的归并关系，再生成按构型计算的质量/COM/惯量。柔性帆板、线束、接触与执行器另需实测或有界参数，不从固定 CAD 状态中自动生成。

本包可先用于后续研究的数据导入、静态场景核对和参数缺口管理。是否采用原有已验证模型做算法开发，应保留独立版本、假设及其适用范围；当前 WP09 实物样机参数还没有因此具备全系统动力学或实机策略部署的证据。
