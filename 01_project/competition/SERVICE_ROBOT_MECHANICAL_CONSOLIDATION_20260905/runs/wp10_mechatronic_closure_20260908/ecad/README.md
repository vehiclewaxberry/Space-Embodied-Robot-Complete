# WP10 实际系统电气设计

用 KiCad 打开 `wp09_system.kicad_sch`；同目录保留子页、两个本地符号库及 `sym-lib-table`。实际导出的两页图纸在 [PDF](exports/WP09_SYSTEM_AND_STOP.pdf)。

本版有99个实际器件、97个网络和72条外部接线，包含76器件停止子页。主表见 [MASTER_FROM_TO.csv](MASTER_FROM_TO.csv)；[MASTER_BOM.csv](MASTER_BOM.csv)的107行包含99个实际原理图位号和8条父级引用，不能将引用再次采购或求和。

上述器件数是原理图位号统计：76个子页位号含71个选型器件与5个逻辑接口，另有23个顶层设备/边界；不代表已装配实物。97个导出网络含16个显式NC隔离网，其余81个为非NC网络。

J101.1、J101.2已改为内部3.3V和5V测试输出，禁止再接外部电源。24V辅助触点湿润路径通过真实K1辅助触点，源与回读不可短接。设计细节及尚未证明的电源纹波、启动、停止动态和温度边界见[电路说明](../electrical/README.md)。

两项ERC电源驱动诊断保留，解释见[ERC_DISPOSITION.json](ERC_DISPOSITION.json)。原理图和静态计算的通过不构成PCB布局、实物上电或100ms整链停止验收。

原生原理图移至第二目录后已实际重新导出并比较器件身份、网络成员和ERC诊断，记录见[可移植检查](../results/ECAD_RELOCATION.json)。生成和集成脚本依赖本项目封存父版本；交付包中的KiCad设计文件可独立打开，并不声称所有工程生成脚本已脱离项目数据运行。
