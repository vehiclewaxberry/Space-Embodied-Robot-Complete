# 四块未选型 PCB 的机械参考源

模型为独立审阅场景：四块互相分开的参考板，没有新增实物托盘或卫星安装关系。所有叶节点标为 `REFERENCE_UNSELECTED_BARE_PCB`。目的是查看原板形、内部切口与安装孔，并为后续设备选型和安装架设计提供可追溯参考。

原始输入为 `../ecad/ECAD_REFERENCE_CARDS.json` 指向的四块实际 KiCad PCB；合同 `../inputs/pcb_reference_contract.json` 绑定实际 PCB、原理图、静态提取器、既有参考卡和包装筛查的 SHA256。构建前重新静态提取板框、孔与板厚，逐字段对照已执行记录，缺失、未闭合或不支持的几何直接拒绝构建。不会用预算矩形替代真实轮廓。

全部 156 条 Edge.Cuts 线/圆弧形成 10 个闭合轮廓：PyCubed 主板 1、PyCubed 电池板 1、OreSat 背板 3（含 2 个内切口）、OreSat 太阳电池板 5（含 4 个内切口）。实际建模保留这些轮廓与 26 个已证安装/板框钻孔，板厚分别为 1.5748、1.5748、1.7702、1.646 mm。26 孔包括 16 个 plated thru-hole pad 和 10 个 NPTH；按来源钻孔直径表示，不模拟镀层或保证成品孔径。

源文件共 3,649 个 pad drill / via 记录，已经包含本次建模的 26 孔；其余 3,623 个未建。四板分别为：主板 511 总记录 / 4 建模 / 507 未建，电池板 85 / 4 / 81，背板 1,854 / 10 / 1,844，太阳板 1,199 / 8 / 1,191。不是制造级完整裸板，铜层、微孔、元件、层压结构、电气连线均未实体化。

坐标单位为 mm。保留原 PCB XY 原点，将屏幕式 `(x, y)` 转为局部 CAD `(x, -y, 0)`，板厚向 `+Z` 拉伸到原始厚度。这个二维坐标转换不冒充刚体变换。各板再使用合同记录的独立 `T_DISPLAY_LOCAL_mm` 平移，四板按 2×2 排列，外包络轴向最小分离 25 mm；这只是审阅摆放，不是卫星安装坐标，也没有臆造配合或支柱。

构建器执行后要求每板有效、闭壳、单一正体积实体；逐个真实圆柱孔测量实际壁面的轴、孔径、面积、厚度跨度，并检查孔圆柱与材料的交集为零。真实截面面积、板厚、局部/摆放包围盒、解析材料体积均核对。阈值为数值核验容差，不是加工公差。STEP 回读和可视检查仍由主执行者串行完成，源码提交本身没有 CAD 验证或制造放行效力。

入口为 `pcb_reference_panels.step.py`，纯辅助源为 `pcb_reference_panels.py`。无 CAD 的预检：`python pcb_reference_panels.py --static-check`。主执行者使用 CAD 技能的 `scripts/gen .../pcb_reference_panels.step.py --write`，随后 STEP 独立回读与快照；`gen_step()` 不自行写文件，实际构建事实只打印到执行日志。没有执行时不得把源码或解析面积称为实体交付。

保持原有 `ELECTRICAL_MECHANICAL_FIT_SCREEN.json` 限制：参考板没有选定，已装元件高度、支柱、连接器插拔、线缆弯曲、真实箱体内腔均未知。本审阅场景不能解除已有计算/配电盒空间 HOLD，不可通过缩放 PCB 来适配预算盒。电气型号、供电/通信针脚、通电、ERC/DRC、制造和航天适用性均未获得新通过结论。许可证沿用原始记录；PyCubed 电池 v01b 的许可证对应关系仍待澄清，不能把该参考转换当作对外发布授权。
