# WP04 数字装配工艺设计 v0

适用配置为本目录 candidate/design_parameters.json 的三态候选。以下是装配工艺设计与验证范围；并无实物装配、上电或释放记录。实际零件、螺纹、预紧、公差和工装未定，不能据此直接加工或带载运行。

| 顺序 | 工序与定位关系 | 数字验证／仍需补齐 |
|---|---|---|
| 01 | 四根主纵梁开孔与清理；从开放端将八个防压套管沿 X 送到对应孔轴 | 本轮对裸纵梁阶段进行保守包络扫掠。实际套管定位芯轴、端部导入、公差及防遗落工装待定 |
| 02 | 预置上下甲板与八角材，再装入端塞、横梁和四柱；暂不封剪力板、设备与活动机构 | 这是工艺顺序约束。甲板／角材完整六维装入路径尚未获得通过结论；不能把孔位匹配代替路径验证 |
| 03 | 上部四跨接板跨过桥板边缘与纵梁；既有柱拉杆延长 3 mm、头侧垫圈上移 3 mm，下端位置保持 | 共享柱拉杆、承压面与实际孔系独立读回；预紧分配／柱压缩／防松待力学输入 |
| 04 | 下部四扩展垫块连接下横梁与下纵梁；四个翼根叉座底板纳入端部竖向（Z轴）紧固叠层 | 局部避让、对偶孔与相邻实体纳入检查。叉座 Ø6.5 让位与原 X144 孔之间的名义净距为 1.13276253 mm，尚无强度许用。翼叶尚不装入本阶段 |
| 05 | 紧固纵梁／端塞的竖向接头；前端轴向螺钉缩短，后端螺钉外移并穿过内侧保留隔框 | 共八端塞，短螺钉避免与竖向螺栓交叉。Ø3.3 底孔与 Ø4 代理的啮合体积标为未建真实螺纹；不得称螺纹合格 |
| 06 | 保持横梁与四个带外翼耳座入位，负 Y 两足叉与耳座／横梁共同紧固，正 Y 两耳座独立紧固 | 两个足叉各用两处沉孔紧固，头顶齐平 Z125.15；底板剩 2.5 mm 未取得承载许用。此时不安装旋转桅杆和枢轴 |

| 09 | 安装设备适配板、导热界面、设备、接插件与固定线束 | 现有设备为预算／包络候选；实际设备孔系、连接器与抽出路径未选型核实 |

| 11 | 双三叶翼与边框／铰链装配，配置 HDRM、展开锁止和活动线束 | 当前叶片／机构关键帧保留；轴向保持、能量／力矩及状态确认硬件尚未完成 |

接口确认应采用合同中的实例 ID、S 系坐标、孔轴和来源哈希。图中的分解滑块仅为观察内部结构的显示变换，不能用于认定上述安装顺序已经验证。

套管验证范围：八条沿裸纵梁的数字直线插入包络已通过；实物公差、导入与临时定位、防遗落和最终保留方式仍待细化。机器审查的上层 unknown 项保留原文，具体通过范围以其八条路径记录为准。

新释放逻辑只为离线合同检查：两站均需有效的锁销退回、盖打开、滑鞋退出与框架折退锁止证据，并附有效时间／故障状态。当前没有真实传感器、时间阈值或驱动硬件，硬件执行许可保持 false。
