# 后续详细设计输入与具体阻塞

本轮先落实真实几何连接，以下项目仍决定工程样机能否完整试装或承载。未知值不由预算盒、显示网格或既有研究 PASS 推算。

| 输入对象 | 所需数据 | 具体影响 |
|---|---|---|
| B601 实装批次 | DM/RS型号、根孔与止口测量、允许支承区、每 link 质量／COM／惯量、失电行为 | 根适配定版、保持接触、实际质量和带载释放 |
| 框架及新接头 | 材料牌号／状态、板型材公差、允许应力、疲劳和表面处理 | 12×12×2 管、3 mm 跨板、7.8 mm 端塞、2.5 mm 沉孔残底的承载／尺寸链；叉座 Ø6.5 让位到原 X144 孔的名义净距 1.13276253 mm 尚无强度许用 |
| 紧固件 | 实际头型、螺纹标准与有效段、等级、垫圈／螺母、扭矩—预紧和防松工艺 | 本轮名义 Ø4 螺栓、长柱拉杆、端塞啮合及拆装工具；4 个旧侧向螺钉代理与柱／梁名义间隙 0 mm，正装配间隙和实物选型未建立 |
| 载荷与地面支承 | 根部六分量包络、q/qdot/qddot、接触载荷、搬运和托持位置 | 接头螺栓群、滑移／分离、孔壁承压、净截面、局部弯曲、连接刚度和局部 FEA |
| 保持器接触／驱动 | 接触垫刚度、摩擦、允许压强、预紧、卡滞载荷、母线与可用能源、执行器力／行程／速度 | 双站反力、拉销力、盖／鞋退出、折退驱动、终位保持和失败处置 |
| 确认信号 | 传感器型号、安装靶标／间隙、阈值／迟滞、延时、断线及矛盾输出 | 释放确认和臂首动条件；当前离线逻辑不能赋予真实运行许可 |
| 线束 | OD、自由段、最小动态弯曲半径、扭转／循环、端接方向、插拔空间 | 臂、翼和保持器运动路径与电缆恢复力矩；不得继承旧 Route-C 数据 |
| 设备／翼 | 实际外形孔系、连接器／热面；翼片质量、铰链／锁止、刚度阻尼 | 设备安装与维护、总质量／惯量、展翼能力及柔性相关 |
| 发射方（后续飞行适配） | 总包络、分离接口基准与孔系、刚度、质量／CG／I限制及环境条件 | 当前开放停放不能当发射收拢；内侧后隔框连接不代表供应方 ICD 已确定 |

在这些输入到达前，仍可继续的数字工作包括：保持器导向端座／轴向防脱／止挡／退出锁止实体设计，后隔框加强肋固定，设备和盖板后装路径，源臂拓扑派生修复与双指／闭体包含检查，线束逐段接口及公差／工艺设计。这些项目保留未完成状态，均不被本轮连接几何的通过结论替代。
