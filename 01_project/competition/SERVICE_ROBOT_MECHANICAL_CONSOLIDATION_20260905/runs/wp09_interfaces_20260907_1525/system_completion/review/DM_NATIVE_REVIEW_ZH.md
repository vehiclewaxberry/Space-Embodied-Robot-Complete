# DM 原生 ABI 与公开型号映射独立复核

结论：最新证据可接受，**155 项独立只读核查通过**。复核只读取文件、检查 ZIP/哈希/源码并独立复算吞吐，没有导入 MotorBridge、执行 DLL、构造控制器或访问硬件。绑定的实际文件 SHA 见 [DM_NATIVE_REVIEW.json](DM_NATIVE_REVIEW.json)。

实际 DLL 执行范围是版本/能力元数据、NULL 指针拒绝，以及未绑定电机的控制器生命周期拒绝路径。没有原生 MIT 编解码或 DM 串行后端执行证据，不能表述为“DM 原生通信或机械臂控制已通过”。普通 Controller 构造在所审源码中只保存通道字符串；脚本未添加电机，也没有调用会立即打开串口/设备的专用构造函数。零物理 I/O 的依据是调用集与源码路径审计，未执行操作系统级设备访问跟踪。

复核提出的一项表述问题已修正：原 `C_state_native_windows_ABI_layout` 实际只测 Python ctypes 侧偏移/大小。最新检查名改为 `Python_ctypes_layout_matches_pinned_repr_C_declaration`，并明确 `native_struct_layout_probe_executed=false`。NULL get_state 提前返回，不构成 DLL 中结构体布局的真实回读。

wheel 与冻结 PyPI 0.5.3 元数据摘要相符；加载 DLL 与该 wheel 的成员逐字节相符，wheel 的 CRC、RECORD 摘要及提取的 Python 文件均验证。相关 Python 绑定与固定源码一致。**这些验证没有提供该原生二进制对应指定 Git commit 的构建证明**；最新回执已正确保留这一限制。

Seeed 固定提交中的型号与 ID 可逐轴回算：前 3 个机械臂关节为 4340P，后 3 个关节及夹爪为 4310；命令 ID 为 1–7，反馈 ID 为 0x11–0x17。这是“6 个机械臂关节加 1 个夹爪驱动”的公开参考，不是七自由度机械臂或用户实物出货绑定。实际减速比、限位和校准仍为空，物理执行禁止保留。
