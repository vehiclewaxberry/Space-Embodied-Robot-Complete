## 4. 优先任务A：针脚级电气设计，不只画系统框图

### A1. 定点绑定实际DM修订

沿现有资料查真实出货版本/安装图/照片或测量，不把开放源码CAD自动当出货ICD。官方仓库公开了多个STEP修订，并明确开放BOM不是最终出货版本。[S1]

只核对影响当前集成的安装基准、孔系、基座加强、线束入口、配套信号/电源分离板、连接器和需保留的原厂线束保持件。不要重建整条机械臂或改accepted运动链。

公开手册可用于发现配置和接口，不能代替本机已安装电机的ID、固件或标定。官方资料给出的推荐地面电源也不是实际任务电流谱。[S2]

### A2. 收口两类供电和两类通信

在现有数据内依次完成：

- RSP地面输出 → 经设计的隔离/保护/监测 → 机械臂外部连接器 → 实际DM输入 → 电源回路返回。
- BPX 8S → 具体P60模块/选件/通道 → 一个实际低功率负载 → 回流；并核对充电/发电接口边界，不靠“8S”推定全部可用电压和能量。
- 现有上位机或控制器 → 确认的CAN适配/物理层 → DM分离板与电机总线。核查拓扑、终端、供电来源、信号参考、隔离、USB反向供电路径、ID与物理速率；不把USB串口速率当CAN位速率，不在各个电机任意重复加终端。
- 控制器 → 实际RS-422物理层 → 推进候选或明确定义的模拟端点。协议不公开时，只关闭已知物理层和模拟器自有协议，不捏造真实推进器命令兼容性。

每条线记录两端设备身份、连接器料号、配对件、插合面/接线面视向、键位、针脚、网络名、回路、线材/接点/屏蔽、额定条件、资料版本、设计/实测状态。未知端点保持未定版，不能自动生成已批准接线图。

供电回流、信号参考地、PE/机壳搭接、屏蔽分别有定义。不能把所有ground网络无条件短接，也不能默认全部浮地。不得未经设计并联RSP与BPX/P60输出。

优先复用现有EDA工具或已有原理图；没有原生EDA条件时，可先形成可读原理图与同源网表，但不要冒充原生EDA/ERC已经通过。无需为了本轮强装新工具或自行设计一套P60/OBC。

### A3. 保护、停止和失效状态必须有电路依据

RSP-500官方2025-09-26资料规定远程RC端开路时输出开启，4–10V控制时关闭。不能把该控制端直接当“断线即停”的安全急停。[S3]

应定义上电/待机/允许运动/停止/故障/复位状态，以及通信中断、控制电源丢失、停止回路断线等情况下能量去向。安全停止涉及受控停止、能量隔离和机械承托；DM是否具有可用制动功能需要证据，不假定断24V后仍保持姿态。

电源额定21A不等于允许全部支路都按21A工作，不等于实际机械臂一直消耗21A，也不证明电源能吸收回生能量。按实际电机/任务资料分析峰值、启动、堵转或受限工况和减速回生；额定值与测量值分列。没有双向吸能规格，不能给RSP回生吸收信用。

保护元件必须与导线、接点、连接器、故障电流和时间特性协调，不只比较单一额定电流。需要回生耗能/箝位时，先完成能量、峰值和温升选型计算，不能把任意TVS写成持续制动负载。

不在本轮接线或通市电。AC侧封装、保护接地及相应工序应由具备条件的责任人按审定设计处理。

### A4. 可运行计算与负控

至少完成一个有真实输入的支路压降、损耗与保护匹配计算。包括去程、回程、连接器及接点电阻，按适用温度/束装/环境选额定条件；处理起动瞬态与静态压降的边界。不得设无依据的统一安全系数或线径。

可用关系：

```text
R_loop = R_forward(T) + R_return(T) + sum(R_contacts)
V_load_min = V_source_min_at_branch - I_case * R_loop
P_loss = I_case**2 * R_loop
```

负控至少覆盖错误针脚视向/极性、漏回流、超连接器能力、漏保护或保护条件不匹配、已存在终端重复添加，以及RC控制线断开时的实际默认逻辑。按适用范围设计，不把所有条件机械塞给每条支路。

## 5. 优先任务B：真实线束与设备安装

### B1. 从已知端点选择实际线材

确定线芯数量、线径、绝缘、护套、屏蔽、外径公差、接点适配与实际厂家弯曲半径。地面样件和飞行候选的材料与工艺分别标记。

当前21mm/6mm仅是中心线数字之比3.5。NASA-STD-8739.4A表7-1对不同类型有3D、6D、10D等不同最低弯曲要求；这不是所有线束统一采用3D的许可。[S4]

先确定适用线束类别、采用标准与厂家约束、半径测量定义，再复核实际路径。内侧半径、中心线半径与动态疲劳半径不得混用。必要时修改转角、导向块位置和束径，不为了保持原路径而反向捏造电缆参数。

### B2. 用真实端接和保持替代仅有的导向

在至少一条已确认支路上落实配对插头/背壳、出口长度、应变释放、线夹/夹块、穿舱护圈、防磨及可拆装空间。确认线束拉力有到结构的路径，而不是只由接点承受；夹紧量不能损坏绝缘。

检查连接器是否能够穿过封闭孔，或者必须先穿线再端接/拆开导向块；不得只因Ø6包络能穿Ø8孔就认定成品线束能装入。

端点定义、工艺余量和实际路由确定后才生成下料长度。区分中心线、服务余量、端部剥线/压接或焊接长度；不得把已建模余量重复相加，也不能统一增加无依据的百分比。

### B3. 只补与功能链有关的责任件

优先处理P60真实PCB孔系、器件支承/连接器插拔反力、A3200对应接口细化是否实际集成、电池本体防窜与绝缘、线束夹点和外部脐带机械保持。

上甲板缺口及上层设备新增不能凭无干涉获得承载信用。按当前样机适用的自重、机械臂反力与插拔/线束载荷评估残余截面、支柱/拉杆和支承；无确定载荷则输出有标签的敏感性，不宣布强度合格。

旧锁止、防脱、后肋等开放项保留；本轮只处理影响当前装配、停止安全或连线的项，其余放现有开放表，避免重新扩张整星机械任务。

## 6. 并行任务C：推进功能与任务能力研究

### C1. 旧MiPS托架与真实推进选型分开

旧MiPS参考继续保留，不因外形可装就冻结飞行型号。商业一体式推进模块的内部罐、阀、加热器和控制器属于供应商责任边界，集成设计可做原理说明但不重复画一套虚构内部实物。自行研制承压推进器不在本轮范围。

### C2. 提取现行任务，最多比较两套有依据的候选

从当前任务/科学输入读取：服务星与目标质量/惯量、抓后组合体初态、所需接近/撤离/稳定/卸载、允许时间、确有要求的移轨、可用质量/功率/体积和操作窗口。不要从旧聊天复制未经本轮绑定的质量。

允许用C-POD这类公开集成RCS作为能力组织方式对照；其官网描述八喷口、集成控制器和RS-422，但不等于已证明能完成本项目任务，也不证明能放进现有共享舱。[S5]

具体主候选/备选分别绑定料号、修订、推力、最小冲量、总冲量、功率、温度、供给条件、命令/遥测与故障状态。NASA资料明确冷气适合小冲量控制但总冲量和较大轨道机动能力有限；必须按任务选择，不能笼统认定所有小卫星任务均适合。[S6]

没有供应商ICD时可做参数研究或有限接口研究，不能给实物制造接口通过信用。两候选都不能支撑需求时，给出应提高的能力或需收窄的任务，而不是选“较好但仍不够”的那个并宣称完成。

### C3. 建立真正的执行器约束

每个喷口的受力方向与位置、组合体质心、姿态、推力上限、最小冲量、占空/响应、共用供给/电源、禁喷与失效进入计算。区分喷流方向与航天器受力方向。

对于给定姿态，静态分配初筛可采用：

```text
w = B(q, r_C) * f
B_i = [d_i ; (r_i - r_C) cross d_i]
```

这是初筛，不是完整捕获与轨道动力学。矩阵满秩不是受限可达性的充分条件；喷口数量少于六也不是任意任务都不成立的证明。任务不要求的自由度不应成为人为淘汰条件。

区分理论时间下界、受限可行分配、积分后资源消耗和时域稳定性。初始角动量统一参考点和惯性系，不能只用目标质量推估，更不能用机械臂内部运动替代系统对外卸载。

最小算例范围：单体、捕获组合体、一个有定义的低剩余推进剂/故障状态。只运行授权的小规模候选分析，暂不重跑全部历史科学仿真。缺喷口方向或任务数据时可以建立输入模式与边界分析，不能虚构本星通过结果。

### C4. 维护空间与羽流是两个不同检查对象

明确当前“服务棱柱”对应连接器、维护端口还是喷口附近预留，不猜用途。

若是地面维护端口，验证拆盖工序、工具、成品插头、线束余量及重新合盖；维护时拆盖可以是合理流程，但必须实际有证据。

若是需要工作时开放的喷口路径，拆地面维护盖不能自动作为飞行操作方案。分别检查实际工作姿态、机械臂/太阳翼/目标相对位置、喷流遮挡和允许禁喷条件。

不要把喷口安装倾角当羽流半锥角。没有羽流/表面限值数据，只标几何保守筛查或未定，不能写热/污染通过。若采用保守锥模型，只能给其明确假设范围内的结论。

### C5. 推进安全逻辑与模拟边界

设计关闭、待命、允许动作、故障、复位状态及命令许可、超时和遥测一致性。软件包发出/收到不等于阀已动作，也不等于产生已知推力。

离线协议模拟可以覆盖通信中断、命令超时、复位、非法命令和状态不一致，但模拟器的PASS不替代真推进控制器、真实阀或推力标定。不得通过工具连接实际阀、加热器或释放器。
