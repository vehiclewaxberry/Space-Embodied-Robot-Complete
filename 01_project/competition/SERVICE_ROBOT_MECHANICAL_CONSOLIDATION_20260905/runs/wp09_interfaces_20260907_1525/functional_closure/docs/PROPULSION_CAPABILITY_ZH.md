## 受约束模型和明确假设

每个喷口的 d_i 是**航天器受力单位方向**，喷流轴向为 −d_i。关于指定共同质心 C：

```text
B_i = [d_i ; (r_i - r_C) × d_i]
B u = [J_linear ; ΔH_C]          u_i：该喷口积分冲量，单位 N·s
0 ≤ u_i ≤ F_i T                单故障关闭：对应 u_i = 0
sum(u_i) ≤ J_module_remaining   总冲量只分配一次
sum(u_i / F_i) ≤ 2 T            假设最多两个喷口等效并发
sum(P_on_i u_i / F_i) ≤ (P_available − P_idle) T
minimize T,  T ≤ T_window
```

P_on 采用未标定的线性平均功率假设：旧 MiPS 每等效开启喷口 4.875 W、总分配 10 W；C-POD 为 2.375 W、总分配 5 W，均另计待机 0.25 W。C-POD PDF 的“两喷口 5 W”只支持此两喷口参考工况，不证明所有喷口组合均允许；旧 MiPS 两喷口限制更是本轮设计假设。实际电源支路分配仍未知，**外置 RSP 未计入星载供电**。阀峰值电流、热控加热、共享供给、允许命令组合与时序还需 ICD。

本模型是平均占空和积分冲量的 LP 松弛，不是可直接执行的阀脉冲程序。MIB 已按正确单位保存；MIB/F 的名义比值为旧型 5 ms、C-POD 50 ms，不能反推实际最短命令或等同阀响应时间。离散脉冲数量、开关时序、温度/压力依赖、推进剂消耗引起的质量变化、姿态传播、耦合控制和软管/热/喷流均未验证。一个 LP 可行解只说明这些**假设约束**下存在平均分配；不是稳定性或任务通过。

两套数值布局都是独立测试夹具，具体每个坐标/方向已写入输入：

- `TEST_ARRAY5_FORWARD_CANTED`：5 个喷口、资源取旧 MiPS 参考；所有受力方向均含正 X 分量，20° 偏转是测试选择，与原厂安装角/喷流角无关。严格要求净平动力冲量为零时，只有零输出，故不能完成这些非零卸载任务。**这不是旧 MiPS 原厂布局失败的证明。**
- `TEST_ARRAY8_CYCLIC`：8 个数学角点，跨度 340×150×70 mm；位置为 (±0.17, ±0.075, ±0.035) m，方向由符号循环构造，资源取 C-POD PDF。它用于满秩、非负可达性和资源敏感性检查，**不是 C-POD 喷口排布，也不是可制造/羽流通过的本星安装方案**。

矩阵的力矩行先除以 0.17 m 才计算无量纲奇异值/条件数。满秩不能替代非负、禁喷、电力、总冲量或时间约束；少于六喷口也不会自动否决一个只要求部分自由度的任务。

## 三类案例的实际计算结果

单体案例用 PATH30 的已分配 I_C 与假设初始 ω=[0,0,1°/s]，得到 H=[−0.006392751326, 0.000296453504, 0.015229746287] N·m·s。只要求该快照角动量卸载、净平动冲量为零，时间窗假设 300 s。

捕获组合体案例只作混合来源敏感性：上述已分配部分加 150 kg 低置信度目标，**假设**目标 COM 为 S=[1,0,0] m、目标体轴与 S 对齐。推得已分配组合质量 170.685271965462 kg、COM=[0.884100959624, −0.001909239077, 0.010350305817] m；惯量按共同质心平行轴合成。H 模取历史 CSV 3.65099，但方向人为设为 S.+Z；**没有重算捕获，也没有将其认作该组合体实际捕获末态**。这里沿用的 3600 s 是历史 PROVISIONAL 窗口。

| 案例 | 五喷口测试夹具 | 八喷口测试夹具：结果/必要耗量 |
|---|---|---|
| 单体已分配子集 | 不可行：正 X 受力锥不能生成非零零净力卸载 | LP 可行，T=27.724236 s，J=0.554484719 N·s |
| 捕获组合体敏感性，全资源 | 同上，不因放宽资源或时间而解除 | LP 可行，T=3328.263252 s，J=66.565265031 N·s |
| 同组合体、只剩 10% 可用总冲量 | 不可行 | 不可行；C-POD 参考剩余 17.4 N·s，增加时间仍不能补回资源 |

低剩余指 **10% 可交付总冲量**，并未假设推进剂质量与剩余冲量必然线性。所有表中时间是固定姿态 LP 模型的时间下界，不能用作真实消旋操作时长。

八喷口夹具在严格零净力下的 Z 轴最大有效力臂为 0.095/√3=0.054848276 m，因此卸载 3.65099 N·m·s 至少需 66.565265 N·s；17.4 N·s 最多对应 0.954359995 N·m·s。零净力时共同 COM 平移项与各喷口合力一起抵消，不能用捕获后质心远移来凭空增加“平衡力偶”的有效力臂。

附加负例：关闭编号 0 喷口（力上限置零，**故障关闭，无泄漏**）后，其活动矩阵秩仍为 6，但上述捕获卸载方向在非负约束下不可达；放宽原资源/时间诊断也不可行。把各喷口推力降至资料 10±2 mN 中的 8 mN 参考值时，需要 4160.329064 s，超过 3600 s。8 mN 不是全寿命/全温度保证下限，这项只是参数敏感性。故障常开或泄漏不是本例，仍须独立模型。

## 当前裁决和精确补充输入

1. **实际 V6 能力 UNKNOWN。** 先提交 V6 随星完整质量与 COM/I_C（含推进剂状态）及捕获组合体 H 的惯性系向量、参考点、允许窗口。当前只知道历史标量，接近/撤离/移轨的正式 Δv 向量和次数仍是 null。
2. **实际器件力旋量 UNKNOWN。** 厂商需提供准确料号/修订的喷口编号、位置、对航天器受力轴、安装变换、允许同时开启组、供给降额、最小脉冲/MIB 与延迟、可用冲量与故障状态；再将假设夹具替换为真实 B。
3. **电力共同限制 UNKNOWN。** 根据信号控制、加热与阀动作峰值绑定实际星载支路；PDU 的低功率选件、当前其他负载与电压范围要一起核对，外部 RSP 不补星载缺口。
4. **工作喷流与维护分开。** 现有服务棱柱只承担声明的维护预留；不能当喷口羽流空间。需喷口/羽流图、半角定义、热/污染表面限值及臂、翼、目标相对位形。拆维护盖不是自动成立的飞行喷放方式。
5. **型号选择继续保留研究态。** C-POD 集成 RCS 可作为下一架构研究入口，但当前包络不能直接替换；真实资料如仍不能满足任务，应增加控制力臂/可用冲量/推力和允许时间，或收窄任务，不能只选择“相对好一些”的器件并宣称完成。

推进控制状态仅定义待实现接口：关闭→待命→许可→受限动作→待命；命令超时、遥测不一致或设备故障进入锁存故障，明确恢复条件后才能复位。真实阀默认态、许可命令和遥测字段尚待厂商 ICD。发送成功不证明阀动作或产生推力；本轮未实现真实协议兼容或操作设备。
