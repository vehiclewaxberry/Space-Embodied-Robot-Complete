## 五、优先工作流 A：储供推进与可实现的任务能力

### A1. 追溯旧资产，不把外形当功能

定点查找历史 TANK、VALVE_PLATE、corner_modules、MAIN_THRUSTER、plume 等资产及预算消费者，映射到当前实际实例。逐个区分：已选真实设备、可核验候选、工程包络、隐藏参考、未集成或仅历史资产。CLASS 不是型号；罐体几何体积不是可用推进剂储量。[P3]

先比较不超过两套架构：一套推进装置兼顾姿轨控/近程任务，和任务确实需要时的 RCS 与主推进分工方案。冷气可作为近程机动与姿控的第一研究基准，温气、电推进或其他方案按实际推力、总冲量、功率及任务时间比较；不因高比冲自动选电推进，也不默认任何冷气系统足够完成捕获后任务。[R1]

可先研究 VACCO C-POD 官方资料的系统组织：八个冷气推力器、储供与电子控制一体、公开流体示意和接口。这是研究参考，不是本星采用决定，也不证明对本星组合体具有足够控制能力。[R5]

### A2. 输出真实的设备和流体接口

候选数据至少覆盖：介质/相态、温度与压力适用范围、干质量/充装质量/不可用余量、推力与供给状态关系、总冲量、最小冲量、响应时间、启动和持续功率、接口协议、安装孔系、外形、端口方向、连接器和维护空间。

以所选架构为依据建立储存—供给—分配—喷口功能关系，落实适用的隔离、调压、过滤、测量、加注/服务接口及热控。并非所有架构都需要相同元件；不为凑清单新增无必要的调压阀或泵。逐段建立端口、接头、管段与管夹关联，区分随星硬件和地面设备。

先做具有厂商资料支撑的安装座、阀板、管夹与喷口支架候选；没有安装尺寸时保留接口范围研究，不伪造承压壳体内部结构。储罐外支承、载荷传递、管路热位移与密封/供给功能分别验证，不能用某个压力边界标准覆盖全部职责。[R9]

### A3. 以实际布局计算能力，不只数喷口

统一星体系；d_i 定义为航天器受到的力方向，而非喷流方向。对给定构型：

```text
w = [F; tau_C] = B(q, r_C) f
B_i = [d_i; (r_i - r_C) × d_i]
```

将非负推力、上下限、供给状态、有限响应、最小冲量、共享供给/功率、故障和禁喷约束纳入可用控制集合。检查 rank 只能作为初筛；满秩不保证受约束指令可达。任务只需特定子空间时，不强行把瞬时六自由度能力当作唯一合格条件。比较力与力矩残差时使用明确的单位和尺度，不能直接比较混合单位矩阵的条件数。

根据实际任务分别核算平移冲量、姿态角冲量、推进剂余量、工作时间与热/电代价；纯平移火箭方程或一个总冲量数不能替代组合体消旋可行性。

建立状态相关禁喷与剩余能力表，关联目标、机械臂、太阳翼、光学面和天线。喷流几何筛查不替代热/污染分析；无来源不指定锥角。不因某一捕获接触阶段设置 FREE_FLOATING/推进关闭，就取消整星推进设计。

在允许范围内，先做一个小型受限分配或资源不足反例，不启动全项目大仿真。真实参数不足时仅做明确标识的示例或范围试算，不能写成当前航天器验证结果。

## 六、优先工作流 B：能源—航电—B601 驱动的真实接口链

### B1. 首先锁定实际 B601/驱动输入，而非先选 EPS 外形

读取实际设备版本、驱动器和手册，核对输入电压范围、持续/启动/峰值电流、机械制动/回馈、通信与控制周期、连接器与针脚、保护、接地、尺寸和热接口。前序研究稿出现的 DC24V 仅作检索线索；未追溯到实际型号前，不将其当成已验证母线合同。[P1][P3]

若驱动和供电最终不能满足当前机械臂任务，提出专用执行器电源支路或任务调整的候选权衡；不把小功率平台 EPS 直接认定为六轴驱动电源。

### B2. 分域，但不凭空指定电压和协议

在同一产品树上定义太阳电池/MPPT、电池与保护、EPS/配电、星务 OBC、任务计算、实时控制、B601 驱动、释放机构、阀/加热器、传感与通信负载。区分逻辑域与大功率执行域，并根据真实接口确定隔离/变换/保护方式。

研究 P60/P80 等公开厂家资料时，不把系统“总功率”替代单路输出电压、电流和保护能力。P60 官方页面的 PDU 可配置输出范围为 3.3–18 V；P80 也有具体通道和配置限制。它们不能只因名义功率较大就被认定为实际 B601 驱动兼容。[R6][R7]

OreSat 可作为卡笼、背板、电源域及设备组织参考，但不能按比例放大 PCB 或不经核验照搬其电压与接口。[R8]

### B3. 至少闭合四项电源检查

建立模式时序负载账：安全/待机、机构释放、接近感知、机械臂运动、捕获后稳定、通信、加热及故障恢复。检查持续功率、峰值与压降、完整任务窗口能量、回馈与故障隔离。

示意计算关系为：

```text
P_bus_req(t) = Σ[P_load_i(t) / eta_i(t)] + P_bus_aux(t)
E_deficit = integral max(0, P_bus_req(t) - P_solar_bus(t)) dt
```

在明确的最不利连续供电区间上积分。P_load 为电气输入而非未经效率换算的机械功率；母线辅助功耗不可重复计入。电池额定容量还应按允许放电深度、温度、寿命和放电效率换算；同时验证后续可充回。额定 Wh、太阳翼面积或一项峰值功率均不能独自证明够用。[R2]

太阳翼应落实电池片/组件候选、有效发电面积、串并联、跨铰互连、遮挡和寿命条件；电池落实固定、绝缘、管理保护、温度与热接口。电机和阀动作时的欠压、停机制动时的可能母线过压、断电后锁止状态，作为本项目待验证问题。[R10][R11]

### B4. ECAD—MCAD 一致

成品板使用同版本数据手册、机械外形/接口控制文件和连接器表，不要求获取厂家不公开的内部原理图。复用开源板应关联同版本原理图、PCB、BOM、器件高度和许可证；自研或改版板需真实电路、封装、布线和规则检查，不能只有裸板 STEP。

每个候选设备至少绑定实际安装基准、孔系、器件与插头高度、插拔方向、线束弯曲余量和热路径。四块现有参考 PCB 继续保持参考身份，除非本轮完成明确的选择与接口验证。

区分星务、视觉计算和实时驱动职责，记录处理器/外部计算机归属、时钟、时间戳、延迟、通信丢失和复位策略。地面 PC 承担的算力不能写成星载能力。

## 七、工作流 C：承接已经完成的几何，做真实机械增量

首先按 WP08 执行单补主枢轴/盖轴轴向防脱、锁销机械捕获，并完成已验证后肋的三态差量集成；这些成熟小任务可以与推进/电气研究交错推进，不能成为本轮全部成果。[P1]

后肋必须按实例替换两件原件、加入八件硬件，不重复加入端框。继承 S 世界系毫米与真实放置，不把其他零件的局部坐标一律当作世界坐标。两站保持机构分别使用各自实际变换，不假定镜像等价。

轴向止退、折叠锁扣、锁销防丢、到位传感与靶标要分别关联真实实体、动作方向、承载方向、故障状态与装入路径；不能仅创建属性名或 fixed=true。已有单向止挡不再误记成“完全没有止挡”。

随后补其余肋、盖板、太阳翼另一端保持、设备托板、连接器/线束端接与工装。新的设备载体和推进支承必须随实际候选接口设计，不先冻结内部卡笼再强塞设备。

不为取得漂亮特征树而重建全部 B601 donor。对新研支架、锁扣、设备托板等责任件保留可修改参数源/合同和关键尺寸；对需要验证动作的局部子装配建立真实运动关系或可追溯驱动关系。固定整星快照可以保留，但不替代连续运动验证。

几何检查必须区分名义接触、实际材料交叠、工具包络、插装路径与运动扫掠。AABB 排除属于筛查，不能计为全量 BRep 布尔。对需要正间隙的通道，零距离零体积接触不算正间隙通过。

每个新责任件交付源/参数、局部 STEP、必要原生件、同源 BOM、基准与装入路径证据。优先局部验证和三态增量回装；不强求反复导出整机大 STEP。关键连接另外记录材料候选、公差、预紧/防松、承压与强度验证状态，未解决的不得冒充制造图定版。[R12]

| 通信/星务 | 天线、收发设备、安装和视场、数据接口、适用任务链路预算、失联/复位/存储策略；未选设备不写成已安装。 |
| 热控 | 电池、驱动、计算机、阀/推进装置的热源与导热路径；真空设计不能沿用地面对流散热结论。[R4] |
| 线束/管路 | 同版本起止端、连接器/针脚或端口、路径、夹点、活动余量、插拔/扳手空间与质量归属。 |
| 状态联锁 | 太阳翼/机械臂/保持器/推进许可的真实输入、未知状态处置及故障后的安全动作；不以几何姿态代替到位信号。 |
| 装配与验证 | 插装顺序、拆装工具、地面支撑、绝缘/接地、材料与工况来源、必要结构/运动检查和后续实物试验方案。 |

同一产品树建立六条关联：承载、电源、流体、数据与时序、热路径、状态许可。每个设备只承担适用的接口，不为所有设备强加六种端口。[P3]

至少分开三套账：历史 accepted 科研模型、当前候选工程干/湿质量与惯量、实际采购/称重/标定记录。未选设备采用有来源范围并标注，不用密度为零“消除”未知质量，也不把几何参考重复计入。捕获后质心和惯量应包含目标的坐标变换与平行轴项；不把新几何质量回写旧 accepted 模型。

## 九、研究支线：用小型可证伪对照连接现有论文

研究假设：实际推力/脉冲、能源、喷流禁用和组合体惯量约束可能改变抓取点或收拢路径的捕后可稳定性。这是待检验假设，不是本任务书已经证明的新颖性。

在现有模型和授权允许范围内，比较“理想连续执行器”与“受约束实际候选执行器”，必要时增加一种资源感知策略。最低代表状态沿用本任务第四节的三类配置；使用同一初态、目标与评价窗口。

评价稳定时间、姿态误差、约束违反、力/力矩不可达残差、能量/推进剂消耗、相机/喷流禁用影响及必要的安全撤离余量；保留失败与排序不改变的结果。机械臂重构只能重新分配系统内部动量，不能被当成不需要外部动量交换的总角动量消除手段。

先交付一个可解释反例或范围分析，不因本任务启动而重做已冻结的 sim_10/11/12 或擅自修改控制参数。新的硬件假设与历史结论分别标识。

## 十、首轮只要求六类成品，不扩张为文档工程

以下名称是建议；本地存在同类表时追加版本化结果并引用原入口，不制造平行真值。

1. 一页实际状态与本轮变化摘要：当前父本、已读取证据、当前允许动作、完成增量、未决关键输入。
2. 原模块表的增量更新：覆盖与六维状态，含责任实例和退出条件，不给无依据的整星完成率。
3. 一份共用设备/接口包：候选、来源、版本、孔系/连接器/端口/热界面及适用状态，分别标候选与已定版。
4. 一组可复现预算和小检查：模式功率/能量、候选干湿质量/质心/惯量、推进能力/禁喷或一个明确反例；附输入来源与运行范围。
5. 一个真实 CAD 增量包：优先完成后肋回装及有效授权内的防脱/锁销；具备资料时补至少一个新电气设备载体或推进安装组件候选。资料不足时不造件，明确精确缺项，同时继续另一条可执行设计链。
6. 一份首轮验收记录：新增/替换实际数量、依赖/变换/几何检查、公开资料选择结论、尚未完成的功能/运动/强度/实物验证，以及唯一下一批具体工单。

第一轮必须同时有推进研究和真实供电/驱动接口结果，不能只交后肋文件或一份新的审计报告。设计结果可以是“在已知约束下排除某方案”，但须有证据和下一候选，不以长期 UNKNOWN 代替推进。

阶段完成按用途判断：几何替身可按尺寸用途完成；功能模块须有确定实现、适用接口、集成及该阶段必要验证。整体 CAD 能打开、统计数量增加、资料齐全均不能单独支持制造/通电/承压/飞行放行。
