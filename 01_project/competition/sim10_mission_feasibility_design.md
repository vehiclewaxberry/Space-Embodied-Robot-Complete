## 1. 物理链与门序（全部来自已验证求解器）

```
目标状态(ω_t, I_t) ──rigidize()──▶ ω⁺, |H_c|          [sim_06 已验证, 25/25]
                                      │
              门1: 捕获后转速  |ω⁺| ≤ ω_budget (2°/s, registry)
              门2: 轮组容量    |H_c| ≤ n_w·h_w            [sim_08]
              门3: 推力器冲量  J_req = |H_c|/l_T ≤ J_avail [sim_08]
              门4: 消旋时间    t_d = |H_c|/τ ≤ t_max       [sim_08]
```
共轴近似下的解析骨架（用于闭式边界，与精确解对照）：
`ω⁺/ω_t ≈ κ_ω = I_t / (I_t + I_s + ΔI_Steiner(μ, 几何))`，`|H_c| ≈ I_t·ω_t`（μ 大时目标主导）。

## 2. 无量纲参数定义（Part 1 交付）

| 符号 | 定义 | 物理含义 | 备注 |
|---|---|---|---|
| μ | m_t/m_s | 质量比（用户指定主轴） | 本项目两锚点：卫星 0.92、碎片 6.25 |
| ι | Ī_t/Ī_s | 惯量比（真正主导 ω⁺ 的量） | 碎片 ι≈211——μ 与 ι 经几何类别映射 |
| ω̂ | ω_t/ω_budget | 翻滚率/预算比 | 门1 的直接变量 |
| h* | I_t·ω_t/(n_w·h_w) | 目标角动量/轮组容量（用户 h*） | h*≤1 = 轮组可消化 |
| j* | J_avail·l_T/(I_t·ω_t) | 可用/所需推力器冲量比（用户 j*） | j*≥1 = 推力器可消化 |
| λ | r_g/L_t | 抓点杠杆比 | 控制 r×mv 耦合与 Steiner 增量 |
| α | 速度匹配度 | 0=直撞, 1=完全同步 | E16 已证 α 改冲量不改 ω⁺ 可行性 |

几何类别映射 ι(μ)（避免 μ、I_t 双自由度撒谎）：三类等密度缩放

G2 立方星本体（按 target_satellite_v0 标定）、G3 致密紧凑体。两锚点必须精确落回 sim_06 数值。

## 4. 边界与区域定义（Part 3 交付）

区域标签（fail-closed，颜色语义沿用 fig_v07 纪律，不做红绿二分）：
- `WHEELS_ONLY_FEASIBLE`：门1∧门2 通过（无需消耗推进剂）
- `THRUSTER_REQUIRED_FEASIBLE`：门1∧¬门2∧门3∧门4
- `INFEASIBLE_RATE`：¬门1（捕获后转速超预算——REPEAT_CORE 的 binding）
- `INFEASIBLE_RESOURCE`：门1 通过但 ¬(门3∧门4)
边界=区域交界等值线；**双层绘制**：解析近似边界（虚线）vs 精确矢量解边界（实线），
两线偏移量即 CL02（标量/简化模型误差）在任务级的放大呈现。
