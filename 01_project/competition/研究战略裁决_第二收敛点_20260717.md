## 1. 首先修正三处事实口径（引用时按此为准）

1. "P1: ω⁺=3.06°/s" 不是 sim_09 的独立结果——3.06°/s 是 **sim_06 名义锚点**，
   sim_09 e0 锚定复现（3.0633，容差内）。正确的说法是：sim_09 72 例网格中
   **69 例操纵度同为 sqrt(det JJᵀ)=0.0065596，捕获后角速率却散布 1.489→3.06°/s
   （≈2 倍）**——同一几何指标值下动力学结局翻倍，这才是"几何≠稳定性"的机器证据。
2. G4 失败的精确指纹（比"模态能不收敛"更有信息量）：A2 捕获活跃窗内，
   **基座角速率 m2/m4 vs m3 差仅 2.0e-6/9.5e-7，tip 挠度差 0.73%/0.10%（已收敛），
   唯独帆板模态能峰值差 2.78%/1.27%**；rtol 扫掠全收敛（1e-9 级）。
   即：**任务可行域关心的量（基座角速率、动量分配）已经模态收敛，未收敛的只是
   帆板自身的能量指标**。这直接决定了下文的论文解耦策略。
3. sim_12 动量塑形必须先过动量记账关（见 §5.2）：自由漂浮下臂运动**不能改变系统
   总动量**，只能重分配；真正的"预置"必须动用执行器（轮组预偏置/推力器），而
   sim_08 已证轮组容量仅为需求的 1/12（0.3 vs 3.65 N·m·s）——这个 8% 预置能带来
   多大改善本身就是一个定量问题，不设计清楚会被 Reviewer #2 以"违反动量守恒"击杀。

### 2.2 Paper 1 定义

- 中文：**考虑柔性附件耦合的非合作航天器捕获任务可行域分析**
- 英文：Capture Feasibility Boundaries for Non-Cooperative Spacecraft with
  Rigid-Flexible Coupled Servicer Dynamics
- 投向：Acta Astronautica（一投）/ JGCD（备选）
- 论文脊柱（每章一个机器裁决支撑）：

## 3. 判断二：G4 = 方案 B 为主，方案 A 作诊断证据，方案 C 延后

### 3.1 物理根因（为什么"只有模态能不收敛"）

理想冲量（Δt=0）频谱平坦，每阶模态注入能量 ∝ (B_t,i·J)²，而悬臂模态动量系数
衰减缓慢（实测 B_t = 0.462/0.256/0.150，≈1/(2i−1) 律），能量级数收敛慢——
**m=5 预计仍差 ~0.7%，m≈6 才勉强过 1% 门槛，且收敛到的是一个非物理理想化的值**。
真实夹爪闭合 10–100 ms，对 >1/(2Δt)=5–50 Hz 的激励指数衰减；本模型
模态频率 1.0/6.3/17.6 Hz（4 阶 ≈34 Hz、5 阶 ≈57 Hz），Δt=20 ms 即天然截断
4 阶以上。**模态能不收敛不是模型错，是 Δt=0 理想化与能量指标不相容——
机器 Gate 抓住了一个适定性问题。**

### 3.2 三方案裁决

| 方案 | 裁决 | 说明 |
|---|---|---|
| A 提高阶数 m=5/7 | **只作诊断，1–2 天** | 慢收敛曲线本身是"理想冲量不适定"的证据图；不作为修复手段 |
| B 有限接触带宽 | **主修复，1 周** | 等冲量半正弦力脉冲（或 Kelvin-Voigt）替换瞬时 Delassus 冲量，扫 Δt∈{5,10,20,50,100} ms；预测：Δt≥20 ms 时 m=3 即收敛过 1%；动量传递不变（冲量定理），只有能量分配变。硬件锚点=B601 夹爪闭合时间。**正合已冻结待办 1 的"有物理依据的捕获带宽/接触柔顺性"** |
| C 混合保真 FFR/ANCF | Paper 2 核心，9 月后 | 切换面动量/能量一致性 + e15 级再认证工作量大，6.5 周内是排期毒药；但"自适应保真捕获仿真"是 Multibody Syst. Dyn. / JSV 级方法贡献，sim_07+e15 已备好 ANCF 锚 |

### 3.3 叙事资产

Paper 1/2 都写进一句话：**"我们的机器裁决 Gate 拒绝了理想冲量下的模态能指标，
迫使模型引入接触带宽——这是验证体系工作的直接证据。"** 大多数论文给不出这种
可信度叙事。

### 4.1 sim_10 任务可行域（实现，不再只是设计文档）

- 输出：逐格 {FEASIBLE_WHEELS / FEASIBLE_THRUSTER(ΔV) / INFEASIBLE(原因)} +
  机器 Gate（锚点格必须复现 3.06°/s、3.65 N·m·s；与 sim_09 72 例逐格一致）。

### 4.2 sim_12 动量预置捕获（Momentum-Biased Capture）

- **先过设计评审再写代码**，核心问题：预置动量从哪来？
  - S3a 轮组预偏置：容量上限 0.3 N·m·s = 需求的 8%（sim_08）——定量回答
    "8% 预置换多少捕获后角速率改善"；
  - S3b 臂摆预整形：不改总动量，只改接触瞬间基座姿态/速率与瞬态载荷——
    效果计入瞬态而非终态，须如实标注；
  - S3c 推力器辅助预置：与消旋预算合并核算。
- 对比阵列：S1 被动 / S2 速度匹配（e16 口径，注意其 REPEAT_CORE 未闭环，
  引用需先补认证）/ S3a/b/c。Gate：总动量记账逐项闭合（约简精度），
  这是本模块的科学诚实生命线。

## 5. 判断四：比赛展示路线（H0–H3 不变，叙事升级）

三层架构，展示"Mission Intelligence"而非"抓取"：

1. **数字孪生层**：sim_11 耦合模型 + 动画可视化（现有 CSV→3D 回放）；
2. **Physics Agent 层（MCP）**：工具 = `query_feasibility`（sim_10 预计算 Ω +

   `plan_detumble`（sim_08 预算）；Agent 输出 EXECUTE/ABORT 且**理由字符串
   直接引用机器裁决 JSON 字段**——"AI 的每个决定都有一个 gate_check 背书"；
3. **B601 硬件层**：H0 资格→H1 执行→H2 视觉→H3 Agent 闭环；演示流程即用户
   拟的 150kg@3°/s → INFEASIBLE/ABORT → 0.5°/s → EXECUTE → B601 执行。
- 诚实边界（材料里主动声明）：地面固定基座不能验证自由漂浮动力学；硬件验证的
  是决策-执行链，动力学可信度由 Gate 链承担。

**红线维持**：不做端到端 VLA、不做无物理约束 Agent、不做 RL 控制。

## 6. Reviewer #2 风险清单（按杀伤力排序）

1. **帆板占位质量 0.348 kg（真实 2–5 kg/m² → 差 5–10 倍）**：真实参数下柔性
   耦合系数、振铃幅值、甚至"A1 柔性可忽略"结论都可能翻转。对策：杨恒参数卡
   列为关键路径（本周催）；拿不到就以帆板/整星质量比 μ_p 无量纲扫掠呈现，
   把结论写成 μ_p 的函数而非单点断言。
2. **瞬时冲量理想化**：方案 B 直接消解，并反转为贡献点。
3. **"可行域=参数扫掠"**：必须有半解析判据 + 边界主动细化；扫掠只作验证。
4. **"FFR+浮动基座是教科书"**：贡献定位在可行域判据与验证链，模型只是工具；
   退化链 Gate（19.20°/92×/sim_01）是防御工事。
5. **操纵度退化是否网格设计使然**（69 例同名义位形）：补跨位形案例，或明写
   "同几何异动力学"正是实验设计意图。
6. **认证链未闭环处不得引用**：e15 `REPEAT_ANCF_CERTIFICATION`、e16
   `REPEAT_CORE`、sim_11 `G4 FAIL`——论文引用链里任何数字都必须来自
   verdict=PASS 的 JSON。
7. **无在轨/微重力实验**：定位为"仿真+地面决策链验证"，不过度声称。
