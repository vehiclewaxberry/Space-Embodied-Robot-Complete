## 3. 主要公式与理论

**3.1 无力矩刚体姿态(sim_01/02, rigid_body.py)**
欧拉方程 + 四元数运动学，DOP853 积分(rtol 1e-10)：
`I ω̇ = -ω × (Iω)`，`q̇ = ½ q ⊗ [0, ω]`

**3.2 臂-基座反作用与广义雅可比(sim_05, dynamics.py)**
系统动量矩阵分块，零总动量下基座速度反解：
`p = H_bb V_b + H_bm q̇` → `V_b = -H_bb⁻¹ H_bm q̇`
广义雅可比：`J_g = J_m - J_b H_bb⁻¹ H_bm`，末端速度 `V_ee = J_g q̇`

**3.3 捕获瞬间塑性冲量(sim_06, capture_impulse.py)** —— 对**组合体质心取矩**，含平行轴 + r×mv 耦合（Dimitrov-Yoshida 规范）：
```
r_com = Σmᵢrᵢ/M,  v_com = Σmᵢvᵢ/M                      (线动量守恒)
H_pre = Σ[ Iᵢωᵢ + mᵢ(rᵢ-r_com)×(vᵢ-v_com) ]
I_comb = Σ[ Iᵢ + mᵢ((dᵢ·dᵢ)E - dᵢdᵢᵀ) ],  dᵢ=rᵢ-r_com   (Steiner)
ω⁺ = I_comb⁻¹ H_pre,   ΔT = KE_pre - KE_post ≥ 0        (塑性耗散)
```
3-DOF 点捕获(球铰只传力不传力偶)：Delassus 矩阵 `(K₁+K₂)J = v_p2 - v_p1`。
**标量简化式** `ω_c = H/(I_s+I_t+I_arm)` 丢弃 Steiner 与 r×mv，全网格低估 2.9–12.3%。

**3.4 ANCF 柔性梁(sim_07, ancf_beam.py)** —— 平面梯度缺失单元，Berzeri-Shabana 弹性力：
`U = ½∫EA·ε² dx + ½∫EI·r''·r'' dx`，`ε = ½(r'·r' - 1)`（弯曲线性、轴向非线性，大转动零应变）
刚度按目标一阶频率反定(D-4)：`f₁ = (β₁²/2πL²)√(EI/μ)`，β₁≈1.875，包络 f₁∈{0.7,1.0,1.3} Hz。

**3.5 消旋执行机构预算(sim_08)** —— 反作用轮只重分配、外力矩才能移除总角动量：
`τ = |H_c|/t_d`，`F = τ/(2 l_T)`，`J_thr = |H_c|/l_T`，`m_p = J_thr/(Isp·g₀)`

**3.6 抓取后可稳定裕度 M_PCS(sim_09, 项目定义指标)**：
`M_PCS = min(1 - H_req/H_max, 1 - J_thr/J_max, 1 - E_flex/E_max, 1 - |ω⁺|/ω_max, 1 - Δθ_b/θ_max)`
`M_PCS > 0` 全资源有余量；用鲁棒分位 `Q₀.₀₅` 表达不确定性下的最小裕度。

**3.7 同步捕获低冲量目标(e16)** —— α 速度匹配 + 归一化冲量目标：
`min sqrt(0.5·((J_lin/J_lin_G0)² + (J_ang/J_ang_G0)²))`（对 G0 归一，防守恒量舍入误排序）

**3.8 系统级抓取评价指标(设计, 未闭合)**：
`Sᵢ = w_g·Q_geom - w_b·Δθ_base - w_j·|J| - w_f·E_flex - w_a·C_act - w_u·R_unc`
采用三级决策：硬约束筛选 → Pareto 排序 → 任务上下文选择（**不用加权总分作主结论**）。

## 7. 与同伴讨论的关键决策点

1. **是否把"不可行性边界"作为核心创新点之一**？当前 REPEAT_CORE 不是负结果——"用完整证据链量化证明当前构型下捕获-消旋的物理不可行边界，并给出使其可行的设计条件(质量比/预算/低翻滚率窗口)"本身是强论文/答辩叙事。
