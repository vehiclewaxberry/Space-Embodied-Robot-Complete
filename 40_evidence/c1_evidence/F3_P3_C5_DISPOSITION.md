# F3-P3 C5 翼板超宽 12mm 候选处置

**文档编号：** `F3-P3-C5-DISPOSITION-20260805`
**生成 UTC：** 2026-08-05
**状态：** `CANDIDATE_C_MODE_B_ONLY`
**前置：** F3-P3 T_SM 双轨裁决（Mode A/Mode B 保留）

---

## 1. C5 问题现状

| 项 | 值 | 来源 |
|---|---|---|
| 收拢包宽 | 238.3 mm | `CODEX_CONTINUATION_RECONCILIATION.md` §3 |
| 可用宽度 | 226.3 mm | 12U 标准 |
| 超宽 | **12.0 mm** | 计算 |
| 翼根机构下限宽 | 302.3 mm（双侧达 \|Y\|=151.15） | 同上 |
| 状态 | `NEGATIVE_PRESERVED_NOT_CLOSED` | 禁止隐藏/减薄/移动制造假通过 |

---

## 2. 三选一候选

### C5-A：翼板/盒体减宽

**方案：** 改变板宽、边框、铰链或堆叠结构，使收拢包宽 ≤ 226.3 mm。

**影响：**
- 必须重新检查刚度、质量和展开机构
- 可能影响太阳翼功率输出
- 可能影响展开扫掠路径

**状态：** `CANDIDATE`

---

### C5-B：翼板安装位置或铰链轴迁移

**方案：** 调整盒体、铰链座或展开方向，使收拢包宽 ≤ 226.3 mm。

**影响：**
- 必须重新检查机械臂收拢走廊和展开扫掠
- 可能影响航天器质心
- 可能影响部署器兼容性

**状态：** `CANDIDATE`

---

### C5-C：仅 Mode B 接受

**方案：** 明确 Mode A（标准 12U 部署器）不满足部署包络，仅 Mode B（外部服务模块）接受当前翼板宽度。

**影响：**
- Mode A 不可部署
- Mode B 可部署，但需自定义部署方案
- 不能写成通用整星合规

**状态：** `SELECTED`

---

## 3. 裁决：C5-C（仅 Mode B 接受）

**理由：**
1. **翼根机构下限宽 302.3 mm 是不可消解的物理事实** — 双侧达 \|Y\|=151.15，机构硬件已存在
2. **减宽（C5-A）或迁移（C5-B）都需要重新设计翼板机构** — 这超出 F3-P3 范围（F3-P3 只装配，不重新设计零件）
3. **T_SM 双轨已保留 Mode A/Mode B** — Mode B 包络更宽（340.5 mm），可容纳 238.3 mm 收拢包宽
4. **项目当前 profile 已是 340.5 × 226.3 × 226.3 mm** — 与 Mode B 一致

**结论：**
- **Mode A（标准 12U）：** C5 超宽 12 mm → `NON_COMPLIANT`
- **Mode B（外部服务模块）：** C5 超宽 12 mm → `ACCEPTABLE`（Mode B 包络 340.5 mm > 238.3 mm）
