# WP03 整星回装：来源与接口记录

本文件支持本轮完整随星总装设计。定向读取范围为WP01设备/翼/坐标/接口、WP02可回装根部、R2太阳翼入口和已有姿控/推进任务来源；未运行CAD、仿真或硬件。当前用户授权本轮候选设计，附件是设计建议和待办来源，旧文件中的历史授权字段保留其原范围，不作为本轮停止设计的条件。原文件均未改动。

机器可读取值、原始候选字段、来源哈希和读取范围集中在 [source_register.json](source_register.json)。其中质量估算、预算、原始厂商引用和实测严格分开；本轮没有新增实测或重新核验所有旧设备产品网页。

## 太阳翼来源选择与真实差异

现行R2发布入口是 [11_SOLAR_R2_MECHANISM.yaml](../MECHANICAL_ENGINEERING_RELEASE_R2/11_SOLAR_R2_MECHANISM.yaml)，指向 [ecr_solar_array_r2](../F3R2_M7_MECHANICAL_FINAL_DESIGN_CLOSURE_V1/ecr_solar_array_r2/)。它包含已有小体积STEP、FreeCAD源、独立运动学、构建/质量/机构/线束记录；不能因WP02未显示翼而视为没有翼资产。

| 来源版本 | 几何/轴线 | 与WP03的关系 |
|---|---|---|
| WP01当前简化翼 | 两翼各一板320×195×5 mm；根轴X平行、y=±125.15,z=-103.15；每侧x=±120的Ø16×16铰链包络；每翼0.4 kg预算 | 直接回放WP01参考姿态时保留；这是新分配，不能冒称R2完整三叶翼 |
| V5 R2B窄三板 | 每侧3板，X长度227、节距56.6667、厚6；根轴y=±143.15,z=0；各逻辑关节0–90°正交折叠 | 历史不同接口。轴点x=-40/-61沿同一X轴，不是轴线横向漂移；不能与R2手风琴式0/180°相混 |
| R2当前重发报告V2及运动学 | 两翼×3叶，每叶300×200×2.5；收拢层间隙0.5；根轴X平行、y=±115.4,z=-108.15；根0→90°、叶间0→180° | 完整三叶翼复用的现行来源；前置臂时代的净空结论不能转授到屋顶臂配置 |

R2旧GEOMETRY_V1、HDRM文字和运动学行尾注释还写114.9 mm；当前常量`113.15+1.0+2.5/2=115.4 mm`与BUILD_REPORT_V2一致。1.0 mm根台肩设计依据是`SOLAR_STANDOFF_DATUM_FEATURE_V1.yaml`，替换了旧0.5 mm设置；本轮记录来源冲突，不改历史文件。R2参数化脚本仍以340.5 mm母线作历史背景，WP03用366 mm核心后必须重新连接根耳/框梁。

R2展开翼尖y=±715.4 mm，双翼跨度1430.8 mm；三叶收拢外侧|y|=122.65，z=-108.15…91.85。R2每翼0.78 kg预算由3×0.18 kg叶片、0.05根铰、2×0.03叶间铰、0.08 HDRM、0.05翼线束组成。若本轮铰链/线束按真实零件计质量，应替换这些分项，不再叠加整翼0.78 kg。

**R2源STEP同时包含STOWED与DEPLOYED两套叶、铰链/HDRM禁入体和WITNESS_BUS_PROXY。** 必须按名称/配置筛选，不能把整个compound直接作为一个服务态硬件实例；禁入体不参与实体体积质量，见`SOLAR_ARRAY_R2_BUILD_REPORT_V2.json.shape_metrics`。

R2已有随星HDRM功能方案是每翼两处向内退回星体套筒的拉杆，站位x=[-140,-120]/[120,140]、z=[-20,20]mm；释放后|y|<113.15。弹簧、阻尼、止挡、锁闩与驱动器仍是候选/缺实选，旧0.05 N·m驱动力矩、0.12/0.24 J止挡能量属于有条件分析，不能直接转为WP03通过。翼线束较晚硬件记录给根环293.3 mm、叶间75.7 mm候选及x155 mm通道；早期110/40 mm不是现行形状所用长度，且供应商动态限制仍未绑定。

## 任务面、发射接口与推进

任务方向沿原+X：WP01体相机35×42×36 mm、中心[201,-72,62]mm，镜头可视圆柱轴沿X。它只证明几何放置；相机光学外参、FOV、焦距、标定和视场遮挡未实现。旧frame文件规定光学+Z_C为视轴，WP03应建立`T_S_C`使+Z_C映射到所选+X_S观察方向，不能用未登记的“同轴”文字代替。

太阳翼绕X轴展开，展开后面板大体位于XY面；历史LEFT=+Y而坐标文档又说+Y朝right，统一用带符号侧别。散热候选面、天线与星敏方向没有WP01最终数值：可以保留可替换安装面和热带落点，需记录臂/翼遮挡及发射接口冲突。散热器面积、辐射率、热流和设备功耗仍为null。

发射接口只有Stage1 `rail-reference`临时候选和WP01 IF-001“后端接口面/法向/T_S_SEP”的需求。所读现行文件未给指定部署器型号、分离环或接口孔系。WP03可以将后端-X面（核心端面x=-183 mm）登记为**新结构保留区**，经端框连接主梁，并把供应方对偶、孔系、承载/紧固、包络及方向列TBD；这不是已存在的合格部署器接口。该保留区与F4R1后面天线/推进候选共面，必须重新分区，不能重叠占用。

任务源已含交会接近、抓取后消旋与外部动量排出需求：sim_08用推力偶作粗消旋、轮组作精稳定，sim_10沿用0.1 N、0.17 m力臂、Isp60 s及0.300 N·m·s轮组档作为冻结研究假设。它们没有实际喷嘴/阀组/安装几何，也没有尾流、质心漂移或晃动。F4R1的4×30 mN·m·s轮组与旧3×100 mN·m·s研究档不同，不能继承旧控制/消旋能力。推进候选空间及电源/数据/热接口可以回装；喷流禁入角、推力方向、数量、供压、工质、Δv和实际整星质心未明确时保持null，不声称全自主在轨服务已闭合。

## WP02回装分类与留下的连接缺口

WP02最终收据确认为79项零件号、56份定制STEP、每态224实例/224实体。用途账是41个ONBOARD候选、81个GSE、102个标准件几何；标准件尚未分产品归属且质量未分配。按当前生成器根段和实例前缀，72个标准件属于根结构、30个属于GSE；机器记录保留逐实例映射依据，不能将全部标准件并入随星。

可回装随星根结构：纵梁、端框/端塞、桥板、上下梁、四柱/端塞/底垫、M3R A/B，以及对应M4/M5/M6标准件几何。根部线束outrigger、spacer、connector slide、mast也被WP02归ONBOARD，但接头尾壳未绑定，仍需检查真实父接口和紧固路径。

**分类冲突：** WP02两半`WP01-HB-SPLIT-CLAMP-LOWER/UPPER-R2`用于固定根部电缆，但生成器未传用途参数，继承默认GSE；对应外伸板/垫块却是ONBOARD。WP03不能仅筛ONBOARD后宣称根部线束已固定。保留原分类记录，按本轮真实安装用途重新设计/登记两半夹件及螺钉的父接口和适用线径，不继承其资格或夹持能力。

高柱、公共吊梁、脚座、560×600底板、支承/上下垫、Y导轨/载台/手动丝杆/俘获销均属于原GSE实现。其功能可用于随星保持概念，安装、驱动能源、接触、退出和载荷路径必须重新建立。原48/12/30/180 mm序列依赖人工和独立托持，不能转换成在轨机构证明。

WP02根部柔度模型把四柱下端理想固定，桥/M3R为刚性耦合；它是地面试件比较，不是完整星体到发射接口或在轨自由体的验证。去GSE参考装配仍可保留臂根连接，但中段保持/支承与释放机制不再随之成立。该缺口应由WP03随星保持新件及明确未完成项表达。

## 本轮可直接采用的登记规则

每个实例独立登记`product_role / representation_role / qualification_status / source_revision / parent_assembly / mount_interface / configuration / mass_source / mass_owner / evidence_scope`。数字来源都没有实物资格新增，默认`qualification_status=NOT_EVALUATED`。WP01总分配16.38499018865684 kg和旧31.022864807342987 kg均不作为WP03总质量；从唯一质量所有者重新求和，GSE、目标和同时态几何排除。源与差异登记完成后继续本轮CAD回装，具体实体连接、扫掠、质量与新增件以WP03实际生成结果为准。
