# F3R2 T_SM 物理坐标栈（冻结）

```text
spacecraft +X  ---------------------------------------------->

  x=185.25      M_FRAME  (B601 动力学/URDF 基准原点，无实体)
     |  +12.75 mm
  x=198.00      Adapter_Plate 外端面
     |  +10.00 mm
  x=208.00      Central_Boss 实体安装面  <-- 螺栓贴合面
     |  +2.41 mm  (G3-1 基座接口适配器占据)
  x=210.41      B601 base flange (8 x M3, 节圆 R45.18)
```

## 裁决

`T_SM = 185.25 mm` 是**航天器系 → B601 动力学基准系**的变换，
**不是**法兰面位置。实体安装面在 `x = 208.00`，二者相距 22.75 mm，
由基座接口适配器实现。因此 185.25 / 198 / 208 三者同时成立，
不再作为冲突尺寸描述。

## 后果

- 已冻结的 F3R2 臂**不平移**，姿态与间隙结果全部保留；
- 动力学与控制取 185.25；
- CAD 配合与螺栓载荷路径取 208.00；
- 适配器把二者刚性连起来。
