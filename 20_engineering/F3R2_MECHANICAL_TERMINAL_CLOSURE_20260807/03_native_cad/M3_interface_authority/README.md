# M3 interface-authority recovery

This directory contains additive, post-M2 evidence for the measured B601
competition interface and the spacecraft-side adapter patterns. Historical
G30/G31 evidence is preserved unchanged; corrected measurements and the M3R
decision supersede only the claims explicitly listed here.

The controlling adapter candidate is **Rev B**. It provides a full 8.0 mm
Stage-A M5 bearing zone, matching diameter-5.5 through clearances in both
parts, and one asymmetric dowel-hole candidate at `(55, 0) mm`. The dowel
removes the former 45-degree geometric ambiguity, but its fit/tolerance and
physical fit-up remain HOLD. The M6 net edge margin is only 6.7 mm and the
live mating load bridge has not been verified. FreeCAD/STEP geometry is
therefore PASS_WITH_EXPLICIT_HOLDS; SolidWorks native closure remains HOLD.

No file in this directory claims an OEM flight interface, flight
qualification, launch qualification, or a formal fastener margin of safety.
