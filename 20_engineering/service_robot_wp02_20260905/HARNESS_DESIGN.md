# WP02 根部与关节2定长线束候选

已生成26个姿态下、固定材料端点和固定自由长度的两条线束中心线，并选择**恒曲率圆弧用于CAD展示**：根部半径50.590 mm，关节2半径56.022–60.541 mm。旧二次Bezier的关节2最小半径仅7.028 mm，作为曲率集中反例保留。真实外径、动态弯曲半径、连接器出口方向和扭转限制均未知，**本结果不能判定线束弯曲合格**。两类曲线都只是几何构造，没有求解电缆力学平衡。

## 数据与CAD接口

运行 `python harness_analysis.py` 生成 `results/HARNESS_ANALYSIS.json`。数据顶层 `poses` 有26行，每行按 `loops.root_service_loop` 和 `loops.joint2_loop` 保存。两者的 `selected_model=constant_curvature_candidate`；**CAD必须读 `poses[i].loops[name].constant_curvature_candidate.centerline_points_mm`**，旧层级的同名字段仍是被否定的Bezier反例，不能误读成当前展示候选。

恒曲率子节点保存：

- `centerline_points_mm`：101个等弧长材料点，点号 i 对应固定材料坐标 s/L=i/100。
- `centerline_points_61_mm`：61个材料点，s/L=i/60。
- `center_mm`、`radius_mm`、`chord_unit`、`normal_unit`、`arc_angle_rad`：精确圆弧重建参数。Bezier旧层级仍保存三个控制点，不覆盖。
- `min_curvature_radius_mm`、端点切线变化、解析包络和 OD=4/6/8/10 mm 的代理包络。

所有点均在星体S系、单位mm。101点折线本身稍短于解析曲线，差值另存于 `polyline101_minus_analytic_length_mm`；不能把折线长度差当成线束伸长。固定弧长材料采样避免了在每姿态随意重新编号控制点造成的虚假材料滑动，但没有定义电缆截面的材料转角。

同一关节路径使用停车 `[0,-30,-60,40,0,0]°` 到工作 `[0,-80,-70,30,0,0]°` 的线性插值：21个均匀路径点，加0.002/0.005/0.01/0.02/0.025五个初动点。路径参数不代表时间，26点的包络并非连续运动的严格包络。

## 固定端点与曲线构造

| 线段 | 起点材料锚 | 终点材料锚 | 候选有效自由长 |
|---|---|---|---:|
| 根部服务环 | S系 `(90,−140,110)` | S系代理端口 `(90,−70,180)` | 180 mm |
| 关节2环 | link1系 `(0,−80,35)` | link2系 `(−75,0,−75)` | 260 mm |

关节2的两个锚点始终绑定各自link，由 accepted URDF FK 转入S系；没有为了满足长度而移动夹持点。根部两点都固定在S系，因此根部曲线不随 q 改变，这**只说明根部固定自由环不变，不能证明跨关节线束通过**。

令端点为p0、p2，d=|p2−p0|，n为−S.Y在垂直于弦方向平面上的单位投影，控制点p1=(p0+p2)/2+A n。对A≥0，用Brent根求解曲线长度等于指定自由长。端距超出自由长时输出 `FAIL_ENDPOINT_DISTANCE_EXCEEDS_FIXED_FREE_LENGTH`，不会拉长电缆；−Y投影退化时也明确失败，不偷偷换一个弯曲方向。

```text
B(t) = (1−t)² p0 + 2t(1−t) p1 + t² p2
L(A) = 0.5 sqrt(d²+4A²) + d²/(4A) asinh(2A/d)
R_min = d²/(4A)，位于 t=0.5
```

A是控制点偏移，曲线中点相对直弦的弓高为A/2。曲率最大值采用解析结果，未依赖61或101点采样寻找。长度同时用独立数值积分复核，各材料点通过反解累计弧长得到。圆曲线/弹性杆/多导向轮可产生不同形状，因此二次曲线家族的成功构造不等于实际电缆会自然形成该形状。

## 恒曲率圆弧构造与所选结果

保持相同端点、同一负Y投影方向及180/260 mm自由长度，求 θ∈(0,2π) 使 `d/L=2sin(θ/2)/θ`，R=L/θ。令u为弦单位方向、n为负Y正交投影单位方向：

```text
center = (p0+p2)/2 − n R cos(θ/2)
p(phi) = center + R [u sin(phi) + n cos(phi)]
phi = −θ/2 + θ s/L，0≤s≤L
```

等φ点就是等弧长材料点。圆弧半径恒定；脚本另用前三个材料点的外接圆重建半径作独立几何核验。端距大于L时仍失败，不通过增加长度绕开问题。

| 项目 | 根部圆弧 | 关节2圆弧 |
|---|---:|---:|
| 可构造姿态数 | 26 | 26 |
| 固定自由长/mm | 180 | 260 |
| 恒曲率半径/mm | 50.590 | 56.022–60.541 |
| 圆心角/° | 203.859 | 246.063–265.912 |
| 相对Bezier最差半径之比 | 2.907 | 7.971 |
| 两端局部切线最大变化/° | 0 / 0 | 10.914 / 16.842 |
| 端点回代最大残差/mm | 0 | 9.86×10⁻¹³ |

所有选中曲线均为θ>π的大圆弧。模型允许该几何形状，**没有锁定连接器出口切线，也没有绑定实际应变释放尾段**。关节2第一端切线变化减小、第二端变化增大；恒曲率改善不意味着每项几何或力学指标都变好。

所选圆弧26姿态中心线联合包络：根部 `(90,−162.985,110)` 至 `(90,−70,202.985)` mm；关节2 `(22.795,−153.006,242.949)` 至 `(98.849,−43.375,364.251)` mm。相比Bezier，关节2圆弧向负X及更高Z扩展，完整曲线与臂、塔架和保持器的间隙须重新检查，不能沿用Bezier包络结论。

OD=4/6/8/10 mm 时所选圆弧最差 R/OD：根部约12.648/8.432/6.324/5.059，关节2约14.005/9.337/7.003/5.602。仍没有OEM动态半径准则可用于判定。

大量余长集中在单个二次曲线中会使弯曲变急；关节2的260 mm候选就是这种情况。后续应依据真实电缆的动态半径和夹持空间选择自由长、锚点、导向或分段曲线。不能仅因为存在余量就判断安全，也不能直接削减长度而不重查全部姿态。

对于 OD=4/6/8/10 mm 的几何代理，关节2最差 R/OD 分别约 **1.757/1.171/0.879/0.703**，根部约 **4.351/2.900/2.175/1.740**。这些只是几何比值，未与任何实际电缆规范比较。每姿态包络采用解析中心线极值，再向各轴扩张OD/2；这是保守的假定圆截面包络，不是与机械臂或机构完成了碰撞测试。

## 厂家数据的适用范围

本地厂家BOM提供 XT30 2+2 的200/350 mm端到端线束总成，以及直头/弯头组合；这不是可直接参与弯曲的自由段长度。180/260 mm是本轮候选自由长，没有用猜测的插头尾长去“换算”厂家总成。

厂家参考来自固定提交 `8def0ebd8ea0785dcbfc58c00ab176ee42acba5d`，本地证据为 `inputs/vendor_reference/B601_DM_BOM_readme.md`。可复用的OEM线夹为 `inputs/vendor_reference/VENDOR_DM_Motor1_wiring_harness_clip.stp`：厂家说明它用于约束 Motor 1 两侧线束、减轻长期拖动对接头的磨损。这不能自动证明它适用于本轮关节2锚位、真实电缆外径、动态弯曲或航天环境。脚本保存BOM、线夹、参数和URDF/FK的哈希。

小STEP及公开BOM仍不能补齐以下数据：真实电缆外径及截面、动态最小弯曲半径、每米允许扭转、夹持尾长、连接器插拔轴与防拉脱结构、回弹弯矩、端部力、摩擦/磨损与循环寿命。以上保持 UNKNOWN/null。

端切线变化只是电缆出口方向变化；它不是材料扭转角，也不能推导扭矩、拔出力或寿命。每条中心线即使是平面曲线，也不能据此将导体束的材料扭转置零。图示夹点的出口轴尚未约束，夹点尾部可能形成未建模急弯。

本轮只覆盖根部服务环和关节2候选。关节3至腕部、夹爪内部、太阳翼根铰链等尚未布线，整个航天服务星线束系统仍未完成。下一步应先核对实际电缆和接头，再调整关节2余长分配/导向，重做同材料点的定长、弯曲和干涉检查，并通过样件循环运动测量端部力及磨损。
