# WP02 根部简化柔度与双鞍座载荷分配方法

本包已建立可复算的四立柱、两上横梁三维 Euler–Bernoulli 梁模型，输出六个单位载荷下的完整柔度矩阵。它用于比较构型和规划地面试件测量，**不提供结构强度裕度、允许载荷或航天适用性结论**。所有数据见 `results/ROOT_COMPLIANCE.json`，运行 `python root_compliance.py` 即可复算；不导入大 CAD，也不修改 WP01。

## 几何、材料与计算边界

计算读取 WP01 当前 `design_parameters.json`，并保存该文件、`service_robot_common.py` 和 accepted URDF 的 SHA-256。S 系为星体几何中心系，X 沿星体长轴，Y 横向，Z 指向顶部。

名义实际载荷路径是 B601 → M3R 两级 → 170 × 202.3 × 6 mm 根部桥板 → x=20/160 mm 两根 14 × 202.3 × 12 mm 上横梁 → 四根 14 mm 方管、壁厚 2 mm → 下横梁及框梁连接 → 地面夹具。新增锚固、螺栓、防压套必须补进实体与接口检查。

本次仅把下列部分离散为有弹性构件：

- 四立柱中心线在 `(20/160, ±94.15)` mm，z=−98.15…95.15 mm，长度193.3 mm。
- 两上横梁中性轴在 z=101.15 mm，有效支承跨度188.3 mm，每根按左右两段建立；端部各7 mm无载悬伸不计入刚度。
- 柱顶到上横梁中性轴的6 mm差值通过刚性偏置保留，没有把构件中性轴误置于接触面。
- 根部参考点 `(90,0,125.15)` mm 与两上横梁中点之间采用刚性耦合。该假设包含桥板和 M3R 被理想化为刚性的影响。
- 四柱**下端六自由度理想夹固**，仅表示专门的 GSE 根部试件边界；没有把飞行星体面板或整面设置为固定边界。

E=69 GPa、ν=0.33，仅为候选铝材假设；G=E/[2(1+ν)]。柱截面 A=96 mm²，Iy=Iz=2368 mm⁴。方管扭转常数采用中线闭口薄壁近似 J=t(14−t)³=3456 mm⁴，厚度比例并非极薄，因此扭转精度尚无误差界。上横梁采用实心14 × 12 mm截面，**忽略 Ø6.6 孔及其局部承压/净截面效应**；矩形扭转常数采用常用近似式，而非精确截面求解。

梁单元包含 EA/L、GJ/L 和两个弯曲平面，局部转角按右手规则。刚性偏置关系为 `u_slave=u_master+theta×r`。梁弯曲矩阵与[代尔夫特理工 Euler–Bernoulli 单元教材](https://oit.tudelft.nl/CIEM5000/2026/lecture1/other_elements.html)一致；三维参数 A/E/G/J/Iy/Iz 的含义参见[OpenSees 弹性梁柱文档](https://opensees.github.io/OpenSeesDocumentation/user/manual/model/elements/elasticBeamColumn.html)。代码独立组装并求解，没有运行 OpenSees。

## 六单位载荷结果

载荷列顺序为 `[Fx,Fy,Fz,Mx,My,Mz]`，力单位 N、矩单位 N·m；响应行顺序为 `[ux,uy,uz,θx,θy,θz]`，平移单位 mm、角度单位 rad。每个矩阵条目的单位是“该行响应单位/该列载荷单位”。根参考点的工程单位柔度为：

```text
             Fx             Fy             Fz             Mx             My             Mz
ux     2.904858e-3      0              0              0         3.642315e-3      0
uy     0               1.346897e-3     0         1.032316e-3      0              0
uz     0               0         2.393032e-4      0              0              0
θx     0          1.032316e-6          0         5.510215e-5      0              0
θy     3.642315e-6      0              0              0         4.470419e-5      0
θz     0               0              0              0              0         1.251550e-4
```

这里只把数值舍入噪声显示为0，JSON保留计算原值。这种混合单位矩阵在数字上不对称：例如 ux/My 与 θy/Fx 相差1000，原因是 mm 与 m 的换算。JSON同时提供以 `[m,m,m,rad,rad,rad]` 为响应、`[N,N,N,N·m,N·m,N·m]` 为载荷的 **SI柔度矩阵**，用它检查互等定理。

复算检查如下；它们只验证本简化模型的数值实施：

| 检查 | 结果 |
|---|---:|
| SI矩阵经0.1 m特征长度合同缩放后的对称相对误差 | 6.56×10⁻¹⁵ |
| 六个缩放特征值 | 全为正，最小2.3930×10⁻⁷ m/N |
| 六单位载荷反力平衡最大力残差 | 1.08×10⁻¹³ N |
| 关于根参考点的反力平衡最大矩残差 | 5.34×10⁻¹⁵ N·m |
| 单柱自由端解析柔度对拍相对误差 | 2.35×10⁻¹⁶ |
| 每段梁1→4单元的柔度相对变化 | 9.13×10⁻¹³ |

单柱对拍覆盖轴向、扭转、双向弯曲及力—转角交叉项。网格对拍用8/16/32个梁单元；Euler–Bernoulli等截面构件在端部载荷下本来可由单个单元精确表示，网格一致性不验证三维实体应力、剪切变形或接触细节。

JSON记录四个固定端对六个单位载荷的反力矩阵，平衡时同时累加各固定端的 `r×F`，没有只检查合力而遗漏关于根参考点的力矩。

## 承载面与框架原点的条件换算

名义 B601 承载面为 z=127.555 mm，根框架原点为 z=125.15 mm；两者相差2.405 mm。不能把该几何差值当作额外抬高整个机械臂的安装量。

令 `r=[0,0,0.002405] m`，`H=[[I,-skew(r)],[0,I]]`，则在两点之间刚性连接的假设下：

```text
w_root = H.T @ w_bearing
F_root = F_bearing
M_root = M_bearing + r × F_bearing
q_bearing = H @ q_root
C_bearing = H @ C_root @ H.T
```

JSON保存上述换算后的 SI 柔度。该变换只做参考点转移，**没有增加桥板、M3R或螺栓的真实柔度**。

## 材料、壁厚与未知连接柔度的敏感性

在 ν 不变、所有构件同时改变 E 的条件下，E=62.1/69.0/75.9 GPa 时所有柔度分量分别为基准的1.1111/1.0000/0.9091倍。这是比例性检查及假设敏感性，不是材料实测范围。

只改变四柱壁厚时，各对角柔度相对基准的变化如下：

| 柱壁厚/mm | ux/Fx | uy/Fy | uz/Fz | θx/Mx | θy/My | θz/Mz |
|---|---:|---:|---:|---:|---:|---:|
| 1.5 | 1.1202 | 1.1437 | 1.0675 | 1.0102 | 1.0709 | 1.1230 |
| 2.0 | 1.0000 | 1.0000 | 1.0000 | 1.0000 | 1.0000 | 1.0000 |
| 2.5 | 0.9293 | 0.9193 | 0.9594 | 0.9933 | 0.9577 | 0.9306 |

可见有些转动柔度对柱壁厚不敏感，上横梁及整体耦合会限制加厚柱壁带来的收益。本结论只适用于当前理想化连接。

实际连接柔度 `C_connection` 仍是 **UNKNOWN/null**。为展示其可能影响，代码另外给出假设模型 `C_total=C_frame+C_connection`，其中 `C_connection=α diag(diag(C_frame))`，α=0/0.1/1/10。对应对角柔度为基准的1/1.1/2/11倍；它只是“连接可与梁同样重要”的参数算例，**不是已选螺栓、夹具或接触面的物理取值**。实测连接存在耦合时应填写完整6×6矩阵，并通过坐标变换、串并联拓扑或显式接头单元进入模型。

## 双鞍座的兼容方程与单侧接触

WP01 两个鞍座候选站位 x=−115/−40 mm。当前按 accepted link2 网格截面保留约2 mm设置间隙；该间隙不能被当作实物已贴合或已承载。对支承反力必须同时满足**平衡、变形兼容、单侧接触**。

令 `u` 为所建线弹性系统广义位移（至少含根部、臂/关节柔度和支承结构的必要自由度），`K` 为对应刚度，`A u` 表示各接触点朝支承方向的间隙闭合量；`λ_i≥0` 为第 i 个接触法向压缩反力，`S` 为支承/垫片压缩柔度，`g0` 为初始间隙。采用反力抵抗闭合的符号约定：

```text
K u = f − A.T λ
g = g0 − A u + S λ
g_i ≥ 0，λ_i ≥ 0，g_i λ_i = 0
```

当 `K` 可逆时，令 `C=K⁻¹`，可得：

```text
g = g0 − A C f + (A C A.T + S) λ
```

应求解上述线性互补问题或枚举活动接触集，并检查求解后未激活接触确实不穿透、已激活接触反力非负。只有在已知两点都接触、几何/刚度完全对称、间隙和预紧一致、载荷作用点也对称等条件下才可能出现均分；本项目目前不具备这些已知条件。

若两接触已由已知预紧建立，增量方程可以写成 `δg=0`、`(A C A.T+S)δλ=A C δf−δg0`，同时仍需检查总反力 `λ0+δλ≥0`。**预紧 λ0、垫片刚度、实装间隙、定位点法向、摩擦系数、保持器闭合力、臂关节锁定/伺服刚度均未知**，本包不输出两鞍座数值反力。保持器是额外机构，必须把其已知位移/载荷和作用位置明确进入方程，不能以假定“有预紧”取代接触定义。

仅有根部6×6柔度还不足以准确计算鞍座反力：两支承作用在臂上不同位置，需要臂自身弯曲、关节弹性/回差、垫片与支承的兼容模型。若后续只把机械臂看成刚体，也必须明确此近似，再把根部与接触位置通过刚体位移映射连接。切向约束和摩擦/滑移应另建，不能用两个法向压缩力表示六自由度保持。

## 实物验证如何接入

建议先按实际装配完成锚固、防压套、螺纹啮合、定位和扭矩工艺，再在GSE试件测量六个独立小载荷方向的位移/转角，至少记录加载位置、力、温度、紧固状态和回程滞回。载荷幅度必须由实际试件与试验条件确定，本包没有给定安全试验载荷。

随后用测得的连接柔度替换 UNKNOWN，复测不同预紧与方向，并通过单/双鞍座接触切换试验识别初始间隙、接触刚度及反力。若需要飞行结构结论，必须将下横梁、框梁、端框、面板和实际安装接口完整加入模型，使用相应自由边界/惯性平衡或真实安装边界。

当前遗漏桥板/M3R弯曲、接触/紧固/夹具柔度、横向剪切、孔边局部效应和翘曲等，模型通常会比实装体系更硬，但没有量化误差界。**数值正定、反力平衡、解析对拍与网格一致均不构成强度合格或整机机械闭环。**
