# WP01 后续零件化、装配与具身联调计划

日期：2026-09-05。对象：`WP01_ROOF_EXTERNAL_R1`，由本包 `design_parameters.json` 驱动的服务星/B601 候选。本文是本轮开始设计后的执行分解；下面所有尚未运行的检查与试验均为计划，不能据表格视为已通过。输入依据见 `DESIGN_INPUTS.md`，对偶接口依据见 `interface_requirements.csv`。

## 1. 先做一个真实可装的关键组合件

首件包含：代表性的框梁/端框段、臂根转接与承载桥、完整 B601 或与其实配接口一致的臂根件、两处可调支承、保持锁扣、释放件及确认传感器、真实臂根电缆和连接器。工作目标是确认臂能安装、支承能调到实际接触面、锁扣能保持并完全退出、手和工具能伸入、线束不妨碍释放与首段运动。

首件先在工装上独立装调，完成接口量测与低速动作；需要承载时，按明确载荷和工装能力另立试验工况。外观打印件可检查包络与装配路径，不能替代材料/连接强度试验。

| 工作项 | 必须产物 | 拿到什么结果后进入下一项 |
|---|---|---|
| P01 实配测量 | B601 根部孔/基准测量表；壳体可支承区域；线缆及插头样件记录 | 对偶面、孔型/深度、插拔方向与测量误差能标到图上 |
| P02 接口零件化 | 转接板/桥/框锚/鞍座/锁扣/导向件可编辑实体、尺寸图和标准件表 | 每个紧固件能装入并拧紧；每个基准/配合有公差目标 |
| P03 工装试装 | 实际装配顺序、工具清单、接触/间隙实测、整改照片 | 无不可达紧固点或被封死连接器；支承调整量覆盖实配偏差 |
| P04 释放动作 | 保持→指令→脱开确认→退出包络→初始展臂全过程记录 | 实测行程与反力能解释动作；断电/未完全脱开不会触发臂动作 |
| P05 真实线束 | 同固定点、同连接器下的全程形态、最小弯曲、端部反力/扭矩和磨擦记录 | 供应商限制与实测误差下仍满足；不满足则修改支架/余长并复测 |
| P06 收敛后放大 | 修订的整星总装、关键件图、接口表与问题关闭记录 | 实配修改已回写唯一参数源，后续主结构与设备板沿此版本设计 |

## 2. 分总成与整星装配顺序

| 序号 | 装配操作 | 当步必须检查 | 返修/拆卸要求 |
|---|---|---|---|
| A01 | 工装定位后端接口和主框梁，装端框/横梁 | S 基准、对角/平面度、框梁对偶面、通孔/螺纹及工具位置 | 开放至少一个设备装入面；定位销能按规定方向退出 |
| A02 | 安装承载桥、臂根转接及其定位/紧固件 | 载荷能沿实体/紧固连接传到主框架；Stage A 环/B 槽按嵌套对偶装入；基准转换与装后孔位 | 臂根紧固和力矩工具不被设备板封住 |
| A03 | 装电池/电源、计算机/驱动、姿控设备板及热连接 | 设备实选尺寸、底脚、热垫厚度/压紧、接插件朝向、维护拔出 | 首装前做纸样或实体包络插入；可拆板不牵拉固定干线 |
| A04 | 布置母线固定干线、分支与接地连接 | 连通/标识、防呆、应力释放、穿舱边缘、防磨、连接器锁紧 | 能断开分总成，不需剪线才能拆设备 |
| A05 | 支撑 B601 后安装根部并记录关节零位 | 候选 frame 为 [90,0,125.15] mm；名义 BRep 接触面 z=127.555 mm，见 [接口几何收据](results/INTERFACE_GEOMETRY.json)；实物注册、紧固程序、实际安装矩阵与线束承力另测 | 工装托持臂后才松根部；保留独立拆臂路径；不把 frame 原点当接触面 |
| A06 | 安装末端工具、F/T、相机及腕部线束 | TCP/相机/F/T 基准，线缆朝向，夹爪全行程与标定靶可达 | 末端传感器单独可更换；拆后按基准或重标定恢复 |
| A07 | 调整鞍座并装保持/释放机构、确认传感器 | 接触点/垫厚、自由度分配、预紧、释放退出量、手动复位 | 可独立调整/换垫；地面复位不需拆主结构 |
| A08 | 装两侧翼根/翼、保持件、翼根服务环 | 铰链轴、锁止、两翼线束与臂首动包络 | 翼可单独拆卸，释放器更换与插头可达 |
| A09 | 完整展开序列检查后装覆盖件 | 禁止接触区、散热/视场/维护开口、覆盖件与活动线束 | 可打开检查保养；封闭前留紧固、线束及序号记录 |
| A10 | 实装称重、零位/外参标定及数字模型更新 | BOM/序列号/修订一致；总质量、CG、关节方向、TCP与视觉外参 | 任何影响质量/安装的返修触发对应测量/标定更新 |

紧固规格、拧紧力矩、润滑/防松、螺纹啮合长度和材料许用值由实选紧固件与载荷计算确定。表中的“检查”不是提供未经依据的通用力矩值。名义 BRep 基座承载底面局部 z=2.405 mm，而 accepted STL 基座 bbox 从 z=0 起；CAD 的同原点接触结果不能替代 BRep/STL/实物基准注册。

## 3. 检查与试验矩阵

每项记录包含：配置 ID、部件/仪器序列号、参数/模型版本、实测数据及误差、明确的合格判据、异常与整改。未给定阈值的项目先输出要求及测量方法，不用默认零值判定。

| 编号 | 目的/工况 | 方法与输出 | 判据的来源/表达 |
|---|---|---|---|
| V01 | 可重建、可装配 | 参数改变后重建；对偶孔/安装面、装入路径、工具实体检查；STEP 读回 | 单位/坐标一致，部件不丢失；计划接口随动；STEP 读回仅证明导出可读 |
| V02 | 完整收拢布局 | 含臂掌指、转接、支承、保持器、连接器、电缆、翼与设备的尺寸和干涉表 | 采用本候选包络；正常接触列允许表；未授权穿透单独整改，不把低体积穿透自动忽略 |
| V03 | 释放与连续运动 | 固定根部变换下逐段检查：保持、脱开、初始展臂、翼展开、工作；必要时自适应加密 | 净间隙 ≥ 公差/装配误差 + 控制/挠曲误差 + 设计余量；各项来自实测/分析，不能只看关键帧 |
| V04 | 支承/根部承载 | 展开反力与收拢支承工况分别建模；孔边/接触/滑移/紧固与刚度计算，再做组合件载荷试验 | 载荷向量/谱、许用值、温度、紧固预紧及分流模型均明确；不把目标质量乘地面重力当在轨抓持载荷 |
| V05 | 保持与释放 | 量测接触预紧、锁扣位移、释放时间/反力；逐次复位；拒动/部分脱开/失电情况 | 行程足以退出最不利包络；确认信号与真实机械状态一致；循环次数/释放限值由实选机构寿命要求给出 |
| V06 | 臂与翼线束 | 真实样段在各关节/翼根循环；弯曲/扭转、余長、端部反力、磨擦、夹挤及连接器受力记录 | 不超过供应商动态限制；连接器不承担非设计拉力；有效长度/固定点与 CAD 相同 |
| V07 | 内部装入与维护 | 实选设备或尺寸一致的插入样件试装，含插头/扳手/抽出通道 | 不靠临时移走不可拆结构才装入；维护动作有确定路径；热界面/线缆不被动作破坏 |
| V08 | 翼部署 | 翼铰链/保持/锁止和线束一起检查；评估臂先、翼先两种顺序并选定 | 同一配置下臂翼运动与线束空间成立；实际力矩/锁止/阻尼满足定义工况 |
| V09 | 数字属性一致 | 称重与质量预算对账；CG 测量；姿态相关质量惯量重算；碰撞几何绑定 | 每个实体仅计一次；惯量明确参考点、轴向和配置；不得把旧整星预算块叠加到新设备 BOM |
| V10 | 感知与末端 | 夹爪行程/夹持力、F/T 零偏/安装刚度、相机视场/遮挡和外参标定 | 阈值由实选传感器、目标接口及任务误差预算确定；关节/相机/TCP时间和坐标可对应 |
| V11 | 具身最小闭环 | 在固定/卸载条件执行静止目标识别→规划→约束检查→接近→抓持→反馈→释放 | 记录定位误差、接触峰值、持稳/滑移和完成率；控制限值来自本实装硬件；不外推自由漂浮捕获 |
| V12 | 异常停止 | 目标丢失、反馈过期、受阻、力阈值、未脱开、断电/失联等注入 | 机械状态与控制动作可解释；停止距离/停止力实测；未确认释放时不允许移动受约束臂 |
| V13 | 后续环境适应性 | 实际任务确定后制定振动/冲击、热真空、润滑/材料、寿命试验 | 条件与判据来自任务/供应件和分析；本轮不声称已经获得飞行资格 |

## 4. 必须保留的设计记录

- **接口尺寸表**：孔中心、定位面、法向、孔/轴类型、配合/公差、螺纹深度、紧固件插入和工具方向。
- **动作定义**：固定的 `T_S_A0`、每个状态的六轴角/夹爪开度/翼角、释放件状态、同一套线束固定点；关键帧与连续路径结果分别保存。
- **装配图/BOM**：原生零件引用、材料/工艺、数量、质量来源、标准件、采购型号、修订、允许代用及对验证的影响。
- **试装记录**：每次改件的原因、实測与设计差异、影响到的接口、图纸修改、需要重做的检查。
- **具身交接**：视觉/碰撞几何、关节与驱动限制、安装矩阵、TCP/F/T/相机标定、实际质量/惯量、线束工作区及机构状态；全部指向同一实装版本。

## 5. 下一轮工作顺序

1. 接收本轮总体参数/STEP 检查结果，给每个接口分配真实对偶零件和固定基准；先明确臂根、支承、释放和线束。
2. 按 P01–P02 完成关键组合件零件化，同时补根部实配、电缆、末端与设备输入。
3. 先完成可装性和保持/释放试装，再进入负载、循环与全范围动作；实测不满足项直接改对应零件。
4. 在其基础上并行完成翼与内部设备，汇入唯一总装，输出全套工程图/BOM/工艺和整星装配记录。
5. 更新实装数字模型后执行 V10–V12；运动目标与自由漂浮场景作为后续扩大任务能力的独立验证。
