# WP01 之后立即执行的首批零件化

日期：2026-09-05。父装配：`WP01_ROOF_EXTERNAL_R1`。本清单沿用本轮用户开始进一步设计的指令，工作顺序由真实接口依赖决定。设计参数见 [design_parameters.json](design_parameters.json)，对偶要求见 [interface_requirements.csv](interface_requirements.csv)，试装步骤见 [ASSEMBLY_AND_TEST_PLAN.md](ASSEMBLY_AND_TEST_PLAN.md)。

**第一批要交付一个可装、可调、可保持并释放的组合件：框架段＋根部承载板/纵梁连接＋B601＋两鞍座＋保持释放＋真实线束。** 当前的外廊、支承和机构几何提供设计位置；下面的零件化任务将这些位置落实为材料、对偶面、定位、紧固、接触和动作。

当前根部 frame 保持 x=90 mm、y=0 mm、z=125.15 mm，旋转 I；名义 BRep 基座局部承载底面为 z=2.405 mm，因此真实几何接触面在全局 z=127.555 mm。依据为 [接口几何收据](results/INTERFACE_GEOMETRY.json) 的同原点对偶情况，不再将 root frame 与承载面混同。accepted STL 基座 bbox 从局部 z=0 起，与名义 BRep 不同，首件必须完成两类模型及实物的基准注册。

母线核心是 366×226.3×226.3 mm。本方案外置臂使整体较高，当前不以紧凑标准 12U 包络合规作为已经完成的结果。姿态和包络变化的最终值以 [布局比较](LAYOUT_COMPARISON.md) 与 [结果目录](results/) 为准。

## 两项必须在零件化时纠正的几何语义

**把 2 mm 支承设置间隙闭合成真实接触。** 当前 `support_mesh_clearance_mm=2` 表示几何初案对源网格设置了间隔。承载鞍座需要确定接触面法向、垫片压缩/刚度、调节量、允许壳体面压和预紧，才能形成可计算的反力。不能一面保留空气间隙，一面在受力图中画出持续支承力；也不能简单加厚垫片后跳过过约束和释放检查。先设计调整结构，再按组合件的实际接触校正模型。

**F/T 是腕链中的真实机械层。** 实选 F/T 放入腕部与夹爪之间会改变腕部长度、质量、TCP 和线束位置。需保留 B601 基础链来源，同时派生包含传感器/两侧转接的本候选工具链；更新 `T_WRIST_FT`、`T_FT_TOOL`、TCP、惯量和碰撞几何，重查收拢/支承、夹爪全行程和工作区。传感器外形靠近原夹爪的示意摆放只表示预留位置。

## 输入补齐与并行安排

1. **总体/根部负责人先完成 WP01-RB/MT 的实配接口。** 实物量测根部孔、物理安装面、连接器位置及壳体可支承区域；材料、载荷和紧固输入同步登记。未知量保持 `TBD` 并列出获取方法，可以先做可调整候选，不能填任意数后声明承载完成。
2. **机构与线束负责人共同做 WP01-SA/SB/HR/HS/HB。** 锁扣、鞍座和线束不能分别固定位置后再相互适配。用最终检验过的收拢姿态，联合选择接触点、释放退出方向、连接器及线夹，并输出组合件图。
3. **末端负责人并行实选 F/T/相机并完成 WP01-FT/CM。** 先补厚度、孔型、线缆方向和载荷，再重建工具链；工具链修改会反馈根部载荷和收拢保持设计，必须在全星详细出图前合入。
4. **翼与航电负责人并行做 WP01-WL/WR/AT。** 共用同一主框架和运动空间；设备实际尺寸取代预算盒后更新质量账本，翼设计同时包含铰链、保持/锁止和根部线束。
5. **试装负责人做 WP01-GSE 和首件装配。** 先记录孔位、接触、工具、插拔和释放问题；依据实测改件，再进行明确载荷和循环条件的试验。

## 每个组合件的完成条件

完成的组合件应具备可编辑原生零件/总装、同修订 STEP、带公差和基准的关键尺寸图、材料/工艺/标准件表、逐件质量来源、装配顺序和测量方案。每个对偶界面须能回答“靠什么定位、怎样紧固、怎样传力、怎样拆卸”，每个活动界面须能回答“怎样释放、怎样确认、怎样避让线束、失电后在哪里”。

首件验证由易到难推进：接口量测与试插 → 无载装配 → 接触/预紧调节 → 释放和初动 → 真实线束全路径 → 规定载荷/循环 → 回写整星总装。实际验证等级、数值和结论随记录给出，不由模型导出或清单勾选自动产生。
