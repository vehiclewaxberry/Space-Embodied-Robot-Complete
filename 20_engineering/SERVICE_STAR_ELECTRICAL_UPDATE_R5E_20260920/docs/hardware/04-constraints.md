# 服务星 R5E｜2026-09-20｜阶段5：实现约束与接续工作

本轮选择的是可评审的器件候选。上电、制造、飞行资格均为 false。

1. **先保持源一致性。** 新 BOM 绑定249-ref网表及三块实读 PCB。239-ref的`revisions/v36/wp10_system.xml`缺10项STOP器件，不能覆盖当前滤波电路。旧HANDOFF的WORKING_REVISION哈希失配单独披露；不回写旧收据来伪造匹配。
2. **R305落实原理图与板图。** 候选665kΩ 0805 +11kΩ 0603，两者0.1%/25ppm。新增中间节点，不能把两个料号当成原单封装已安装。八角初始公差计算只保证理想分压的比较，未包含参考源、偏置、迟滞和温漂。量产料号/供货再核验。
3. **有效电容优先验收。** C301初始公差下限1.425µF，仍需证明环境与寿命下≥1µF；C302/C305分别需在12V工作点证明≥10µF/≥1µF。原厂典型DC偏压图不当作批次保证。C209/C210的X7S温度系数为±22%，初始公差与正TCC相乘的两只上限筛查为19.9104µF；旧16.32µF只含初始公差。THN其余负载电容、ESR和瞬态稳定性仍未知。
4. **电流与保护。** TPS26600是AUX小电流支路器件，不承载MAIN的20A。MAIN Q201进焊盘颈部既有62.9086 A/mm²仍超过35 A/mm²筛查值，选型更新不能关闭该问题。继续核对SOA、熔断器清除时间、电池源阻抗、再生能量及制动电阻热容量。
5. **电热与CAD。** R201/R202合计2.5mΩ；R202高度为2.95±0.2mm。V30中的旧0.2mΩ实体和旧热结果不能直接当作V36。新候选C204、C301及1210电容的空间须进入R5紧凑主路/制动板布局。现有R4接口PCB到TIM的4.5mm间隙、CF1装配干涉仍待解决。
6. **接口与线缆。** J200/J203是电源边界，仍需插接件、端子、线径、电流与极性；J202需真实复位方式。J201禁止默认短接跳帽；J210是AUX板铜盘，无独立采购件。接口分类不代表连接器选型完成。
7. **封装与资料。** TNPW标准阻值、尺寸、容差、TCR按原厂系列表生成订货码，未核库存。既有封装通过PCB比较不代表新器件已放置。对C204尚缺原厂焊盘验收；ADI两份PDF及部分候选规格书目前仅原厂网页核验，归档缺口见源清单。

已完成受控ECAD候选属性修订。下一实施顺序：有效电容/封装与R305完整阈值校核 → R305两串及无源件落板/焊盘复核 → 保护瞬态验证 → V36实体紧凑载板/电热布局 → 线束端接和装配 → 有界台架验收。可并行处理公开资料与布局，但任何未知值不能自动关闭验收项。
