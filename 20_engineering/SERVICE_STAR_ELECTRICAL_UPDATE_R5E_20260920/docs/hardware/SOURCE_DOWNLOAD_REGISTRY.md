# 本轮原厂来源与下载记录

18条原厂来源以`inputs/PRIMARY_SOURCES.json`为输入，归档状态与SHA-256见`results/PRIMARY_SOURCE_ARCHIVE.json`。其中10份PDF已本地归档；其余使用已核验的原厂网页/PDF页面，缺少本地PDF的状态明示。没有把下载失败解释为器件不存在，也没有把网页在售或系列订货码解释为库存保证。

下载日志保留于`sources/KEMET_DOWNLOAD_LOG.json`、`KEMET_DOWNLOAD_NETWORK_LOG.json`与`PASSIVE_DOWNLOAD_RETRY.json`。本轮成功取得4份KEMET精确料号规格书。失败或被替换的候选不进入已选MPN，最终清单以45项输入与249行派生BOM为准。

LT3013EDE#PBF原先已在锁定网表U301的Value中。本轮从该值恢复结构化候选料号，并补核原厂第2页订货表和DE封装；没有为U301新增工作点合格结论。[Analog Devices原厂规格书](https://www.analog.com/media/en/technical-documentation/data-sheets/3013fe.pdf)

本记录位于项目工作区；未改写工作区外的共享下载台账。采购URL、报价、库存、交期及替代供应商均待实际采购前核验。
