# M5 全闭环机械工程执行方案 V1

## 1. 目标与裁决边界

本方案把 B601 机械臂、M3R 安装链、航天器平台、太阳翼和抓取目标组织成可追溯的数字工程闭环。当前授权范围是源文件绑定的几何、九构型诊断快照、理想刚性塑性捕获冲量、六自由度连接载荷分配和接触辨识计划。

当前不授权正式有限元分析、物理接触力或压力、飞行载荷、强度/裕度、制造放行、强化学习策略训练、硬件在环或实物执行。未知物理量必须为 `null/HOLD`，不得以零代替。

## 2. 闭环主链

```text
权威源与哈希冻结
  -> 坐标系/单位/构型契约
  -> 中性 CAD 与真实 link-local 几何
  -> 九构型运动学与分层碰撞
  -> 质量/质心/惯量闭环
  -> 接触与执行器试验辨识
  -> 捕获事件冲量及物理接触时程
  -> 六维载荷路径和连接分配
  -> 结构模型、收敛、相关性与裕度
  -> 多体/柔性耦合抓取验证
  -> 物理门控自主规划与 HIL
  -> 试验偏差回写、版本升级、回归复验
```

任何下游结论只能使用上游已经签署且哈希匹配的数据。发生源文件、单位、坐标系、构型、材料批次或边界条件变更时，变更影响链上的全部门禁自动失效并重新验证。

## 4. 当前已经固化的工程裁决

1. 名称含 `LINKLOCAL` 的 B51 部件 STL 数值上是顶层装配坐标；必须先以 q=0 变换逆局部化。文件名不得作为坐标权威。
2. R1 夹爪源模型数值坐标属于 `gripper_link`，不能直接绑定 `link6`；固定 `gripper_joint` 变换必须保留。
3. 太阳翼显示分支统一采用隔离的 V5 R2B 三面板候选，不能与 M4 展开盒代理混用。其根部坐标差异需 ECR 处理。
4. C01--C09 全部只是诊断几何快照；质量、惯量、系统碰撞和接触权威均未由快照创建。
5. 旧 `M_FRAME` 不是物理平台安装面，不得用于结构边界；平台载荷桥到 M3R 的真实安装基准变换目前为 `null/HOLD`。
6. 旧 LC-010 的关节 2 指令 `+60 deg` 超出已接受上限 `0 deg`，不能继续作为数值载荷输入。
7. 理想刚性塑性捕获只能给出冲量与力偶冲量。没有接触持续时间或经辨识的时程模型时，禁止由冲量推导峰值力。

## 5. 试验辨识与不确定度办法

接触闭环按 CT-01 至 CT-05 顺序推进：先确认材料/表面/环境和量程，再辨识法向、回弹、摩擦及执行器，最后做集成捕获相关。原始通道统一使用 SI API，仪器原单位只在受控导入层转换。

每个用于设计判断的量必须记录：估计值、标准不确定度、分布、有效自由度、校准或数据来源、相关组、适用温度/真空/循环范围。线性区采用 GUM 传播；显著非线性或相对不确定度超过 20% 时同时执行保留相关性的 Monte Carlo。缺项时保持 `null/HOLD`。

## 6. 结构与自主阶段的硬门禁

正式结构求解必须等待受控结构几何、物理载荷与组合、真实安装边界、紧固/接触定义、材料许用值、九构型质量特性、网格/收敛计划和验收准则全部通过。当前不得发出 `STRUCTURAL_ANALYSIS_READY`。

自主抓取环境必须从同一机械接口读取哈希绑定数据；若窄相位碰撞、接触参数、质量惯量或结构门任一未通过，捕获动作必须被屏蔽并退化到 ABORT/保持/撤离。当前 Sim15 只验证软件契约、动量守恒、冲量包络和连接载荷平衡，不构成 RL 或飞行性能证明。

## 7. 下一轮最短关键路径

1. 完成 Sim15 八工况捕获冲量包络及六组连接载荷平衡回归，关闭“诊断可复现性”缺口。
2. 冻结 C01--C09 的指端行程映射，完成太阳翼根部坐标 ECR，并建立精确窄相位/公差碰撞模型。
3. 建立九构型质量、质心、惯量测量/计算台账和不确定度模型。
4. 明确夹指接触材料、表面、目标代理和执行器候选，执行 CT-01 至 CT-04；再以 CT-05 相关捕获时程。
5. 发布平台载荷桥真实安装基准、连接几何、材料/紧固件和飞行载荷组合，重新计算结构入口门。
