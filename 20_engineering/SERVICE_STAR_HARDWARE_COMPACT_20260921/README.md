# 航天服务星与 B601 机器人硬件数字样机

本目录是2026-09-21从本机工程库提取的精简设计工作副本，范围仅为机械、电气线束、能源热控和动力推进。它不包含航天动力学、任务控制、RL/VLA或上层规划研究。

当前基线：R6H水平安装机械候选、R5E电气候选、R2/R3线束与机械臂接口、B2热方案及推进接口准备。整理与复制不会把候选设计变成制造或飞行放行。
