# 工作空间与避让检查清单

## 1. 用途

本清单用于检查服务星、reBot 机械臂、太阳板、相机、天线和目标模型之间的工作空间与间隙关系。当前阶段只建立检查项，不声明已经完成 CAD 干涉检查或仿真验证。

## 2. 检查记录格式

建议每次检查记录：

- 检查日期。
- 模型版本。
- 使用的 CAD/URDF/示意图版本。
- 机械臂关节角或姿态名称。
- 最小间隙。
- 是否存在碰撞或遮挡。
- 证据文件，如截图、表格、脚本输出或人工标注图。

## 3. 核心检查项

| 状态 | 检查项 | 通过标准 | 证据 |
|---|---|---|---|
| [ ] | 机械臂零位姿态 | reBot 零位姿态不与服务星本体、相机、太阳板、天线发生干涉。 | 待填 |
| [ ] | 折叠收纳姿态 | 折叠姿态满足桌面展示、运输和安全停机需求。 | 待填 |
| [ ] | 最大伸展姿态 | 最大伸展姿态不撞击服务星本体、太阳板和天线。 | 待填 |
| [ ] | 末端捕获工作空间 | 末端执行器能够覆盖目标抓取特征，并保留接近方向。 | 待填 |
| [ ] | 与太阳板碰撞风险 | 机械臂运动包络与太阳板折叠/展开包络保持安全间隙。 | 待填 |
| [ ] | 与天线碰撞风险 | 机械臂和目标模型不得侵入天线结构包络。 | 待填 |
| [ ] | 与相机视场遮挡 | 折叠、展开和捕获阶段不应长期遮挡关键相机视场。 | 待填 |
| [ ] | 与目标星太阳板碰撞 | 接近目标抓取特征时，不碰撞目标星太阳板。 | 待填 |
| [ ] | 与服务星本体碰撞 | 机械臂各连杆、末端执行器和线缆不碰撞服务星本体。 | 待填 |
| [ ] | 紧急停止/安全姿态 | 任意演示阶段都能回到明确的安全姿态。 | 待填 |

## 4. 需要叠加显示的图层

- 服务星本体简化外形。
- reBot 各连杆和末端执行器。
- 机械臂折叠姿态。
- 机械臂展开姿态。
- 机械臂最大工作空间包络。
- 相机视场锥。
- 太阳板折叠和展开包络。
- 天线包络。
- 目标主体、目标太阳板、目标抓取特征。
- 禁碰区域和允许接触区域。

## 5. 输出要求

- 至少输出一张 6U 布局检查图。
- 至少输出一张 12U 展示模型检查图。
- 至少输出一张目标捕获工作空间图。
- 至少输出一张太阳板/相机/机械臂避让图。
- 所有图件均应标注模型版本，不得使用未标注来源的截图作为正式报告证据。

## 6. 原英文 v0 检查覆盖补齐（2026-09-06 合并）

原 `workspace_clearance_checklist_v0.md` 合并至本清单；原文可从统一整理账本恢复。所有未提供证据的检查维持 `open`，本次整理不填写间隙数值或判定通过。

| 姿态 | 需明确的补充检查 | 原建议证据 |
|---|---|---|
| 零位 | 对前部任务舱与相机的位置 | CAD 截图或运动学渲染 |
| 折叠 | 收拢间隙与突起限制 | 折叠包络图 |

| 预抓取 | 接近目标时不碰本体，并检查相机视场 | 接近姿态截图 |
| 捕获 | 接触只发生在允许抓取特征，保留视场检查 | 捕获姿态截图 |

双侧太阳板与天线均检查收拢/展开状态；目标星的太阳板、天线及非抓取禁入区均进入接近与捕获检查。服务星本体避让覆盖连杆、关节、适配器和末端。碰撞字段与禁入边界结合 [碰撞避让要求](collision_avoidance_requirements.md) 使用。

工作空间包络属于布局检查输出，不能据此声称控制器、动力学仿真或实物捕获已经验证。
