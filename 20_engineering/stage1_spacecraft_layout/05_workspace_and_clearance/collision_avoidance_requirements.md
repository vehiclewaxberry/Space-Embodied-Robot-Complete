# 碰撞避让需求

## 1. 用途

本文件定义服务星、reBot 机械臂、太阳板、目标模型和接触阶段的碰撞避让需求。当前阶段只定义约束和后续建模要求，不声明碰撞检测、轨迹优化或接触控制已经实现。

## 2. 碰撞对象

仿真和 CAD 检查中至少应包含以下对象：

- 服务星本体。
- reBot 各连杆、关节外壳、末端执行器和线缆近似包络。
- 机械臂安装法兰/转接座。
- 服务星太阳板。
- 服务星天线。
- 相机视场锥，作为遮挡检查对象。
- 目标星主体。
- 目标星太阳板、天线和非抓取区域。
- 目标抓取特征和允许接触区域。

## 3. 约束要求

| 编号 | 约束 | 要求 |
|---|---|---|
| COL-01 | 机械臂与服务星本体 | 机械臂各连杆、关节和末端执行器不得与服务星本体发生几何穿透；应设置最小安全间隙字段。 |
| COL-02 | 机械臂与太阳板 | 机械臂运动包络不得侵入太阳板折叠或展开包络；若太阳板状态不同，应分别检查。 |
| COL-03 | 机械臂与目标星非抓取区域 | 末端执行器只允许接触指定抓取特征或允许接触面，不得接触目标太阳板、天线和敏感面。 |
| COL-04 | 末端接近速度限制 | 抓取前末端接近速度必须设置上限，并在仿真参数中显式记录为 `v_approach_max_mps`。 |
| COL-05 | 接触阶段阻抗控制需求 | 接触阶段应预留阻抗控制或等效柔顺控制接口，避免把刚性位置控制直接写成接触策略。 |
| COL-06 | 碰撞包络可视化 | 仿真中需要可视化服务星、机械臂、太阳板、目标非抓取区域和允许接触区域的碰撞包络。 |

## 4. 安全间隙字段

第一阶段可先建立字段，后续由 CAD 和仿真填写具体数值：

| 字段 | 说明 |
|---|---|
| `clearance_robot_body_m` | 机械臂与服务星本体最小间隙。 |
| `clearance_robot_solar_panel_m` | 机械臂与服务星太阳板最小间隙。 |
| `clearance_robot_camera_fov_m` | 机械臂与相机视场遮挡/侵入裕度。 |
| `clearance_robot_target_sensitive_m` | 机械臂与目标敏感区域最小间隙。 |
| `clearance_ee_grasp_feature_m` | 末端执行器与目标抓取特征的接近裕度。 |

## 5. 接触阶段需求

接触阶段不得只依赖视觉叙事，应在第二阶段或后续控制设计中预留：

- 末端速度限制。
- 末端力/力矩监测或虚拟接触力估计。
- 阻抗控制、导纳控制或等效柔顺策略接口。
- 接触前、接触中、接触后三个阶段的状态机标志。
- 抓取失败或接触异常时的安全撤离动作。

## 6. 可视化输出

后续仿真或报告图必须能显示：

- 机械臂可达工作空间。
- 服务星本体碰撞包络。
- 太阳板碰撞包络。
- 目标非抓取区域。
- 目标允许抓取区域。
- 末端接近路径。
- 朴素规划与 RNS 规划使用的同一几何约束。

## 7. 阶段通过条件

- [ ] 服务星本体与机械臂碰撞约束已定义。
- [ ] 太阳板碰撞约束已定义。
- [ ] 目标非抓取区域约束已定义。
- [ ] 末端接近速度字段已定义。
- [ ] 接触阶段阻抗控制或柔顺控制接口已定义。
