# 第一阶段到第二阶段转换计划

## 1. 转换目标

第一阶段输出布局设计基线，第二阶段基于该基线建立自由漂浮空间机械臂动力学模型，并形成 GJM/RNS 反作用抑制对比图。转换时不得把尚未完成的 CAD、质量属性或仿真曲线写成已验证结果。

## 2. Stage 1 输出

Stage 1 应输出：

- 布局：6U 快速布局、12U 展示型服务星布局、reBot 安装位置、目标模型布局。
- CAD：服务星、机械臂安装转接座、目标星/碎片的 CAD 或等效几何模型需求与版本记录。
- 质量质心惯量表：服务星、转接座、目标模型和关键占位件的质量、质心、惯量预算表。
- 工作空间图：机械臂折叠、展开、最大工作空间、目标捕获工作空间和避让图。

## 3. Stage 2 输入

Stage 2 应接收：

- `reBot-DevArm_fixend.urdf`。
- 服务星惯量参数。
- 机械臂安装变换 `^S T_B`。
- 目标模型，包括尺寸、质量、惯量、抓取特征、视觉标记和碰撞包络。
- 太阳板、相机、天线和服务星本体的简化碰撞几何。
- 朴素规划与 RNS 规划使用的共同任务点和约束。

## 4. Stage 2 任务

Stage 2 主要任务包括：

1. free-flyer 基座建模。
2. GJM 建模。
3. RNS 反作用抑制规划。
4. 朴素规划对比。
5. 基座姿态扰动曲线输出。
6. 末端轨迹跟踪误差输出。
7. 几何碰撞包络和工作空间可视化。

## 5. Stage 2 杀手锏图

第二阶段应重点形成两张核心图：

1. GJM 下末端轨迹跟踪。
2. RNS vs 朴素规划下基座姿态扰动对比。

这两张图必须使用同一服务星惯量参数、同一机械臂安装变换、同一目标抓取任务和同一碰撞/工作空间约束，避免通过更换输入条件制造对比优势。

## 6. 转换检查清单

| 状态 | 检查项 | 说明 |
|---|---|---|
| [ ] | `reBot-DevArm_fixend.urdf` 已定位 | 只使用该 URDF 作为后续动力学入口。 |
| [ ] | 服务星坐标系 `S` 已定义 | 包含坐标方向、参考点和版本。 |
| [ ] | 机械臂基座坐标系 `B` 已定义 | 与 URDF 基座链接一致。 |
| [ ] | `^S T_B` 已定义 | 可写入 Pinocchio/free-flyer 模型。 |
| [ ] | 服务星质量属性已建立 | 质量、质心、惯量均有来源和可信度。 |
| [ ] | 目标模型质量属性已建立 | 每类目标均有尺寸、质量、惯量和抓取特征。 |
| [ ] | 碰撞包络已定义 | 服务星、机械臂、太阳板、目标非抓取区域均可视化。 |
| [ ] | 任务点已定义 | 朴素规划与 RNS 规划使用相同起点、终点和约束。 |
| [ ] | 报告图需求已定义 | 对应 GJM 轨迹跟踪和 RNS 反作用抑制图。 |

## 7. 不允许事项

- 不使用 `reBot_B601_DM_with_gripper.urdf` 替代后续指定动力学入口。
- 不把 VLA 输出直接作为关节力矩或关节控制命令。
- 不在质量属性不完整时宣称完成高可信动力学对比。
- 不把 CAD 外观图等同于碰撞检测结果。
- 不把示意轨迹写成 GJM/RNS 仿真结果。

## 8. 建议执行顺序

1. 完成 12U 展示型服务星 CAD 或等效几何模型。
2. 完成 reBot 安装转接座和 `^S T_B`。
3. 填写质量、质心、惯量预算表。
4. 建立目标模型和抓取特征。
5. 输出工作空间与避让图。
6. 冻结 Stage 2 v0 输入包。
7. 开始 free-flyer、GJM、RNS 和朴素规划对比建模。
