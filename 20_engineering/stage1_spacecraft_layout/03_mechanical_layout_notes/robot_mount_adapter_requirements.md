# reBot 机械臂安装法兰/转接座需求

> 坐标记号迁移（SSOT，2026-07-09）：机械臂基座 = 安装面坐标系 `M`（= reBot URDF 基座，SSOT 已将旧“机械臂基座 `B`”并入 `M`）；服务星→安装面统一写 `T_SM`（旧 `^S T_B`）。旧 `B`、`^S T_B`、`^M T_B` 仅作兼容别名，不作主记号。见 [`../04_mass_inertia_budget/coordinate_frame_definition_v0.md`](../04_mass_inertia_budget/coordinate_frame_definition_v0.md) §0。

## 1. 用途

机械臂安装法兰/转接座用于连接服务星前端任务面与 reBot 基座，必须同时服务三件事：

1. 地面样机中固定 reBot 基座。
2. CAD/装配中表达结构安装、线缆通道和传感器接口。
3. 动力学建模中给出服务星本体到机械臂基座的固定变换。

## 2. 坐标系定义

### 2.1 服务星本体坐标系 `S`

- 记号：`S`
- 原点：第一阶段可取服务星几何参考点；质量预算完成后应能切换到质心参考点。
- 方向：建议 `+X_S` 指向前端任务面，`+Z_S` 指向上表面，`+Y_S` 按右手系确定。
- 用途：记录服务星组件位置、质心、惯量、机械臂安装变换和目标相对位姿。

### 2.2 安装面坐标系 `M`

- 记号：`M`
- 原点：安装法兰几何中心或安装孔中心阵列基准点。
- `+Z_M`：安装面法向，建议指向机械臂伸出方向。
- `+X_M`：沿服务星任务面水平方向或与主要安装孔阵列对齐。
- 用途：定义法兰孔位、安装面尺寸、线缆孔、传感器接口和装配检查。

### 2.3 机械臂基座 = 安装面坐标系 `M`（旧 `B` 仅兼容别名）

- 记号：`M`（SSOT 已将“机械臂基座 `B`”并入安装面坐标系 `M`；见 §2.2）。
- 原点和方向：与 `reBot-DevArm_fixend.urdf` 基座链接坐标系一致，即 `M`。
- 用途：作为 reBot 运动学和动力学模型的基座参考；旧记号 `B` 不再作主记号。

## 3. 固定变换定义

必须定义从服务星坐标系 `S` 到安装面坐标系 `M`（= reBot 基座）的固定变换 `T_SM`：

```text
T_SM =
[ R_SM   p_SM ]
[ 0 0 0    1  ]
```

其中：

- `R_SM`：安装面坐标系 `M` 相对服务星坐标系 `S` 的旋转矩阵。
- `p_SM = [x_M, y_M, z_M]^T`：`M` 原点在服务星坐标系 `S` 下的位置。
- 该变换必须在 CAD、质量预算表、Pinocchio/free-flyer 模型和报告图中使用同一版本号（旧记号 `^S T_B` 仅兼容）。

第一阶段不要求填写最终数值，但必须保留字段、单位、参考点和坐标方向定义。

## 4. 结构与接口需求

| 编号 | 要求 | 说明 |
|---|---|---|
| ADP-01 | 支持 reBot 基座固定。 | 安装孔、定位销、夹持结构或等效固定方式需与 reBot 实物或基座模型匹配。 |
| ADP-02 | 安装面具有明确平面基准。 | 便于 CAD 装配、加工检查和动力学坐标系定义。 |
| ADP-03 | 保留线缆通道。 | 线缆不得穿过机械臂运动包络或太阳板展开区域。 |
| ADP-04 | 预留力/力矩传感器或虚拟接口。 | 实物可安装传感器；仿真可设置末端或基座虚拟力/力矩接口。 |
| ADP-05 | 转接座质量和惯量需单独记录。 | 不得把转接座质量混入服务星本体且不标注来源。 |
| ADP-06 | 便于写入 Pinocchio/free-flyer 模型。 | 输出 `T_SM`（旧 `^S T_B`）、转接座质量属性和简化碰撞几何。 |

## 5. CAD 与仿真字段

| 字段 | 单位 | 说明 |
|---|---|---|
| `adapter_mass_kg` | kg | 转接座质量估计或 CAD 质量。 |
| `adapter_com_S_m` | m | 转接座质心在 `S` 下的位置。 |
| `adapter_inertia_S_kgm2` | kg m^2 | 转接座在指定参考点和坐标系下的惯量。 |
| `mount_frame_M_in_S` | m, rad | 安装面坐标系相对服务星坐标系的位姿。 |
| `robot_base_frame_M_in_S`（= `T_SM`，旧 `B_in_S`） | m, rad | 机械臂基座 = 安装面坐标系 `M` 相对服务星坐标系的位姿。 |
| `collision_geometry` | m | 转接座简化碰撞体，如盒体、圆柱或凸包。 |
