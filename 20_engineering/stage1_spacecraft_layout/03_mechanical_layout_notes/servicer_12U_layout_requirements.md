# 12U 展示型服务星布局要求

## 1. 用途

12U 服务星作为竞赛展示主模型，用于支撑总体方案汇报、CAD 渲染图、工作空间示意、任务视频脚本、自由漂浮动力学仿真输入和 GJM/RNS 反作用抑制对比图。

本文件只定义 12U 展示型服务星的设计任务和输出要求，不表示 CAD、动力学仿真或实物样机已经完成。

## 2. 总体分舱

| 分舱 | 位置 | 主要内容 | 设计目的 |
|---|---|---|---|
| 前端任务舱 | 面向目标的前端 | reBot 安装点、相机、任务照明、视觉标记、抓取辅助接口 | 支持目标接近、识别、捕获和演示拍摄。 |
| 中部平台舱 | 服务星中部 | OBC、EPS、电池、反作用轮、结构主梁、配重调节空间 | 形成稳定质量中心，便于控制质心和惯量。 |
| 后部推进/通信舱 | 远离目标的后端 | 推进占位、通信天线、地面调试接口、线缆出口 | 支持任务叙事和系统完整性表达。 |

## 3. 任务叙事支持

12U 展示型服务星必须同时支持以下三类报告叙事：

1. 目标捕获：服务星接近失效小卫星，识别目标特征，规划机械臂捕获动作。
2. 在轨服务：服务星对带标准接口的目标执行把手抓取、接口接近或辅助操作。
3. 碎片清除：服务星接近圆柱形火箭适配器/壳段，通过限定抓取区域完成清除任务展示。

每类叙事都应明确目标类型、接近方向、相机观察方向、机械臂抓取特征、禁止碰撞区域和演示镜头。

## 4. 机械臂安装要求

| 编号 | 要求 | 说明 |
|---|---|---|
| 12U-LR-01 | 机械臂安装点尽量靠近质心投影。 | 降低机械臂运动对服务星姿态的耦合影响，便于第二阶段形成 RNS 与朴素规划对比。 |
| 12U-LR-02 | 安装点不得与相机、太阳板、天线和线缆通道冲突。 | 安装点周围需保留装配、维护和可视化空间。 |
| 12U-LR-03 | 安装面应能定义明确的安装面/机械臂基座坐标系 `M`（=reBot URDF 基座，SSOT）。 | 用于后续写入 Pinocchio/free-flyer 模型。 |
| 12U-LR-04 | 机械臂折叠姿态不得遮挡主要相机视场。 | 支持开机、搜索和安全停机镜头。 |
| 12U-LR-05 | 展开姿态应覆盖目标捕获、在轨服务和碎片清除的代表性抓取点。 | 工作空间图应与目标模型叠加展示。 |

## 5. 必须输出的图件

| 图件 | 目的 | 状态要求 |
|---|---|---|
| CAD 渲染图 | 展示 12U 服务星整体构型、任务面和机械臂安装。 | 后续 CAD 完成后生成；当前阶段只定义需求。 |
| 工作空间包络图 | 展示机械臂可达区域、目标抓取点和不可达区域。 | 后续由 CAD/URDF/运动学工具生成；当前阶段定义图层。 |
| 太阳板/相机/机械臂避让图 | 展示太阳板展开边界、相机视场、机械臂运动包络之间的关系。 | 必须标出最小间隙和遮挡风险。 |
| 任务叙事组合图 | 支撑目标捕获、在轨服务、碎片清除三种叙事。 | 可用于竞赛汇报和视频分镜。 |

## 6. 对 GJM/RNS 对比的参数要求

为了输出“朴素规划 vs RNS 规划”所需的几何与惯量参数，12U 服务星必须记录：

- 服务星总质量。
- 服务星质心在本体坐标系中的位置。
- 服务星绕质心的 3x3 惯量矩阵。
- reBot 基座相对服务星本体坐标系的位姿变换。
- 机械臂各连杆质量属性来源。
- 目标模型的质量、质心、惯量和碰撞包络。
- 抓取点在目标坐标系中的位姿。
- 太阳板、天线、相机和服务星本体的简化碰撞几何。
