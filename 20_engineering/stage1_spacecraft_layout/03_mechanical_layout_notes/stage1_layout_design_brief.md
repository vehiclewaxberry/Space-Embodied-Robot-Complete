# 第一阶段卫星与机械臂布局设计任务书

## 1. 阶段定位

本阶段建立 6U/12U 缩比服务星 + reBot 等效空间机械臂 + 非合作目标星/碎片模型的布局设计基线，用于未来飞行器大赛中的航天飞行器总体方案、自由漂浮动力学仿真和地面样机验证。

本阶段只形成布局设计任务书、建模需求、质量/质心/惯量预算模板、工作空间与避让检查清单。当前不声明 CAD 已完成，不声明动力学仿真已完成，不虚构任何轨迹跟踪、基座姿态扰动或接触控制结果。

## 2. 设计基线角色

| 对象 | 当前角色 | 边界说明 |
|---|---|---|
| OreSat | 6U/12U 机械结构、板卡堆叠、太阳板和结构接口参考 | OreSat 是机械结构参考，不是本项目最终原创设计；后续竞赛模型必须形成自己的任务面、机械臂安装、目标交会和展示叙事布局。 |
| reBot | 地面样机与动力学等效机械臂 | reBot 用于建立可落地的机械臂工作空间、安装边界、地面演示和自由漂浮动力学等效模型。 |
| `reBot-DevArm_fixend.urdf` | 后续动力学建模入口 | 后续动力学使用 `reBot-DevArm_fixend.urdf`，当前布局必须给出服务星坐标系到安装面坐标系 `M`（=reBot URDF 基座）的变换 `T_SM`，便于写入 Pinocchio/free-flyer 模型。 |
| 目标星/碎片模型 | 非合作目标、碎片清除和标准服务对象的展示对象 | 目标模型只作为任务场景、视觉识别、抓取接口和碰撞包络定义，不在本阶段假设已完成捕获仿真。 |

## 3. 与动力学和竞赛展示的关系

当前布局必须服务于 GJM/RNS 反作用抑制对比图。布局设计需要保留服务星质量、质心、惯量、机械臂安装变换和目标模型参数，使第二阶段能够比较朴素规划与 RNS 规划下的基座姿态扰动。

当前布局也必须服务于实物演示视频。机械臂安装面、相机视场、目标抓取特征、太阳板避让和折叠/展开姿态，应能支撑一个可拍摄、可解释、可复现实物演示流程。

VLA 只作为高层任务决策，不直接输出关节力矩。VLA 可用于选择任务类型、目标类别、抓取点候选和操作阶段，但低层轨迹、关节速度、关节力矩、接触控制和基座反作用抑制应由传统规划、动力学模型、GJM/RNS 与控制器承担。

## 4. 本阶段交付物

1. 6U 服务星快速布局需求。
2. 12U 展示型服务星布局需求。
3. reBot 机械臂安装法兰/转接座需求。
4. 非合作目标星、圆柱碎片和标准服务对象需求。
5. 质量、质心、惯量预算 CSV 模板与填写说明。
6. 工作空间与避让检查清单。
7. 碰撞约束与可视化需求。
8. 第一阶段到第二阶段的转换计划。

## 5. 阶段边界

- 不修改已有动力学代码。
- 不修改已有 URDF。
- 不把 OreSat 直接包装为最终原创服务星。
- 不把 reBot 等同于真实在轨机械臂硬件，只将其作为地面样机和动力学等效机械臂。
- 不把 VLA 输出写成低层控制命令。
- 不虚构 CAD 渲染图、工作空间图、GJM/RNS 曲线或实物演示结果。

## 6. 通过条件

第一阶段通过时，应至少具备以下可追踪输入：

- 服务星外形、任务面、平台舱、推进/通信舱的布局定义。
- reBot 基座安装面、安装坐标系和服务星到机械臂基座的变换定义。
- 目标模型的尺寸、质量、惯量、抓取特征、视觉标记和碰撞包络字段。
- 能填写到第二阶段动力学模型中的质量、质心和惯量预算表。
- 能支撑竞赛报告和视频脚本的工作空间、避让和任务叙事检查项。
