# 目标星与碎片模型需求

## 1. 用途

本文件定义第一阶段需要建立的三类目标模型。目标模型用于竞赛报告叙事、视觉识别、机械臂抓取工作空间检查、碰撞包络定义和第二阶段自由漂浮动力学仿真输入。

当前阶段只定义目标模型需求和参数字段，不声明目标 CAD、视觉检测、抓取仿真或接触控制已经完成。

## 2. 通用坐标与数据要求

每个目标模型必须定义目标坐标系 `T`：

- 原点：目标几何中心或目标质心，二者不一致时必须分别记录。
- `+X_T`：推荐指向主要抓取接口或服务星接近方向。
- `+Z_T`：推荐指向目标上表面或太阳板法向。
- 所有抓取特征、AprilTag、碰撞包络和惯量矩阵必须说明参考坐标系。

每类目标都必须输出以下字段：

| 字段 | 说明 |
|---|---|
| 外形尺寸 | 主体长宽高、圆柱直径/长度、太阳板展开尺寸、天线长度等。 |
| 质量估计 | 总质量和主要部件质量分配，标注来源与可信度。 |
| 惯量估计 | 在目标坐标系或质心坐标系下的 `Ixx, Iyy, Izz, Ixy, Ixz, Iyz`。 |
| 抓取特征 | 把手、环、对接接口、边缘、加强筋或指定抓取区。 |
| 视觉标记 | AprilTag 或等效视觉标记的位置、朝向、尺寸和编号。 |
| 碰撞包络 | 简化碰撞体、禁入区域和允许接触区域。 |
| 报告场景 | 用于竞赛报告和视频脚本的任务描述。 |

## 3. Target-1：失效 6U/12U 小卫星

### 3.1 模型定位

Target-1 表示带太阳板和天线的失效小卫星，可作为非合作目标星，用于展示目标识别、接近、机械臂捕获和姿态扰动抑制。

### 3.2 参数定义

| 项目 | 定义要求 |
|---|---|
| 外形尺寸 | 至少定义 `body_lx_m, body_ly_m, body_lz_m`；若区分 6U/12U，应分别记录；太阳板需定义折叠尺寸和展开跨度；天线需定义长度和安装方向。 |
| 质量估计 | 定义 `target_mass_kg`、主体质量、太阳板质量、天线质量；来源可为 CAD、标准估算或人工假设，必须标注可信度。 |
| 惯量估计 | 初始可按长方体主体 + 平板太阳板 + 细杆天线估算，后续由 CAD 更新。 |
| 抓取特征 | 可设置失效卫星把手、结构边框、预设抓取环或对接接口；必须明确允许抓取区域。 |
| 视觉标记/AprilTag | 建议布置在服务星接近方向可见的主体面或抓取接口附近，避免被太阳板遮挡。 |
| 碰撞包络 | 主体盒体、太阳板薄板包络、天线细长包络和禁碰区域需分开建模。 |
| 报告场景 | 服务星接近失效小卫星，视觉识别 AprilTag 和抓取接口，reBot 执行捕获动作，后续用于展示 RNS 抑制基座姿态扰动。 |

## 4. Target-2：圆柱形火箭适配器/壳段

### 4.1 模型定位

Target-2 表示圆柱形火箭适配器、壳段或空间碎片，用于碎片清除任务叙事。该目标通常缺少标准接口，抓取区域和禁碰区域需要明确划分。

### 4.2 参数定义

| 项目 | 定义要求 |
|---|---|
| 外形尺寸 | 定义 `cylinder_diameter_m`、`cylinder_length_m`、壁厚或端面特征；若有法兰或加强筋，应单独记录。 |
| 质量估计 | 定义总质量和质量分布假设；轻薄壳体和实体圆柱不得混用同一惯量假设。 |
| 惯量估计 | 初始可按薄壁圆柱或厚壁圆柱公式估算，必须记录采用的模型。 |
| 抓取特征 | 可定义圆柱外表面指定抓取带、端面环、加强筋或夹持区域；非抓取区域必须标为禁碰。 |
| 视觉标记/AprilTag | 可安装在圆柱端面或外圆柱面局部平面支架上；需记录标记法向。 |
| 碰撞包络 | 至少包含圆柱主体包络、端面包络和抓取禁入区；仿真中应能显示圆柱轴线。 |
| 报告场景 | 服务星接近圆柱碎片，识别端面/抓取带，机械臂以受限速度接近并完成清除任务展示。 |

## 5. Target-3：带标准抓取接口的服务对象

### 5.1 模型定位

Target-3 表示带标准抓取接口的服务对象，例如把手、环、对接接口或模块化服务端口。该目标用于在轨服务叙事，强调接口识别、低速接近和可重复演示。

### 5.2 参数定义

| 项目 | 定义要求 |
|---|---|
| 外形尺寸 | 定义主体尺寸、标准把手尺寸、环直径、接口深度、对接面尺寸和安装高度。 |
| 质量估计 | 定义主体质量、接口质量和可替换服务模块质量；所有估计需标注来源。 |
| 惯量估计 | 初始可按主体盒体 + 接口局部质量估算，后续由 CAD 或测量修正。 |
| 抓取特征 | 必须定义标准把手、环或对接接口的中心位姿、允许接触面和禁止碰撞边界。 |
| 视觉标记/AprilTag | 标记应靠近标准接口，且在机械臂接近前可被相机稳定看到。 |
| 碰撞包络 | 主体包络、接口包络、允许接触面和禁碰区域应分层建模。 |
| 报告场景 | 服务星识别标准服务接口，VLA 给出任务阶段选择，传统规划和控制完成接口接近与抓取演示。 |

## 6. 惯量估算记录要求

惯量估计不得只写最终数字，应保留估算来源：

- `shape_model`：长方体、薄板、薄壁圆柱、厚壁圆柱或 CAD。
- `reference_frame`：惯量矩阵参考坐标系。
- `reference_point`：几何中心、质心或指定装配点。
- `confidence`：`low`、`medium`、`high`。
- `update_plan`：后续由 CAD、称重或实验辨识更新。

## 7. 通过条件

- [ ] Target-1 失效小卫星字段已建立。
- [ ] Target-2 圆柱碎片字段已建立。
- [ ] Target-3 标准服务对象字段已建立。
- [ ] 每类目标均定义外形尺寸、质量估计、惯量估计、抓取特征、AprilTag、碰撞包络和报告场景。
- [ ] 所有目标参数均能进入第二阶段动力学和碰撞可视化模型。

## 8. 原英文 v0 的补充约定（2026-09-06 合并）

本文件合并了原 `target_models_requirements_v0.md`，三类目标的共同字段和任务场景保留于上文；原英文全文可从统一整理账本恢复。

- 三类模型均保留 CAD 原点、几何版本与估算来源。实际尺寸待核查时写 `manual_review_required`；未选定几何、材料、壁厚或密度时，质量与惯量写 `TBD`。模板建立不代表实测参数已取得。
- 失效小卫星可选边缘、导轨或演示用抓取区；标记尽量避开接触点。识别、接近、预抓取、捕获、稳定化是原场景顺序，尚需逐阶段结果证明。
- 圆柱目标可用端环、局部把手、夹持带；接近方向可为轴向或径向。标记宜放平支架/平标记板；曲面引起的识别歧义只有经过专项测试才能接受。
- 合作目标标记在最终抓取姿态仍需可见；连接器、标记及其他非接触表面应列为禁碰区。工具捕获、检查与转运是该类目标的候选演示场景。
- 目标数据进入 `T_ST`、初始相对位姿、碰撞检查和后续质量惯量输入。视觉标记存在不表示感知代码已实现；接触成功需要对应地面试验或仿真证据。
