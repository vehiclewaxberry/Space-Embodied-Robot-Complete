# 6U 服务星快速布局要求

## 1. 用途

6U 服务星用于第一阶段快速建立缩比服务星布局基线，优先服务机械臂安装、相机视场、工作空间避让、质量/质心/惯量估算和后续自由漂浮动力学建模。该模型可作为早期验证模型，不等同于最终竞赛展示主模型。

## 2. 坐标与分区约定

建议在第一阶段统一采用以下工程约定，并在 CAD 或示意图中显式标注：

- 服务星本体坐标系 `S`：原点可先取几何中心或设计参考点，后续由质量预算更新为质心参考；`+X_S` 指向前端任务面，`+Z_S` 指向上表面，`+Y_S` 按右手系确定。
- 前端任务面：机械臂、相机、任务照明、抓取辅助标记和目标接近方向的主要布置面。
- 中部平台舱：OBC、EPS、电池、反作用轮和结构主承力件占位区。
- 后部接口舱：通信、推进、调试接口、线缆出口和地面支撑接口占位区。

## 3. 布局要求

| 编号 | 要求 | 输出形式 |
|---|---|---|
| 6U-LR-01 | 机械臂安装在前端任务面，安装位置应便于末端执行器从服务星前方接近目标。 | 前端任务面布局图、安装点坐标。 |
| 6U-LR-02 | 相机与机械臂工作空间尽量同轴或近同轴，避免相机只看到机械臂背面或被本体遮挡。 | 相机光轴、机械臂基座轴线、末端工作空间示意。 |
| 6U-LR-03 | 中部放置 OBC/EPS/电池/反作用轮占位，优先靠近结构中心并便于调整质心。 | 中部平台舱占位图、组件清单。 |
| 6U-LR-04 | 后部放置通信/推进/接口占位，避免与前端机械臂和相机线路冲突。 | 后部接口舱占位图、接口方向说明。 |
| 6U-LR-05 | 两侧太阳板避开机械臂最大工作空间，不得侵入折叠、展开、捕获和安全姿态的关键路径。 | 太阳板展开边界、机械臂包络叠加图。 |
| 6U-LR-06 | 输出质量、质心、惯量估计表，所有条目应标注来源和可信度。 | `04_mass_inertia_budget` 表格。 |
| 6U-LR-07 | 输出机械臂折叠姿态和展开姿态，用于 CAD 检查、视频脚本和后续仿真初值。 | 折叠姿态图、展开姿态图、关节角记录表。 |

## 4. 质量与惯量输出要求

6U 模型应至少输出下列质量属性字段：

| 项目 | 要求 |
|---|---|
| 总质量 | 给出 v0 估计值、来源和可信度；不得写成实测值，除非已有称重记录。 |
| 质心位置 | 在服务星坐标系 `S` 下给出 `x_m, y_m, z_m`。 |
| 惯量矩阵 | 在同一参考点和同一坐标系下给出 `Ixx, Iyy, Izz, Ixy, Ixz, Iyz`。 |
| 机械臂质量属性 | reBot 本体质量属性应与 URDF 或实际测量来源区分记录。 |
| 太阳板状态 | 折叠和展开状态可能改变碰撞包络，应分开记录几何状态；质量属性变化按建模策略说明。 |

## 5. 折叠与展开姿态要求

- 折叠姿态应满足运输、桌面展示和安全停机状态，不与服务星本体、相机、天线、太阳板发生几何干涉。
- 展开姿态应满足前向目标捕获演示，末端执行器能够进入目标抓取特征附近。
- 两种姿态都应记录关节角、末端位姿、相机可见性和最小间隙。
- 若后续采用 `reBot-DevArm_fixend.urdf`，姿态记录应能映射到该 URDF 的关节命名。

## 6. 检查清单

- [ ] 前端任务面已定义。
- [ ] 机械臂安装点坐标已定义。
- [ ] 相机光轴和机械臂工作空间关系已定义。
- [ ] 中部平台舱占位已定义。
- [ ] 后部通信/推进/接口占位已定义。
- [ ] 太阳板不侵入机械臂最大工作空间。
- [ ] 折叠姿态已记录。
- [ ] 展开姿态已记录。
- [ ] 质量、质心、惯量估算表已建立。
