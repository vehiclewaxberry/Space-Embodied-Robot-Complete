## 2. 实质断裂（❌ 必须修正）

### D-RECON-01｜太阳翼根部**站位完全错位**（HIGH）

- Codex `SOLAR-ROOT-01`：根部基座 `X=[-79,-43]`，耳站位 `X=[-75,-65]` 与 `[-57,-47]`，
  HDRM 杆 `X=-160, 40`，机构从 **bus 侧 |Y|=113.15 向外** 伸展。
- 收拢翼板（B5/110 冻结）：`X=[-174.5, 52.5]`（110 实测包络 X[-177.5, 55.5]）。
- **NATIVE-01 把铰链放在 `X=[126,174]`、销轴 `Y=±76`（bus 内侧）** ——
  既不在翼板 X 跨度内，也与"外挂式书本折叠翼根"架构相反。
- 后果：本轮的 `05/06_Solar_Array_Root_*`（各 9 件）**几何站位无效**，
  需按 Codex 的 X[-79,-43] / 外挂 |Y|≥113.15 重做。
- 根因：本轮只用了"冻结翼根 Y=±110, Z=-105.65"这一条数字，
  **未读 `100_Mechanical_Continuation` 的 SOLAR-ROOT-01 章节**（该目录在 120 阶段
  被我登记为冻结只读并锁哈希，但内容从未打开）。

### D-RECON-02｜ARM-STOW 鞍座 Z 高度**相差一个数量级**（MEDIUM，非缺陷但须裁决）

- Codex `ARM-STOW-01`：主鞍座源包络 `X=[40,90], Y=[-30,30], Z=[88,110.15]`；
  腕/夹爪软支承 `X=[-150,-110], Y=[-30,30], Z=[88,110.15]`——**鞍座顶面在舱顶 110.15**。
- NATIVE-01：主鞍座 `X=[10,60]`、前臂 `[-40,0]`、腕 `[-100,-40]`，
  接触高 **Z=234.77 / 248.49 / 253.80**（由 130 真实厂商几何 + 25° 时钟收拢位形顶点实测）。
- 判定：**两者不是同一件事**。Codex 的是 B601 LOD1 之前的**占位源包络**
  （其文中明言 "Contact faces are candidates pending B601 LOD1"）；
  NATIVE-01 的是**真实几何 FK 实测**。**NATIVE-01 值取代 Codex 占位值**，
  但 Codex 的 X 站位 [40,90] / [-150,-110] 与本轮 [10,60] / [-100,-40] 的差异
  源于收拢位形不同（Codex 无位形，本轮=25° 提案），须随时钟角一并裁决。

## 3. 丢失的负结果（❌ 必须补回，属治理违规风险）

Codex 明确要求："The primary geometry must retain this negative result" 且
"No display component is hidden, thinned, or moved to create a false pass."

| 负结果 | Codex 值 | NATIVE-01 现状 |
|---|---|---|
| **C5 收拢翼包超宽** | 收拢包宽 238.3 > 可用 226.3，**超 12.0 mm** | ❌ 未继承（本阶段无翼板，也未登记该 HOLD） |
| **翼根机构宽度下限** | 双侧根部硬件达 \|Y\|=151.15 → 机构下限宽 **302.3 mm** | ❌ 未继承；且本轮把机构移到 bus 内侧（Y=±76），**在构造上"消除"了超宽** |

**第二条尤其严重**：把机构内移使超宽问题凭空消失，正是 Codex 合同禁止的
"moved to create a false pass"。本轮并非有意规避（是因未读该文件），但结果等同。
