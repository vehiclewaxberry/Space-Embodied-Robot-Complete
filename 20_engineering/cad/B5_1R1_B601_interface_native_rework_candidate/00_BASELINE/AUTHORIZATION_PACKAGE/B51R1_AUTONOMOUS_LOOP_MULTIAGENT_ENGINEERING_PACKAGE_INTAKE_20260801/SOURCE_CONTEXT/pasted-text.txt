# 二、我对当前 G1A 的自主技术裁决

## 1. Datum 自动采用

```text
±101.65 mm ＝ 纵梁中心轴
±110.15 mm ＝ 主承力结构表面
±113.15 mm ＝ 可拆面板外表面与 footprint 层
±105.65 mm ＝ 历史未解析字段，保留但禁止驱动几何
```

这保留了历史证据，同时避免为了过 Gate 强行猜测 105.65 mm 的物理语义。现有执行图也明确区分纵梁轴、承力面和可拆面板，并禁止让面板获得主载荷路径信用。

## 2. 不直接批准当前反直觉命名

当前待冻结方案存在一个明显风险：

* `CS_CHILD_JOINT_<JOINT>`被放在父 Carrier；
* `CS_PARENT_JOINT_<JOINT>`被放在子 Carrier。

它虽然可以内部自洽，但极易导致：

* API 查错对象；
* parent/child方向误解；
* joint ownership写反；
* 后续控制人员理解错误。

由于目前原生 Carrier 仍为 `0/10`，现在修正成本最低。因此改为：

```text
CS_LINK_<LINK>

CS_JOINT_<JOINT>_PARENT_SIDE
CS_JOINT_<JOINT>_CHILD_SIDE

AXIS_<JOINT>
PLANE_ZERO_<JOINT>

CS_VISUAL_MOUNT_<LINK>
```

所有旧名称只保留在只读 alias register，禁止用于 API 查询，也不创建重复 CAD 特征。

### Ownership

父 Carrier拥有：

```text
CS_JOINT_<JOINT>_PARENT_SIDE
```

子 Carrier拥有：

```text
CS_JOINT_<JOINT>_CHILD_SIDE
AXIS_<JOINT>
PLANE_ZERO_<JOINT>
```

两个P分支则分别由左右指 Carrier拥有自己的轴和零位，不再存在命名方向歧义。

# 三、容差不再需要逐项找你签字

采用两级机器验收。

## 名义门槛

| 项目          |                  门槛 |
| ----------- | ------------------: |
| 坐标系平移回读     |            `1e-8 m` |
| 坐标系旋转回读     |          `1e-8 rad` |
| Link FK平移   |            `5e-6 m` |
| Link FK旋转   |          `5e-6 rad` |
| R关节回读/q0/限位 |          `1e-6 rad` |
| P关节回读/q0/限位 |            `1e-6 m` |
| 同文档回q0 FK   | `5e-6 m / 5e-6 rad` |

## 自动重复性处理

如果首次超限：

1. 保留首次失败；
2. 相同条件重复10次；
3. 计算最大值、均值、标准差和原始序列；
4. 在硬上限内，可以判：

```text
PASS_WITH_MEASURED_REPEATABILITY_BOUND_AUTHORING_ONLY
```

硬上限：

| 项目       |          自治硬上限 |
| -------- | -------------: |
| 坐标系平移/旋转 | `1e-7 m / rad` |
| FK平移/旋转  | `2e-5 m / rad` |
| R/P标量回读  | `5e-6 rad / m` |

这种条件通过只允许继续 CAD 创作，**不能替代最终正式 T005，也不能释放控制模型**。超过硬上限则自动 fail-closed，不向你反复索要放宽门槛。

# 五、Stage A残留锁文件自治处置

当前6字节`~$`文件不再等待人工删除授权，而采用：

```text
HASH_AND_QUARANTINE_NOT_DELETE
```

条件：

* SolidWorks进程数为0；
* 文件大小精确为6字节；
* SHA-256精确匹配已登记值。

动作：

1. 复制/移动到候选目录的锁文件隔离区；
2. 保留原字节和哈希；
3. 复算 Stage A 哈希；
4. 确认Stage A未变化；
5. 生成处置收据。

不永久删除，不碰正式Stage A文件。

H9不强制自主拍板。

```text
DUAL_BRANCH_MODE_A_MODE_B
```
