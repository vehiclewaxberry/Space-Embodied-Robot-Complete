# O11：25° 时钟角量化裁决报告

日期：2026-07-27　机器数据：`design/o11_clocking_adjudication.json`
判据：用户 2026-07-27 指定七项（高度／宽度／与主结构间隙／鞍座数量／解锁路径／
太阳翼避让／相机遮挡）。几何源：130 真实厂商网格顶点 + NATIVE-01 STOWED 导出结构
（3226 三角）+ Codex FIDELITY-01A 冻结的翼包络与 GNSS 站位。

## 一、决定性发现：时钟角与 q1 完全冗余（F-O11-1）

在 clock = 0/15/25/35° 四种情况下分别做同一约束下的位形优化，结果：

| 时钟角 | 优化得到的 q1 | **clock + q1** |
|---|---|---|
| 0° | 160.322°（顶在限位） | 160.322 |
| 15° | 153.322° | **168.322** |
| 25° | 143.322° | **168.322** |
| 35° | 133.322° | **168.322** |

**所需的世界系 J1 转角恒为 168.322°。** 时钟角只是把这个转角搬进关节限位里，
它与 q1 是同一个自由度的两种记法——**世界系收拢位形在所有可行时钟角下完全相同**。

由此得到硬性结论：

```
最小必需时钟角 c_min = 168.322° − 160.428°(joint1 限位) = 7.894°
25° 的 q1 余量 = 25 − 7.894 = 17.106°
```

**七项判据在各可行时钟角之间不构成区分**（表中 106.36 / 106.34 / 105.96 之类的
差异是 0.25° 网格伪影）。它们真正区分的是**"有时钟角"与"无时钟角"**。

## 二、七项判据实测（clock=0 vs 有时钟角）

| 判据 | clock=0（无时钟） | 有时钟角（≥7.894°） | 判定 |
|---|---|---|---|
| **C2 宽度** | max\|Y\| = **151.74** > 113.15，**超 38.59mm** | 106.3，余量 6.8mm | **clock=0 出局** |
| C1 高度 | 345.5（舱面上 232） | 354.1（舱面上 241） | 相当 |
| C3 间隙（可动段） | 0.02mm | 0.00mm | 均贴合，见三 |
| C4 鞍座 | 28 窗口，塔高 48–107.5 | 28 窗口，塔高 65.3–117.8 | 均在 150 限内 |
| C5 解锁 | 首动 q3−5° → 0.17mm | 首动 q2+5° → 1.13mm | 均偏紧 |
| C6 翼避让 | clear（0 顶点入翼包络） | clear | 均通过 |
| C7 GNSS 遮挡 | 24.15% 立体角 | 23.17% | 相当 |

**clock=0 的失效机理**：q1 被限位卡在 160.322°，差 7.894° 到不了所需姿态，
优化器被迫改用另一族位形，横向甩出到 |Y|=151.74——**破整星半宽 38.59mm**。
这与 Codex 记录的"根部机构下限宽 302.3"是同一类超宽负结果，但成因不同
（那是翼根硬件，这是臂位形）。

## 三、必须同时报告的负结果：三个"最优"位形都贴着结构

| 位形 | 可动段最小间隙 | 鞍座塔高 | 首动后间隙 |
|---|---|---|---|
| clock=25 优化解 | **0.00mm** | 65.3–117.8 ✅ | q2+5° → 1.13mm |
| clock=35 优化解 | 0.23mm | 61.6–**169.0** ❌超限 | q3−5° → 6.48mm |
| **交付 v2（25°）** | **6.40mm** | 108.8–**182.9** ❌超限 | q2+5° → **36.37mm** |

**没有任何候选同时满足"可动段间隙 ≥8mm"与"鞍座塔高 ≤150mm"。**
优化器用的是包围盒角点代理，它在角点层面满足了 [deck+8, deck+150] 带约束，
但顶点层面仍贴合——说明该代理对本问题**不保守**，需改用顶点级约束重搜。

交付 v2 是三者中工程上最可用的（间隙 6.4mm、首动后 36.4mm），代价是塔高超限 32.9mm。

## 四、裁决

```
O11_RULING = CLOCKING_REQUIRED_VALUE_FREE_ABOVE_7.894DEG
```

1. **时钟角是必需的**，不是可选优化——无时钟角时臂横向破包络 38.59mm。
   `STOW_NO_CLOCK_COMPARATOR` 配置由"待比较"降级为**已证伪的对照组**，
   保留在装配中作为反例证据，不再作为候选方案。
2. **25° 的具体数值不由七项判据决定**，由 q1 限位余量决定：任何 c ≥ 7.894° 都给出
   相同的世界系位形；25° 提供 17.106° 余量，是稳健取值。**建议批准 25°**，
   理由改写为"限位余量"，不再声称是七项判据择优的结果。
3. **收拢关节向量仍为 CANDIDATE_HOLD**——三个候选都过不了"间隙 ≥8mm ∧ 塔高 ≤150mm"
   双约束。新增开放项 **O13**：以顶点级间隙为约束重搜收拢向量。
4. ARM-STOW 的 X 站位差异（Codex `[40,90]/[-150,-110]` vs 本轮 `[10,60]/[-100,-40]`）
   —— 实测支承窗口为 X[-113,187]（v2）或 X[-93,187]（优化解），**两者都比 Codex
   的两窗口方案宽得多**；Codex 的窗口基于 B601 LOD1 之前的占位包络，予以取代，
   最终鞍座站位随 O13 的向量一并定案。

## 五、方法学限制（不得省略）

- C3/C5 的"贴合"判定剔除了 G06 基座与 G01——基座与安装适配器是**螺栓贴合面**，
  0 距离是设计意图。全臂口径的 0.03–0.05mm 是该贴合面，不是干涉。
- C7 用 GNSS 天顶锥（顶点 (100,0,113.15)、半角 70°、方位 2°×天顶 2° 分箱、sinθ 加权）。
  该站位继承自 Codex FIDELITY-01A，**NATIVE-01 尚未建 GNSS 实体**，属参考评估。
- 收拢态 Z 上限仍 `UNKNOWN`（人工裁决保持）。高度判据只能做**相对比较**，
  不能判任何候选"合规"。
- 优化器为确定性坐标下降（多起点、4°→1°→0.25° 三级网格），非全局最优证明。
