# M4 工程研究与验证办法

## 1. 本轮研究问题

本轮不以“把 CAD 画满”为完成标准，而以四个可证伪问题为主线：

1. 数字样机中的每个组件、构型和坐标变换，能否追溯到冻结输入或被明确标为 `UNRESOLVED/HOLD`？
2. 九构型的质量、质心、惯量、包围盒、碰撞和关节状态，哪些可以作为可重复的数字模型量，哪些仍缺物理权威？
3. M3R—B601—12U、夹爪导轨和太阳翼铰链三条关键机械链，分别缺少哪一项尺寸、材料、载荷或试验，才能进入结构/机构验证？
4. 在不冒充高保真接触的前提下，能否建立一个守恒量可检验、未知输入会自动封锁动作的自由漂浮抓取研究内核？

## 2. 模型分层

| 层级 | 模型 | 可回答的问题 | 不能回答的问题 |
|---|---|---|---|
| G0 | 包络、坐标系、拓扑 | 组件是否存在、位置语义、粗碰撞范围 | 装配可制造性、精密干涉 |
| G1 | 中性 B-Rep 数字样机 | 实体有效性、体积、包围盒、冻结界面一致性 | 飞行材料强度、实际装配偏差 |
| M0 | 低置信度数字质量模型 | 研究场景中的刚体质量/惯量输入和敏感度 | 实测整星质量特性、飞行真值 |
| D0 | 自由漂浮刚体诊断模型 | 线/角动量、事件状态机、动作安全掩码 | 接触压力、柔性响应、抓取稳定裕度 |
| D1 | 经参数辨识的接触/多体模型 | 接触冲量、抓取后耦合响应 | 仅在摩擦、刚度、阻尼、时延等经试验或批准后成立 |
| S1 | 受控结构有限元模型 | 应力、变形、接头载荷、模态 | 只有结构入口门通过后才允许执行和记入裕度 |

层级之间不得自动升级。`G1 PASS` 不等于 `S1 PASS`，`D0 tests PASS` 也不等于接触动力学或 RL 已验证。

## 3. 闭环执行法

每次 Loop 必须按同一顺序闭合：

1. **Authority**：冻结输入路径、SHA-256、单位、坐标系、配置和来源分类。
2. **Question**：只提出一个可由当前模型层级回答的工程问题。
3. **Model**：建立最小充分模型，所有未获授权的量保持 `null/HOLD`。
4. **Check**：至少执行一个独立数值检查，例如重开、形状有效性、质量重组、旋转矩阵正交性、惯量正定性、动量守恒或 fail-closed 动作测试。
5. **Adversarial review**：检查重复计质量、坐标系混用、诊断几何冒充释放几何、预算量冒充实测量、测试 fixture 冒充生产接口。
6. **Decision**：只签发与证据同等范围的 token；其余能力维持 `HOLD`。
7. **ECR**：任何冻结数值变化均记录旧值、新值、单位、来源、影响项、验证证据和处置。

## 4. 九构型研究设计

九构型是一个统一配置轴，而不是九个互不相干的模型副本：

- 太阳翼轴：双侧展开、左失效、右失效、双侧失效；
- 机械臂轴：在轨收拢、任务准备、预抓取；
- 捕获轴：22 kg 与 150 kg 目标捕获。

每个构型必须绑定相同字段集合：组件集合、关节向量、刚体变换、质量、质心、惯量、包围盒、碰撞资源、来源、置信度与状态。缺少关节向量或变换时，配置可以作为语义记录存在，但不得聚合出伪精确的系统惯量。

## 5. 质量与不确定度方法

采用非重叠组件集合，并按以下优先级选择来源：

`MEASURED > CAD_DERIVED > MATERIAL_DERIVED > BUDGETED > PROVISIONAL > UNKNOWN`

- 标量质量写明 `kg`；质心写明参考坐标系和 `m`；惯量写明参考点、轴和 `kg*m^2`。
- 只有完整的质量、变换和惯量输入才能使用平行轴定理聚合。
- 现有 12U、太阳翼及目标数据可作为低置信度数字研究输入，但不能改写为实测或飞行值。
- 不确定度未知时值为 `null`，状态为 `HOLD`；不得用零表示未知。
- 捕获目标进入系统聚合前，必须明确捕获变换和是否形成刚性连接。

## 6. 三条关键机械闭环

### M3R—B601—12U

冻结孔系、基准、安装面和时钟角；补齐紧固件规格、夹紧长度、预紧控制、摩擦分散、嵌件/螺纹啮合、外载荷及允许值。未来的接头分析按 NASA-STD-5020 和项目裁剪后的结构标准执行；当前只建立需求与证据槽位。

### 夹爪导轨

将行程、轨—掌几何间隙、直线度、平行度、热膨胀、表面处理、真空润滑、执行器力和目标接触限制分开管理。零 B-Rep 重叠只能证明名义几何不相交，不能证明热真空、磨损和公差条件下不卡滞。

### 太阳翼/HDRM

以 `release -> drive -> deploy -> latch -> positive indication` 为状态链，分别记录最小/最大驱动力矩、预载、释放冲击、冗余、寿命循环和故障模式。当前 HDRM 和铰链数据不足时只发布包络与接口，不发布机构可靠性结论。

## 7. 动力学与抓取研究顺序

1. 先验证自由漂浮刚体模型的线动量和角动量残差。
2. 再验证预抓取、接触候选、捕获和中止事件的确定性状态转换。
3. 以 22 kg / 0.5 deg/s 和 150 kg / 3 deg/s 为边界锚点，运行参数敏感度；这些是场景输入，不是实测任务条件。
4. 摩擦、接触刚度/阻尼、夹持力、目标允许压力、结构柔性任一未知时，生产接触动作必须被安全掩码封锁。
5. 只有经试验/辨识的接触参数、完整质量特性和通过的模型验证证据齐备后，才进入接触动力学与策略训练。

该顺序采用 NASA-STD-7009 的模型目的、配置控制、验证、确认、不确定度和可信度思路；当前文件只是项目研究方法映射，不声称已满足该标准。

## 8. 最小试验与测量闭环

| 闭环对象 | 最小新增证据 | 直接解除的 HOLD |
|---|---|---|
| 整星/构型质量 | 受控称重、测量模型、仪器校准与标准不确定度 | configuration mass |
| 质心/惯量 | 多姿态质心试验与摆振/扭摆辨识，含坐标变换和不确定度预算 | configuration CG/inertia |
| M3R 接头 | 紧固件/嵌件/材料证书、预紧方法、外载荷和接头试验 | fastener/contact entry |
| 夹爪 | 力—位移、间隙、热真空循环、磨损与目标接触试验 | force/friction/jam risk |
| 太阳翼/HDRM | 驱动力矩、释放冲击、寿命、冗余和状态指示试验 | mechanism functional gate |
| Sim14 | 实物或高可信模型相关、残差阈值、参数辨识和独立复现 | contact-model credibility |

## 9. 发布判据

M4 最终门分别判定：数字样机、结构分析入口、诊断动力学桥、生产接触/RL。允许数字样机与诊断动力学桥在限定范围内通过，同时让结构分析、飞行材料、HDRM 鉴定和生产接触/RL 保持 `HOLD`。任何报告必须同时显示通过范围和被封锁范围。
