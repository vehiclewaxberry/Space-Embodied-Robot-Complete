# 地面 AIT 装配逻辑

状态：`DESIGN_ONLY / TOOL_CLEARANCE_AND_TORQUE_UNSOURCED_BLOCKED`

## 1. AIT 入口条件

进入实体装配前必须具备：

- 已准入的 12U 部署器/发射接口 ICD；
- 已冻结的逐项 BOM、接口控制图、线束图和紧固件表；
- B601 基座孔位/定位/连接器受控图；
- 发射锁产品资料、锁点与地面解锁工装；
- 已批准的材料、表面处理、出气和禁限用材料清单；
- 可校准的装配工装、扭矩工具、称重与质心测量方案。

上述条件当前均未全部满足。本文件规定顺序和证据插入点，不授权制造或总装。

## 3. 线束与连接器顺序

### 3.1 路由原则

- 主干线束沿具名 corridor，分支在线束图规定的 breakout 点离开。
- 活动关节服务环不得穿越 HDRM 接触面、导轨/凸耳接触区、工具区或太阳翼扫掠区。
- 穿板处必须有边缘保护；固定点和应力释放点的间距、最小弯曲半径、屏蔽和热控制均按选定线缆 datasheet，当前为 `PLACEHOLDER`。
- 机械臂电缆应在基座接口处有可分离服务环，使 B601 可在不拆主结构的情况下更换。

### 3.2 连接顺序

在所有电源隔离并完成 ESD/接地流程后，建议的工艺顺序是：

1. 机壳搭接/保护接地；
2. 无源温度、位置和锁状态传感；
3. 数据与同步；
4. 执行机构命令/反馈；
5. 最后接通主电源与电池回路；
6. 每完成一组连接立即做键位、锁紧、拉脱/应力释放和连续性检查。

实际顺序必须由连接器/设备 ICD 签署；本顺序为 `DESIGN_ONLY`。

## 4. 紧固件、防松与力矩

- 每个连接必须在紧固件表中给出规格、等级、表面处理、润滑状态、安装力矩、允许复用次数和防松方法。
- 安装力矩全部为 `PLACEHOLDER`，不得从常用表或记忆填入。
- 螺纹胶只可用于已通过出气、温度、拆卸和材料相容性审查的接头。
- 锁紧螺套、锁紧螺母、安全丝或机械止动件应按可维护性和载荷选用；不得把多种防松方式无审查叠加。
- 扭矩工具必须在有效校准期内；工艺记录包含设定值、实测/工具 ID、操作者、时间和见证标记。
- 对要求复装的接口，拆卸后应记录螺纹、涂层、螺套和定位特征状态。

## 5. 称重与质心测量插入点

质量测量不是总装末尾的一次动作：

| 测量点 | 构型 | 目的 |
|---|---|---|
| M1 | 裸主结构与部署器接口 | 建立结构 tare 和质量所有权 |
| M2 | bus 电子设备、线束与外板完成，未装 B601/太阳翼 | 核查平台子系统闭合和局部 CoM |
| M3 | B601、安装座、HDRM 完成 | 捕捉臂根偏置和数字模型—实物差异 |
| M4 | 最终发射收拢构型，RBF/保护件按质量报告规则处理 | 形成发射质量、CoM、惯量输入 |
| M5 | 环境试验或重大拆装后 | 核查漂移、漏装和配置一致性 |

每次记录构型、坐标系、支承/吊具 tare、温度、量具校准和不确定度。M4 未完成前不得释放 GJM 或角动量预算的新物理基线。

## 6. Remove-Before-Flight 与抑制器

候选 RBF/安全件清单：

- `RBF-EPS/BATTERY`：电池/主电源安全；
- `RBF-ARM-HDRM`：机械臂释放回路安全；
- `RBF-SOLAR-HDRM-L/R`：太阳翼释放回路安全；
- 部署开关模拟器或旁路保护；
- 连接器、光学面、导轨/凸耳和敏感表面的保护盖；
- 地面吊具、临时支承和运输锁。

具体数量、独立 inhibit 架构、插拔顺序和移除责任由当前 CDS、部署器和电气安全 ICD 决定，全部为 `PLACEHOLDER / UNSOURCED_BLOCKED`。

原则上每个危险部署功能应具有彼此独立、可测试且状态可观测的抑制链；“软件未发命令”不能单独充当机械/电气抑制。

## 7. Flatsat 与整星测试分界

### Flatsat 负责

- 电源、数据、OBC、ADCS、通信和 B601 控制接口的功能连通；
- 软件、时间同步、故障注入、锁状态遥测和 release-command interlock；
- 连接器键位、线束 pinout 和电气 inhibit 逻辑；
- 不依赖真实结构柔度、最终线束长度或发射锁预紧的功能验证。

### 整星负责

- 最终线束长度、应力释放、接地/屏蔽和结构安装；
- 收拢包络、工具可达性、真实 HDRM、太阳翼/臂顺序与物理联锁；
- 质量、CoM、惯量、模态、环境和最终 fit check；
- 所有会受真实结构、热、摩擦、重力补偿或装配公差影响的验证。

Flatsat PASS 不得升级为整星结构或发射资格。
