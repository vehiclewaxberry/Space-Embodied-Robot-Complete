# 在轨装配接口与序列

状态：`DESIGN_ONLY / ASM00_AG0_BLOCKED_BY_INTERFACE`

本文件给出竞赛任务的工程内核，但不把规划稿写成已验证能力。当前没有装配物理求解器结果、蒙特卡洛结果或实验数据；现有 `ASM-00` 只冻结了九项成功判据合同并机器确认阻塞项。

## 1. 接口基线

候选接口采用分阶段几何与柔顺：

```text
粗捕获导向特征
→ 锥面/倒角把横向和角度误差转成接触法向力
→ 双销或等效定位特征完成姿态收敛
→ RCC/柔顺腕控制接触力与卡滞风险
→ 完全就位检测
→ 可自锁且可受控解锁的硬锁
```

该架构为 `DESIGN_ONLY`。锥口/喉部尺寸、销距、销/孔倒角、间隙语义、摩擦副、表面处理、刚度、阻尼、锁紧力和容许载荷均为 `PLACEHOLDER`。

## 2. 捕获包络与容差链

### 2.1 捕获包络

必须分别定义：

- 自由空间接近包络；
- 首接触几何包络；
- 导向锥/倒角可收敛包络；
- 双销或定位特征可进入包络；
- 完全就位与锁紧包络；
- 可安全退出包络。

当前数值一律为 `PLACEHOLDER`。旧草案中的粗/细容差是 `LITERATURE/PROVISIONAL`，且 `ASM-00` 已因导向半径、销距、倒角、摩擦来源和间隙语义缺失而阻塞，不能提升为设计值。

### 2.2 容差链

平移方向至少满足：

```text
E_sensor
+ E_estimation
+ E_robot_tracking
+ E_base_motion
+ E_structure_thermal
+ E_manufacturing
+ E_interface_wear
<= E_capture_available
```

转动误差还会通过销距或等效特征间距转换成横向误差：

```text
E_lateral_from_angle = f(E_angle, feature_spacing)
```

总链必须同时计入最坏方向、相关性、热真空形变和重复装配磨损。`feature_spacing` 未准入前不得给出角容差。

## 3. 导向特征如何限制接触力

倒角/锥面不是“自动成功”：

- 其法向把横向误差分解成轴向推进与侧向校正；
- 摩擦锥、锥角和表面状态决定是滑入、卡滞还是楔紧；
- 几何自锁可能破坏可逆退出，因此不可把楔紧当作正常锁紧；
- 导向深度必须足以把粗误差收敛到定位特征可接受的剩余误差；
- 接触力上限必须由末端 F/T、控制限幅和结构允许载荷共同约束。

本轮只保留这些设计关系。接触系数、最大允许力和推进速度全部为 `PLACEHOLDER`。

## 4. 柔顺中心与 RCC 设计意图

远心柔顺中心应放在接近首接触/插入特征的受控位置，使横向接触力产生有利的自对准转动，而不是放大卡滞。候选自由度分配：

- 横向平移与小角度倾转：柔顺；
- 插入轴：受力/位混合控制；
- 完全就位后轴向和扭转：切换为高刚度或硬锁；
- 未接触方向：保持轨迹与基座资源约束。

被动 RCC、柔顺腕或主动阻抗/导纳均可实现该意图，但实际刚度、阻尼、行程、远心位置和饱和策略均为 `PLACEHOLDER`。没有实验或 ASM-01 结果支持具体选型。

## 5. 锁紧机构

### 5.1 设计目标

锁紧机构必须同时满足：

- 完全就位前不可误锁；
- 断电后保持自锁；
- 具备独立状态检测；
- 能在受控条件下重复解锁；
- 解锁时不依赖盲目大力回拔；
- 锁紧后的载荷路径不长期依赖 B601 关节保持力。

### 5.2 候选

本轮候选为“电机驱动的正锁止凸轮/丝杠式闩锁 + 独立位置确认”，状态 `DESIGN_ONLY`。它以正锁止保持、以反向受控驱动解锁，避免把不可逆几何楔紧当作自锁。电机、传动、冗余、行程、保持力、释放力和循环寿命均为 `PLACEHOLDER`。

## 6. 可逆装配序列

| 相位 | 动作 | 可逆性与退出条件 |
|---|---|---|
| O0 观察 | 重建目标接口位姿、速度和接口健康 | 数据不一致则不接近，回到安全观察点 |
| O1 5D 接近 | 沿接口法向接近，保留绕轴自由度或任务允许自由度 | 超出捕获走廊则退回 pre-assembly pose |
| O2 首接触 | 低速进入导向面，切换力/位混合控制 | 未分类接触立即停止；不做盲目轴向拔出 |
| O3 柔顺导向 | 让 RCC/柔顺腕吸收横向与倾斜误差 | 力、位移、时间或状态异常则卸载并回到 O2/O1 |
| O4 定位特征进入 | 单销/双销或等效定位逐级约束 | 卡滞则改变力旋量或小幅退回；未知状态进入 SAFE_HOLD |
| O5 完全就位 | 以几何、力、位姿和接触历史共同判定 | 任一证据缺失不得锁紧 |
| O6 硬锁 | 执行正锁止并交叉确认 | 锁失败且仍可逆时解锁并退回；禁止带病宣告成功 |
| O7 载荷转移与验证 | 逐步释放机械臂保持，验证接口承载与资源 | 验证失败时重新抓持；是否解锁需状态机和地面授权 |

锁紧前序列应可逆；锁紧后解锁是独立受控动作，不默认自动执行。

## 7. 单点失效退出策略

| 失效 | 退出策略 | 证据状态 |
|---|---|---|
| 位姿/视觉失效，尚未接触 | 停止推进，退到已知安全观察点，重定位 | `DESIGN_ONLY` |
| F/T 或接触状态不一致 | 零化推进命令，保持/卸载到已知低力状态；无法分类则 `SAFE_HOLD` | `DESIGN_ONLY` |
| 单点接触滑移 | 降低推进，恢复视触觉估计，回到首接触 | `DESIGN_ONLY` |
| 双点卡滞 | 不沿轴硬拔；改变力旋量、微退或重对准；状态未知则停止 | 有现有风险分析支持“盲退不安全”，无实验验证 |
| 几何楔紧 | 禁止继续加力；保持、卸载或等待人工/地面裁决 | `DESIGN_ONLY` |
| 闩锁未闭合 | 机械臂保持柔顺抓持；若载荷安全则反向退出 | `DESIGN_ONLY` |
| 闩锁卡在闭锁 | 不自主强制解锁；进入 `SAFE_HOLD`，用独立状态和地面指令裁决 | `DESIGN_ONLY` |
| 单个锁状态传感器失效 | 不以单通道宣布成功；使用异构证据或保持安全态 | `DESIGN_ONLY` |
| 基座轮组/姿控资源逼近上限 | 暂停装配并回到资源安全构型；阈值来自未来轮组 datasheet | `UNSOURCED_BLOCKED` |
