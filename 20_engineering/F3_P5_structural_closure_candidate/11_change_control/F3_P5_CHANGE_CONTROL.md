## 1. 变更触发条件（ECR）

自本文件生效起，下列任一触发必须走 ECR（Engineering Change Request）：
1. 基准面/尺寸/GD&T 任何改动（8 件任何一键）
2. 接触垫 G07/G08 材料、刚度或预紧量改动
3. HDRM 竞赛演示件机构方案改动
4. T_SM（185.25 mm）或 Mode B 单一轨道路线改动
5. 状态机 `F3_P5C_SM_FROZEN_V1` 任何状态或互锁改动
6. 6×6 刚度/柔度矩阵、ROM 模态数值改动（需重跑 UL 才可改动）
7. 材质、毛坯、表面处理改动
8. 制造工艺路线改动（CNC→增材等）

## 2. 变更流程

```text
发起方提交 ECR（描述+原因+影响）
  → F3 结构负责人评审（影响分析：UL/modal/HOLD/状态机）
  → 涉及控制/具身交接则联动 P5E 包更新
  → 批准签发 ECO（Engineering Change Order）
  → 更新对应 JSON/CSV/YAML + 重新运行 smoke test
  → 变更入账，禁止未批准的直接修改
```

## 3. 禁止项（No-Go）

- 未走 ECR 直接修改冻结文件（含 Gate JSON/HOLD 寄存器/状态机 YAML）
- 在无 AL 载荷谱情况下声称飞行合格或强度/屈曲裕度非 TBD
- 将比赛样机(G07/G08/HDRM 竞赛件)结论引申为飞行证据
- 删除负结果条目（Mode A 排除、Mode B STOW 排除、波动性分段等必须保留）
