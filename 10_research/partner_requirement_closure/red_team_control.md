## 攻击点① 末端轨迹控制的新颖性与贡献声明

**裁决：NEEDS_FIX（贡献声明部分站得住，但文献定位缺失、柔性增广贡献在占位参数下不可宣称）**

核实结论：
- `coupled_dynamics.py:375-386` 的 `generalized_jacobian` 确为
  `J* = [J_m, 0] − J_b H_bb⁻¹ H_bm` 的 6×(6+2m) 帆板增广形式，docstring 自称
  "Umetani-Yoshida 增广形式"——计划 §0 对 UY1989 谱系的继承声明是诚实的，
  且 claim_allowed 已自我限定为"相对排序与机器证明"，未僭称方法新颖。此部分 OK。
- **但 C1 只取 J* 的关节列块 J*_θ(6×6)**，柔性只通过 H_bb/H_bm 装配中的帆板惯量间接进入；
  帆板质量为 SSOT 占位 0.348 kg（真实差 5–10×，待办 3），占系统 26.5 kg 的 1.3%，
  J*_θ 与 sim_05 刚性 J_g 的数值差异预期在 1% 量级以下。**C2b 的 −J*_η η̇ 补偿项与
  "帆板激振定量分离"在占位参数下预期给出≈0 的分化**——计划 §7 只约束了"帆板指标相对比较"，
  没有把"柔性增广 J* 本身的贡献"也列入禁宣清单。这是贡献声明的一个真实漏洞：
  审稿人会问"你的 J* 和 1989 年的 J_g 差在哪"，而占位参数下的诚实答案是"数值上几乎不差"。
- **文献定位缺失（NEEDS_FIX 核心）**：C3 的"反作用零空间 + 梯度投影"正是
  Nenchev 等 Reaction Null Space（RNS）谱系（含柔性基座 RNS 工作），计划只引了 UY1989；
  C0 vs C1 的漂移分化对应 Papadopoulos/Dubowsky 扰动图谱系。计划书未列先行方法对照表，
  实现后写论文时将被审稿人以"复现经典未引用"直接打击。
- **站得住的贡献只有三条**，建议 §1 显式改写为：
  (i) 退化锚点逐位闭环的机器裁决证据链（19.199885629572467° 级对拍，全仓库制度延伸到控制层，方法学贡献）；
  (ii) ISS 解析界 + 数值越界即 FAIL 的误差有界性闭环（Gate C-F，文献中少见的可证伪化处理）；
  (iii) 轨迹集与 sim_10 可行域 / sim_12 策略层的任务联动（T2=WHEELS_ONLY 锚点、T3=ABORT 执行层）。
  四方法 C0–C3 本身均为文献方法，只能作为"物理假设阶梯"的载体陈述。

**具体修改建议**：§0 增加"先行方法对照表"（UY1989 GJM / Nenchev RNS / Papadopoulos-Dubowsky
扰动图 / 柔性基座 GJM），claim_forbidden 增加一条："占位帆板参数下不得宣称柔性增广 J*
相对刚性 J_g 的任何优势或差异（该主张 BLOCKED_BY 待办 3）"。

## 攻击点② C3 零空间在 approach_5d 口径的严密性

**裁决：NEEDS_FIX（口径选择本身正确且诚实，但存在 6 个未预注册的定义/奇异性缺口）**

先确认做对的部分（CONFIRMED_OK）：
- 6R + pose_6d 下 nullity=0、C3 只在 approach_5d 定义、T2 需完整姿态时标 NOT_APPLICABLE——
  这一"诚实声明"完全正确，杜绝了硬造冗余。
- `ik.py:87-113` 核实：approach_5d 行构造 = 3 位置行 + `N @ skew(a_des) @ skew(a) @ J[3:,:]`
  两行，与 B601Arm.J5 同一代数，rank(J5)=5 时 nullity=1 成立，`_diagnose` 已输出
  task_rank/task_nullity 可直接复用为 Gate 信号。
- C3 目标函数取 `‖(H_bb⁻¹H_bm)_ang,θ·θ̇‖`——**这是基座角速度映射，参考点选择正确**
  （对比 control_02 A-1 项的错误写法，见攻击点③），值得肯定。

未闭合的缺口（每条附修改建议）：
1. **N 非投影算子**：§2 骨架 `N = I − J⁺J` 若 J⁺ 取阻尼伪逆 pinv_λ（计划通篇用 DLS），
   则 N 不是零空间投影算子，零空间项会向任务空间泄漏 O(λ) 误差，直接污染
   "C3 末端不劣化>10%"的 Gate C-D 判定。修改：预注册 N 用 SVD 精确投影
   （秩判据复用 sim_09 RANK_RTOL=1e-8），与任务解的 pinv_λ 分开。
2. **ζ 的代数环未定义**：ζ = −k_r∇_θ̇‖Aθ̇‖² = −2k_r AᵀAθ̇，θ̇ 取"上一步指令"、
   "粒子解 pinv_λ(J)[·]"还是"含 Nζ 的全量"（后者为隐式方程 (I+2k_r N AᵀA)θ̇=θ̇_p）
   三种定义结果不同。修改：预注册取粒子解（显式闭式，可独立复算）。
3. **基向量时变不连续**：`_axis_plane_basis`（ik.py:54-66）在 |a_des·x̂| 跨 0.9 阈值时
   切换 seed，n1/n2 跳变 → J5 第 4-5 行跳变 → θ̇_cmd 阶跃。sim_09 中 a_des 为常量无此问题，
   但 T2 的 a_des(t) 随目标翻滚 30 s 内扫过数十度，**极可能跨阈值**。修改：预注册连续基
   （平行输运）或机器断言 T2 全程 |a_des·seed| 不进入 [0.85,0.95] 切换带。
4. **秩降未预注册**：臂自身奇异（σ_min→0）时 rank(J5) 可降至 4，nullity 跳 2，
   N 维度突变；Gate C-E 的 σ_min 下限只保护任务解不保护零空间维稳定。
   修改：预注册"nullity≠1 的时刻 ζ 强制置零并记录占比"。
5. **限位裁剪破坏零空间性质**：θ̇_cmd 逐关节限幅/限位钳位后不再位于 null(J5)，
   既注入任务误差又使"反作用下降"归因失效。修改：预注册"限位裕度 < 阈值时 ζ 衰减到零"
   （光滑屏障），并在 CSV 记录 ζ 被裁剪的时间占比。
6. **收益量级无预估**：1 维零空间上反作用梯度的投影收益可能只有百分之几，
   Gate C-D 只要求"下降"（任何 ε>0 都算过门）。修改：预注册最小有效下降量
   （建议 ≥5%，与数值噪声分离），否则如实报告 NULL_RESULT。

**A-1（NEEDS_FIX，高）A1 硬约束的参考点物理缺陷**：
计划 §4.2 将反作用零空间约束写为 `(H_bm)_ang·q̇ = 0`（3 硬约束）。但
`sim_05/dynamics.py:6` 明示动量口径为 **[P; L_about_base_origin]**（对基座 S 原点）。
零动量下 V_b = −H_bb⁻¹H_bm·q̇；令 (H_bm q̇)_ang=0 只消去对 S 原点的臂角动量项，
由于系统质心 c≠S 原点、H_bb 含 M·c× 耦合块，**基座角速度残差为
ω_b = I_S⁻¹·c×(H_bm q̇)_lin ≠ 0**——而 (H_bm q̇)_lin 峰值 0.1602 kg·m/s（sim_05 README:118）
非零。参考点差异不可忽略已有本仓库先例：sim_11 A2 的 |H_O|=3.678 vs |L_C|=3.721 N·m·s。
后果：P1"19.20°→<2°"可能因这项系统性残差达不到，且"反作用零空间"命名与实际约束不符。
**修改**：约束改为直接取 `(H_bb⁻¹H_bm)` 的角行 ×q̇=0（即 ω_b≡0，同为 3 约束、闭式、
与 control_01 C3 的目标函数口径恰好统一），或等价地用对系统质心的角动量行
`(H_bm q̇)_ang − c×(H_bm q̇)_lin = 0`。A2 前馈 `h_w,cmd=−(H_bm·q̇)_ang` 同一缺陷
（PD 反馈可部分兜底，但前馈口径应同步改，否则"前馈+小反馈"的架构主张失真）。

**A-2（NEEDS_FIX，高）轮组容量包络语义缺口**：
冻结链 h_max=0.300 N·m·s 是 3×100 mN·m·s 的**标量合计**口径，sim_08 assumptions.yaml
limits_of_validity 明示 "single-axis scalar budget on |H_c|（vector allocation = v1）"。
control_02 是第一个把 h_w 作为 3 维矢量状态闭环仿真的模块：三正交轮的物理包络是
**每轴 ±0.100 的箱**（对角最大 0.173），球半径 0.300 在任何方向都不可达。
P2 的"峰值占用 0.0891/0.300≈29.7%，预测无饱和"在每轴口径下变为
**0.0891/0.100=89.1%**——M1 是 joint2/joint3 俯仰主导机动，臂动量恰恰集中单轴，
加上 PD 瞬态余量，**"无饱和"预测可能翻转**。
**修改**：attitude_stab_v0.yaml 预注册包络语义双口径：箱（每轴 0.100）为物理饱和判据，
球 0.300 仅作与 sim_08/sim_10 冻结链对拍的口径；P2 按双口径分列预测（29.7% / 89.1%）。

**A-3（NEEDS_FIX）姿态峰值口径不一致**：指标表定义 max‖euler(t)‖，而 19.20° 锚是
四元数总转角 dev_angle 口径（sim_05/sim_11 同款，sim_11 CSV dev 列）。GC1 逐位对拍
在口径混用下必挂。修改：统一 dev_angle。

**A-4（NEEDS_FIX）几何相位锚无承载机动**：2.6168° 出自 sim_05 test_3 **闭合关节循环**
（tests/test_dynamics.py:81-121），而 §4.1 的 M1（0→60/−40 保持）与 M2 均非闭循环，

修改：增补 M3=sim_05 闭循环机动（证明集 8→12 例），或把几何相位降为引用性说明并从

应写死（建议 1e-12，与 GC0 同源；单个最小脉宽冲量 ~F·l_T·t_min≈1.7e-4 N·m·s，
