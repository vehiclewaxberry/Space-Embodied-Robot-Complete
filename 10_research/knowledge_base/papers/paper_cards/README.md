# 论文阅读卡入口

本目录不复制阅读卡。canonical 阅读卡继续保存在：

- [`50_literature/references/notes/INDEX.md`](../../../../50_literature/references/notes/INDEX.md)
- [`50_literature/references/notes/`](../../../../50_literature/references/notes/)

当前机器计数统一读取 [`../controller_state.yaml`](../controller_state.yaml)，不再在本页手工维护。使用规则：

1. 有完整阅读卡的条目可用于受限的方法、边界和对比论证；
2. 只有题录与 PDF 的条目，在写细节前必须补核心精读；
3. 状态为 `BLOCKED_NO_LOCAL_PDF` 的条目只能登记缺口，不能推测正文；
4. 任何题录字段以 [`manifest.yaml`](../../../../50_literature/references/manifest.yaml) 和 [`refs.bib`](../../../../50_literature/references/refs.bib) 为准。
