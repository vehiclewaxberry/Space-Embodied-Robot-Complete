## 0. 设计原则（从本仓库教训直接导出）

1. **fail-closed**：任何规则无法求值（缺参数、域外、指标不适定）→ 升级保真或返回
   UNKNOWN，绝不静默降级。承接 sim_10 的 `FLEX=UNKNOWN 不入判据` 口径。
2. **科学结论只认机器裁决 JSON**：ROM 认证产出 `rom_gate_check.json`，测试 PASS ≠
   认证 PASS。
3. **e15 教训（REPEAT_ANCF_CERTIFICATION）**：交叉求解最大差 5.64% > 5% 门槛即
   REPEAT；且 e15 已明文拒绝"用低振幅诊断锚点冒充最终候选"——ROM 认证集必须含
   **真实工况幅值**的最终候选交叉认证，低幅诊断只能作 sanity 项。
4. **指标适定性先于收敛判据**：sim_11 v1.0→v1.1 证明理想冲量 Δt=0 对模态能指标
   不适定（m=2..7 慢收敛尾 +2.86/+1.29/+0.72/~+0.4%）；切换规则必须先判"该指标在
   该激励下是否适定"，再谈误差阈值。
5. **第一版禁止黑箱神经网络**：代理链 = 物理模态截断 → 解析响应面 → 小型残差
   模型（线性可检视基函数），全部系数入册、哈希锁定、带外推护栏。
6. **占位参数传染性**：帆板参数（0.348 kg/侧、f1=1.0 Hz、ζ=0.005）与 T_c=20 ms
   均 PROVISIONAL；ROM 认证结论继承 `PROVISIONAL_PARAMS: true` 标记，参数转正
   （杨恒参数卡 / B601 夹爪实测）后全部 Gate 重跑。

## 2. 模型切换规则设计（六判据，全部机器可执行）

判据按**短路顺序**求值；任何判据无法求值 → fail-closed 动作（升级或 UNKNOWN）。
符号：候选工况 x，当前层 Lk，指标见 YAML `metrics` 注册表。

### R1 域内性（domain guard）——最先判，域外一票 UNKNOWN
- x 必须落在该层认证域凸包内：参数域（μ、ω、λ、α ∈ sim_10 扫描卡范围；T_c ∈
  [5,100] ms 已扫掠带；帆板 f1 ∈ 认证包络）。
- 域外 → 返回 `UNKNOWN_OUT_OF_DOMAIN`，禁止外推（含响应面/残差模型外推）。

### R2 指标适定性（well-posedness）——接触时长 vs 最高有效频率
- 接触带宽边 `f_band = 1/(2·T_c)`；模态基须覆盖带内全部模态：
  `f_m(最高保留模态) ≥ κ_band · f_band`，安全系数 κ_band = 1.4（名义）。
  实证锚点：T_c=20 ms → f_band=25 Hz，f3=17.55 Hz 在带内 → m≥3 必要（sim_11
  `A2_bandwidth_coarse_m2_diagnostic`：m=2 缺带内模态，模态能差 2.18%）。
- 若 T_c → 0（理想冲量）或 f_band 超出可信模态基频率上界 → **模态能指标判
  不适定**：动量级量（ω⁺、基座角速率、tip 峰值）仍可用，能量级量禁止入判据，
  且必须改用带宽口径或升级 L2。承接 sim_11 `ideal_impulse_diagnostic`。

### R3 挠度/长度比（线性域检查）
- `r_defl = w_tip,peak / L_panel`。名义锚点：A2 带宽口径 2.071 mm / 0.2 m = 1.04e-2。
- `r_defl < 0.02` → L1 线性模态域内（绿）；`0.02 ≤ r_defl < 0.05` → 黄区，L1 结果
  须挂 `LINEARITY_MARGINAL` 且边界候选升级 L2；`r_defl ≥ 0.05` → L1 无效，强制 L2。
- 阈值依据：EB 小挠度假设常规工程界 2–5%；黄区上界与 sim_07 静基准（1% 误差内的
  验证幅值 w/L=1%）保持一个量级余量。**阈值本身列为认证集敏感性扫描对象**（D 类
  待定项，见 §5）。

### R4 模态能尾部收敛（截断误差在线估计）
- 前向加密链：`τ_m = |E_modal(m+1) − E_modal(m)| / E_modal(m)`。
- `τ_m < 0.01`（G4' 同判据）→ 截断可信；`0.01 ≤ τ_m < 0.03` → m 加密一档后复判；
  连续两档不降（慢收敛尾特征，参考理想冲量 +2.86/+1.29/+0.72%）→ 判不适定回 R2
  或升级 L2。
- 尾部估计同时用作 L1 模型形误差下界：`ε_trunc ≈ κ_tail · τ_m`，κ_tail = 3（几何
  级数余项上界系数，名义；认证集标定）。

### R5 候选距安全边界距离（保真升级的核心触发器）
- 归一化裕度 `d = (v_limit − v_pred) / v_limit`（v = binding 指标，如 ω⁺ vs 轮组
  限速、|H_c| vs 容量、推进剂 vs 预算；取所有 binding gate 的最小裕度）。
- 与该层总误差估计 `ε_tot(Lk)`（= 认证误差 ⊕ ε_trunc ⊕ 参数占位敏感度）比较：
  - `d > β_safe · ε_tot`（β_safe=4）→ 当前层可定案（含 UQ 膨胀后仍不跨界）；
  - `β_esc · ε_tot < d ≤ β_safe · ε_tot`（β_esc=1）→ 升一级保真复核；
  - `d ≤ β_esc · ε_tot` → 直升 L2 终审；L2 仍不能分辨 → 判 `BOUNDARY_UNRESOLVED`
    （诚实结论，允许进论文——X2 过渡带 1.08% 亚分辨率凹陷即此类先例）。
- X2 教训显式入规则：`G1_slender` 类过渡带（μ∈[0.4,0.7] 名义）内的候选，无论 d
  多大，最低使用 L1 复核（L0 单独定案禁止）。

### R6 误差估计与算力预算（调度层）
- 每层维护 `error_model`：认证残差分位数（p95）+ R4 截断项 + 占位参数敏感度带
  （registry v2 敏感性矩阵挂钩）。预测输出一律携带 `value ± ε_tot, level, basis`。
- 预算约束：`cost(plan) = Σ n_k · c_k ≤ budget`。名义配比（漏斗型）：
  L0 全域 O(10⁴) 点 → L1 复核 O(10¹–10²)（top-k ∪ 边界带 ∪ 黄区）→ L2 终审
  O(10⁰–10¹)。c_k 现为占位（YAML `calibration_required: true`），R1 阶段实测校准。
- 预算不足时**不降级判据**：削减候选数（缩 k），绝不放宽阈值（`thresholds_widened`
  永久为 false 的仓库惯例）。

## 3. ROM 认证 Gate（`rom_gate_check.json` 裁决口径设计）

认证 = 在**认证集**（§4）上，低层预测对高层参考解的机器裁决。五个子门全过才准
该层进入自动调度；任一 FAIL → 该层降为 `SCREENING_ONLY`（只准做筛选，不准定案）。

### GR1 逐量误差门（末端 / 基座 / tip / 模态能）
| 量 | 阈值（L0 vs L1 / L1 vs L2） | 依据 |
|---|---|---|
| 末端/接触点速度残差、传递冲量 |λ| | ≤ 1% / ≤ 1% | sim_06↔sim_11 刚性极限恒等已达机器精度，1% 是宽松上界 |
| 基座姿态峰值 / 角速率峰值 | ≤ 1% / ≤ 2% | G3b 退化恒等 1e-3 量级；跨模型形比较放宽至 1–2% |
| tip 挠度峰值 | —（L0 无此量）/ ≤ 5% | G3a 现行 5% 门槛，实测最差 0.38% |
| 一阶主频 | — / ≤ 2% | G3a 现行 2% 门槛 |
| 模态能峰值 | — / ≤ 10% | e15 低幅诊断 10% 门槛；能量为二次量，最敏感，单列 |
- 全部按 p95 分位数裁决（不是均值），逐例残差入 CSV 留档。

### GR2 Top-k 候选排序一致性
- 认证集上按任务目标函数（如最小 ω⁺ / 最小推进剂 / sim_12 策略成本）排序：
  - **top-3 集合恒等**（无序集合相等，k=3 对齐 e15 "名义 Top-3" 口径）；
  - top-10 内 Kendall τ ≥ 0.9；
  - 排序翻转仅允许发生在 |Δ目标值| < ε_tot 的"统计平局对"内（平局对单列不计罚）。

### GR3 unsafe false-negative = 0（硬门，零容忍）
- 高层判 UNSAFE / INFEASIBLE 的认证例，低层不得判 SAFE / FEASIBLE。计数必须
  **恒等于 0**——一票 FAIL，无百分比减免。反向（低层保守误杀 false-positive）
  只记率入报告，不设门（fail-closed 允许保守）。

### GR4 域外必须返回 UNKNOWN
- 认证集附带**域外探针例**（参数超扫描卡、T_c 超扫掠带、r_defl 超线性域、帆板
  f1 超包络）：选择器对全部探针必须返回 `UNKNOWN_OUT_OF_DOMAIN`，返回数值预测
  即 FAIL。承接 sim_10 `FLEX=UNKNOWN` 与 e15 fail-closed 口径。

### GR5 交叉求解认证（e15 口径重过）
- L1：Radau vs BDF（已有 G5 ≤5% 门槛，现值 ≤0.16%，重跑确认即可）。
- L2：ANCF 侧 Newmark vs 变步长隐式双解，**最终候选真实幅值**下最大相对差 < 5%
  ——即重过 e15 `REPEAT_ANCF_CERTIFICATION` 的未闭环项（`final_candidate_
  cross_solver.available=false` 必须翻为 true 且 pass）。低幅锚点不得顶替。
- 代理链（响应面/残差模型）：留一交叉验证残差 p95 入 GR1 同表，且外推护栏
  经 GR4 探针验证。

## 4. 认证集设计（不实现，仅规格）

- **A 类 锚点例（~10）**：sim_06 两锚点（3.0633 / 1.3872°/s）、sim_08 预算行、
  sim_12 16 例中的 B-S1 对齐子集——逐位复现级，防回归。
- **B 类 边界带例（~30）**：sim_10 四区域边界两侧 ±(1,3,10)·分辨率采样，重点覆盖
  X2 过渡带（G1 μ≈0.51）与 λ 非单调凹陷邻域——GR2/GR3 的主战场。
- **C 类 物理压力例（~15）**：T_c ∈ {5,20,100} ms × 帆板 f1 ∈ {0.6,1.0,2.2} Hz
  （registry v2 包络）× 挠度黄区工况——R2/R3/R4 规则的判别力测试。
- **D 类 域外探针（~10）**：专供 GR4；含"真实多板模态间距 f2/f1=2.8"这类
  解析悬臂模态域外构型。
- 全部认证例的参数、哈希、层级参考解路径入 `rom_certification_manifest.yaml`
  （规格待 R1 阶段落地）。

## 5. 代理链约束（第一版禁止黑箱 NN）

1. **第一层 物理模态截断**：FFR m 阶截断本身即 ROM；截断误差由 R4 在线估计。
2. **第二层 解析响应面**：对 L0 可行域量（ω⁺、|H_c|、推进剂）用**物理结构化**
   解析式拟合（sim_10 已有解析/精确双解框架 X4 即原型）；系数带物理量纲与符号
   约束（单调性、极限行为 μ→0/∞ 正确），拟合域=认证域。
3. **第三层 小型残差模型**：解析式残差用低维线性基（多项式/有理基 ≤ 10 项）
   回归，系数入册哈希锁定；**禁止** MLP/GP 黑箱；残差模型只准内插（GR4 护栏）。
4. 神经网络类代理留作 v2 展望（须先有 v1 认证基线作对照），本计划不设计。
