### 1.3 帆板 FFR 模型（决策 D-YH-3：作业段 FFR）

挠度场 `w(s,t) = Σᵢ φᵢ(s)·ηᵢ(t)`，方向为帆板法向 e3 = +Z_S；φᵢ 为悬臂
Euler-Bernoulli 解析模态（特征方程 `cosh β cos β = −1`，β₁L = 1.87510407 与 SSOT 一致），
经质量归一 `∫μφᵢφⱼ ds = δᵢⱼ`。由参数卡运行时生成（禁止手抄）：

- 模态刚度 `K = ∫EI φᵢ''φⱼ'' ds = diag(ωᵢ²)`（数值残差 < 1e-8 相对），nominal EI 下
  f = [1.0002, 6.2682, 17.5511] Hz——一阶与 sim_07 ANCF 的 1.00021 Hz 同值；
- **平动/转动模态动量系数**：`B_t,ᵢ = ∫μφᵢ ds`（方向 e3），`B_r,ᵢ = ∫μ s φᵢ ds`（对根部、方向 e1）。
  m=3 时 B_t = [0.4622, 0.2561, 0.1502]，B_r = [0.06715, 0.01071, 0.00383]（质量归一单位）。
  B_t 正是质量阵 M_bη 平动行的系数（见 2.3）。

质量离散：展向 Gauss-Legendre 质点切片（24 节点）+ 切片弦向/厚向转动惯量**集中块**
（基座固连常惯量）。这样 η≡0 刚化极限严格闭合到 SSOT 平板惯量
（tests：vs 精确平板公式 3.0e-18，vs YAML 舍入值 < 1e-9），保证退化链 G3b 成立。
模态转动惯量（Rayleigh 修正）忽略——量级 (t/L)²/12 ≈ 7.5e-5，标准 Euler-Bernoulli FFR。

## 2. 动力学方程与分块推导

### 2.1 方程形式

```
M(q)·u̇ + c(q,u) = Q ,   Q = [ 0(基座,自由漂浮) ; τ(关节) ; −K_η η − D_η η̇ (模态) ]
```

由 Kane 方法（投影 Newton-Euler）装配，与拉格朗日严格一致。刚度阵 K 仅作用于 η
（分块对角 diag(ωᵢ²)×2 侧），模态阻尼 D = diag(2ζωᵢ)。

### 2.2 点/体运动学（S 系分量）

对本体系坐标为 x（含关节/模态引起的相对运动）的质点：

```
v_S = v_b + ω_b×x + ẋ_rel
a_S = v̇_b + ω_b×v_b + ω̇_b×x + ω_b×(ω_b×x) + 2ω_b×ẋ_rel + a_rel
```

刚体转动项（S 系分量，体相对 S 转动 ω_rel）：

```
(dh/dt)_S = J_S·ω̇_S + ω_rel×(J_S ω_S) − J_S(ω_rel×ω_S) + ω_b×(J_S ω_S) ,  ω_S = ω_b + ω_rel
```

Kane 行：`[M u̇ + c]_r = Σ_体 [ (∂v/∂u_r)·(m a_S) + (∂ω/∂u_r)·(dh/dt)_S ]`。

**实现教训（已写入回归测试）**：`ω_b×v_b` 输运项的虚功率 = `P_S·(ω_b×v_b)`，
在零动量流形上恒为零——约简模式与能量审计对漏项**完全免疫**，只有 full 模式
的动量漂移能暴露它。当前 12 s full 工件实测 |ΔP|=2.6e-12、|ΔL|=1.4e-12，
远低于 1e-9 门槛；这正是"动量守恒机器裁决必须包含全量积分交叉证据"的直接理由。

### 2.3 质量阵分块（基座 b / 臂 a / 帆板 η）

```
M = [ M_bb   M_ba   M_bη ]      M_bb(6×6)  锁定全系统空间惯量（基座行 ≡ 动量映射 A 的列）
    [ M_baᵀ  M_aa   M_aη ]      M_ba(6×6)  臂-基座耦合：sim_05 的 19.20° 扰动来源
    [ M_bηᵀ  M_aηᵀ  M_ηη ]      M_bη(6×2m) 帆板-基座耦合：平动行 = B_t·e3，转动行 = Σ mₖφₖᵢ(xₖ×e3)
                                M_ηη = E(质量归一)
```

**M_aη ≡ 0（结构性零）**：在"基座空间拟速度 + 相对坐标"下，臂与帆板速度都只含
基座列与各自列，交叉块严格为零；臂-帆板耦合经基座块传递（消去基座后以 Schur 补
形式出现）。这与调研报告"经基座的间接耦合"的表述一致，且是可检验命题（tests 断言 =0）。

### 2.4 两种积分模式与广义雅可比

- **reduced_momentum（主线）**：惯性系动量 h_I 为常量约束，
  `V_b = H_bb⁻¹(h_S(t) − H_bm q̇_m)`，动量守恒到机器精度（对齐 sim_05 证据文化）；
  [基座; 模态] 行联立解 η̈。支持 h_I ≠ 0（A2 捕获后）。
- **full（交叉证据）**：V_b 入状态量全量积分，动量漂移检验装配一致性。
  两模式互证：2.5 s 窗姿态差 3.6e-11°（tests）。
- **帆板增广广义雅可比**：`J* = [J_m, 0] − J_b H_bb⁻¹ H_bm  (6×(6+2m))`，
  H_bm 含模态列——帆板振动通过动量守恒反拖基座、进而牵动末端的通道显式可见。
  已验证恒等式 `Φ_EE u ≡ J* q̇_m`（零动量流形，1e-12 级）；输出于 A1 summary JSON。

### 2.5 能量定理（审计依据）

`d(T+U)/dt = τ·θ̇ − η̇ᵀD η̇` 对本模型精确成立；积分器同时积累 `W_joint = ∫τ·θ̇ dt` 与
阻尼耗散，审计 `|W − ΔT − ΔU − E_damp|`。

### 3.4 v1.1：有限接触带宽捕获（G4 阻断的物理修复）

**根因诊断（分支 A，m 增阶）**：理想冲量 Δt=0 频谱平坦，逐阶模态注入能量
∝ (B_t,i·J)²，而悬臂模态动量系数衰减缓慢（B_t = 0.462/0.256/0.150/…，≈1/(2i−1) 律）。
实测 A2 模态能峰值 m=2→3→4→5→7 逐阶 **+2.86% / +1.29% / +0.72% / ~+0.4%**——
慢收敛尾，纯提阶数需 m≈8–10 才能形式过 1% 门槛且"收敛值"仍在爬。
**结论：理想冲量对能量类指标不适定，系模型域边界而非装配缺陷**
（动量级量不受影响：基座角速率 m 差 2e-6、tip 挠度 0.73% 早已收敛）。

**物理修复（分支 B，`src/contact_window.py`）**：真实夹爪闭合 5–100 ms，
对 >1/(2T_c) 的激励带限衰减。把瞬时 Delassus 冲量摊为**等冲量半正弦力/力偶脉冲**
（∫F dt = λ 严格保持，方向按捕获瞬间惯性系冻结），追踪星（full 模式 + 外力广义力
Q_ext = Φᵀw）与目标刚体在接触窗内**联立积分**——作用反作用同点，组合动量守恒
直接成为机器审计；窗末残余相对速度用一次 Delassus 小冲量收口（夹爪最终锁死）。
参数卡 `scene_A2_capture.yaml` contact 段；T_c 名义 20 ms 为 **PROVISIONAL**
（待 B601 夹爪闭合时间实测）。
