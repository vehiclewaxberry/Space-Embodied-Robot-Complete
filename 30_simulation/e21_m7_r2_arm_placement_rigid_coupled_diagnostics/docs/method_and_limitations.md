# 方法与局限

## 安装语义审计

接受 URDF 的 `base_link` 与全部移动连杆（含刚性并入 link6 的夹爪）按配置 q 组合为完整臂质量属性。对每个账本配置分别施加两个精确 4×4 变换，计算臂质心欧氏误差和臂自身质心惯量最大分量误差。该比较是离散模型语义审计，不是统计推断。

## 刚性翼自由漂浮臂

局部求解器只保留 sim11 方程的最小刚体核心：固定残余体、B601 `base_link`、六个移动刚体、规定关节轨迹、自由基座六维拟速度以及惯性系零总动量代数约束。当前 R2 双翼不使用 legacy FFR；其部署锁定刚性质量属性已经包含在 V3_R2/C07 反演残余体内。结果因此只能回答“安装上下文变化对刚性 R2 组合体的臂致基座反作用有多敏感”，不能回答柔性振铃或捕获问题。

## 固定基座 R2 ROM

leaf-only ROM 按上游脚本的三叶片二维链动能构造 Mqq，K 为 `diag(k_root,k_inter,k_inter)`，五个刚度组合通过广义特征值复算。质量脚本另外把两个 0.03 kg inter-hinge 作为随动点质量；把这两个点加入 ROM 会改变 Mqq 与频率，说明动态质量分配尚未冻结。该差异明确标注为非选择冲突，不传播到任何动力学输入。

## 保留 HOLD

R2 刚度、阻尼和质量仍含未实测候选量；e15 仍为 `REPEAT_ANCF_CERTIFICATION`；R2-HRN-04 全 FK 线束扫掠仍 FAIL；handoff 仍 `PENDING_OWNER_REVIEW` 且未授权下一阶段。碰撞、接触、目标、任务、生产和飞行全部未评估。
