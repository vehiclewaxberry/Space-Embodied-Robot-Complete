# e21 预注册

时间冻结：2026-08-23（数值执行前）。

## 问题与判据

- 审计 V2 与 V3_R2 的 C01..C09 完整臂质量属性是否可由单一安装上下文解释。只允许比较 ODR-01 动力学变换与 M4/WP11 物理几何上下文变换；不得选择、平均或把差值解释为不确定度。
- 若九配置中至少各有一个配置只在不同上下文内落入预注册容差，则记录 `MIXED_PLACEMENT_CONTEXT_DETECTED`，但裁决措辞必须保持为“质量消费语义未解决”，不得否定 ODR-01 或宣告配置错误。
- 当前 R2 动力学只执行 C07/M07_ARM_ONLY。由 V3_R2/C07 总质量属性减去 ODR-01 安装下完整臂反演固定残余刚体。残余体必须正质量、惯量正定；其含义仅是 bus/M3R/bridge/部署锁定 R2 双翼的等效组合。
- 两个安装 lane 各自从零位置、单位四元数、零总动量、零累计功独立启动。不得传递任何状态。ODR-01 lane 初始总质量/CG/惯量应闭合 V3_R2；物理几何 lane 保持同一残余体并只报告相对 V3_R2 的差异。
- M07 CSV 的每一行 q/qd/qdd 必须由首尾点和单段五次多项式独立复现到预注册容差。
- 自由漂浮 lane 必须通过动量、能量账、四元数归一、质量阵正定与输入闭合检查。
- 固定基座 ROM 必须独立复现发布的 leaf-only 3x3 Mqq、对角 K 及五个刚度组合频率。加入两个 0.03 kg 随动 inter-hinge 点质量所得 Mqq* 只用于冲突诊断；不得生成阻尼矩阵、参与因子或受迫响应，也不得进入自由漂浮 lane。
