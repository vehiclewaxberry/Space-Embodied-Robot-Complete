# CURRENT R2 数字主机 R4 增量结论

本轮完成了 R4 收敛判定代码与安全测试闭环，但没有执行新的时域 Run4；预执行门按单位合同和输出隔离要求 fail-closed。因此最高合法状态为 `R4_REPEAT_REQUIRED`。

对航天器—B601 自由漂浮机械臂场景，目前可得出的工程结论是：

- S02 case1 的无外力矩刚体守恒轨迹在三个细化步长下进入数值底板；Run3 的失败来自旧判据在底板内继续拟合阶数。R4 生产 helper 已修正该语义。case2/case3 只有单一步长，现被 fail-closed 判为证据不足，因此没有整个 S02 套件的 PASS。
- S03 的 `dt=1e-3` 饱和与大漂移在 `dt=5e-4` 下消失，joint6 峰值从 `7.0 N·m` 降到 `7.67e-05 N·m`，跟踪误差从 `5.26e-2 rad` 降到 `3.15e-7 rad`。证据强烈指向离散数值失稳，而非真实持续执行器能力不足。
- 上述结论仍是刚体、无接触、无重力、PREBIND 诊断；没有目标接触、柔性、执行器动态、时延、传感噪声或正式控制放行。
- legacy `0.117` 不是相对角动量漂移，也没有单一单位；它混合了角动量和线动量。S02 的相对六维范数同样依赖单位缩放。后续必须拆账后才能把守恒量用作科学硬 Gate。

唯一建议动作是 R5 单变量修复：拆分角/线动量指标并实现版本化运行包，然后原样复跑 S02/S03。不要在此之前进入真实接触抓取、NMPC/RL 或父级 Release。
