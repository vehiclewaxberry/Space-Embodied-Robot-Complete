# 数据划分策略（预注册）

## D0（本增量）

**不划分。** D0 是确定性回归集（CI 语义）：每次数字主机更新必须全量重跑并逐位比对
（浮点通道按预注册容差）。任何"训练/验证/测试"划分对 D0 无意义且禁止。

## D1（同状态配对策略集，未生成——预注册规则）

- 划分键 = `base_state_id`（**整组同进同出**：同一初始状态的六策略 episode 永不跨 split，
  防止同状态泄漏）。
- 建议比例 70/15/15（train/val/test），按 `base_state_id` 哈希取模分配（种子固定、可复现）。
- 锚点状态（sim_10/sim_12 复现点：22kg@0.5dps、150kg@3dps）**强制进 test**，
  作为不可训练的物理对拍锚。
- `ABORT` 与 `NOT_EVALUATED` episode 保留在各自 split 内，不得为平衡而移动。

## D2/D3（阻塞中）

划分策略随参数区间来源 / 相机权威一起预注册，本文件届时增补版本号（不改写本节历史）。

## 泄漏防护通则

- 同一 `plant_sha256` + 同一 IC 的重复 episode 视为同组。
- 任何 split 重排 = 新 `DATASET_MANIFEST.json` 版本 + 全量哈希重算，旧 manifest 不删除。
