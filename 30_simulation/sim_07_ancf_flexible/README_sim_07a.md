## 1. 场景与激励接口

- 场景：`target_debris_v0` @ 3°/s（轴 [1,0.15,0.4]/‖·‖），残余接近速度 v_app = 0.01 m/s
  （sim_04/sim_06 标称工况）。
- 激励来自**已验证**的捕获求解器 `30_simulation/common/capture_impulse.py`（Gate A 通过），两种捕获理想化：
  - **6DOF 刚性锁定**：`capture_post_state(...)["impulses"][0]` → 基座速度跃变 (Δv_B, Δω_B)；
  - **3DOF 点式捕获**（理想球铰，只传力不传力偶）：`rigidize_point_contact(bodies, r_g)`。
- 帆板：+Y_S 侧一块，根部 frame F 在 S 系 [−0.05675, +0.11315, 0] m；chaser stack 质心
  由 `chaser_stack()` 取（S 系 x ≈ 0.0278 m）。S→惯性系映射 R_flip = diag(−1,−1,1)
  （`build_capture_scenario` 约定）。
- 根部材料点速度跃变 Δv_F = Δv_B + Δω_B × (r_F − r_com,chaser)。**基座固连系**中的初始条件：
  e(0) = 直板，初速度场 v0(y) = −[Δv_F + Δω_B × (y·ŷ_F)]，y ∈ [0, L]（根部节点被夹持，DOF 置零）。

## 2. 模型假设（阶段 A）

| # | 假设 | 说明 / 量级 |
|---|------|-------------|
| A1 | **单向耦合**：基座运动规定，不接收柔性反馈 | 板质量 0.348 kg ≪ stack 26.5 kg（1.3%），反馈为二阶小量；阶段 B 取消此假设 |
| A2 | **平面化**：ANCF 梁在 (y,z) 平面弯曲；梁轴 = +Y_F，横向 = +Z_S（板法线，弯曲主方向） | 取 Δv_F、Δω_B×r 的 Z_S 分量作横向激励 |
| A2a | **轴向准刚性**：初速度场丢弃 Y_F（轴向）分量，只保留横向 | EA≈2968 N → 轴向一阶模态 ≈52 Hz、响应幅值 ~6e-5 m，Rayleigh 阻尼几拍内耗散，对所有弯曲指标无贡献；若保留会迫使积分器全程解析该快振荡。轴向 DOF 本身保留在模型中（膜-弯几何耦合完整）。被丢弃的轴向初速：6DOF −4.55 mm/s、3DOF +2.21 mm/s（§4） |
| A3 | **忽略 X_S（面内/弦向）分量** | 板弦向刚度（b=0.227 m 板面内）≫ 弯曲刚度。被忽略的面内初速见 §4 表（6DOF 根部 13.6 mm/s、3DOF 根部 16.5 mm/s）——3DOF 工况的主激励正是被忽略的面内分量，故其面外响应数值只作下界/指示性结论 |
| A4 | **捕获后基座匀速+匀角速运动的惯性力忽略**（跃变后不再施加基座加速度） | 离心项与科氏项量级见 §6 |
| A5 | 阻尼：常 Rayleigh 阵 C = αM + βK_t，ζ = 0.01 在 f₁ 与 5f₁ 两点精确匹配（每个 EI 工况各自匹配） | α = 2ζω₁ω₂/(ω₁+ω₂)，β = 2ζ/(ω₁+ω₂)；K_t 为直板切线刚度（常阵） |
| A6 | EA 随 EI/EI_nom 缩放（等效截面不变 → E 等比） | 与 benchmark 的等效截面构造一致；轴向模态 ≫ 50 Hz，对指标无影响 |
| A7 | 根部瞬时夹持（跃变瞬间根部即随基座） | 标准初条件激励问题；根部弯矩 M_root = EI·d²z/dy²|₀（小挠度曲率近似） |

单元与参数：8 单元平面梯度缺失 ANCF 梁（Berzeri–Shabana），L = 0.200 m、μ = 1.7419665 kg/m、
EI ∈ {4.3630e-3, 8.9042e-3, 1.5047e-2} N·m²（f₁ = 0.7/1.0/1.3 Hz 包络，SSOT
`20_engineering/config/geometry/flexible_appendage_v1.yaml`）。t = 0..15 s，1500 采样点。

**积分器选择（刚性说明）**：Rayleigh 的 βK 项对离散化最高模态（~3.5 kHz，非物理网格模态）
给出过阻尼特征值 λ ≈ −βω² ≈ −2.6×10⁵ 1/s，任何显式方法（含 DOP853）被稳定性极限压到
dt ≈ 2×10⁻⁵ s（实测 6 案例 × 20 s 需数小时，且与是否激励该模态无关）。故**有阻尼扫描用
隐式 Radau（rtol 1e-6，提供常切线 Jacobian）**，并以回归 R3 与 DOP853（rtol 1e-8）
在 2 s 阻尼窗口交叉验证（tip 轨迹最大相对偏差 2×10⁻¹⁰ ≪ 1e-3 门限）；无阻尼能量守恒
回归 R1 仍用 DOP853（rtol 1e-10）。atol = 1e-10。

## 4. 3DOF vs 6DOF 激励差异

| 量 | 6DOF 刚性锁定 | 3DOF 点捕获 |
|---|---|---|
| \|Δv_B\| (m/s) | 0.01277 | 0.01136 |
| \|Δω_B\| (rad/s) | 0.05347 | 0.04674 |
| Δω_B 分量 (rad/s) | [0.0455, 0.0022, 0.0280] | [−0.00007, −0.0028, 0.0467] |
| 横向初速 根部→翼尖 (mm/s) | 7.89 → 16.99 | −0.14 → −0.16 |
| 被丢弃轴向初速 (mm/s) | −4.55 | +2.21 |
| 被忽略面内初速 根部→翼尖 (mm/s) | 13.57 → 19.17 | 16.51 → 25.84 |
| 捕获耗散 ΔT (J) | 5.274e-3 | 3.426e-3 |

**一句话结论**：两种捕获的 |Δω_B| 相近（0.047 vs 0.053 rad/s），但方向完全不同——6DOF 刚性
锁定通过力偶把 ~0.046 rad/s 转入 X 轴（板弯曲方向），而 3DOF 点捕获（球铰不传力偶）的 Δω
几乎纯绕 Z 轴（板面内方向），故点捕获的面外横向激励与响应比刚性锁定小约两个数量级
（tip 0.04 vs 3.7 mm @nominal）。注意：3DOF 工况的主激励恰好落在被平面化忽略的面内方向
（16.5 mm/s），其面外数值只作下界/指示性结论（A3）。

## 5. 能量一致性检查

- 6DOF：U_max ≈ 2.34e-5 J = **0.44% × ΔT**（5.27e-3 J）✓ 量级一致（远低于上界）。
- 3DOF：U_max ≈ 2.9e-9 J ≪ ΔT（3.43e-3 J）✓。
- **单向模型能量可超出 ΔT 上界的原因（声明）**：规定基座运动 = 基座是无限能量源/汇，板吸收
  的能量由运动学决定（= ½∫μ v0² dy，本工况 6DOF ≈ 2.4e-5 J），与 ΔT 无守恒关系；ΔT 只是
  双向耦合真实系统中柔性模态能量摄入的上界。本工况板质量占比 1.3%，运动学能量恰好远小于
  ΔT，故检查通过，但该不等式不是单向模型的结构性保证——阶段 B 双向模型中才严格成立。
  图 `root_moment_and_energy.png` 中 ΔT 横线即此一致性检查。

## 6. 被忽略项的量级声明（假设 A4）

对捕获后基座残余旋转 ω_post（6DOF: |ω⁺|=0.0535 rad/s 绕组合质心；3DOF: 0.0467 rad/s 绕
chaser 质心）精确计算离心加速度场 ω×(ω×r) 的横向（Z_S）分量，用悬臂梁静挠度公式折算
（均布+三角载荷解析式）：

| 案例 | 离心准静态翼尖挠度 (m) | 占动态峰值 | 科氏比 2\|ω\|/ω₁ |
|---|---|---|---|
| 6DOF / low, nom, high | 1.8e-5, 8.9e-6, 5.3e-6 | 0.35%, 0.24%, 0.19% | 2.4%, 1.7%, 1.3% |
| 3DOF / low, nom, high | 2.7e-6, 1.3e-6, 7.7e-7 | 4.7%, 3.3%, 2.5% | 2.1%, 1.5%, 1.1% |

声明：**6DOF 各案例被忽略项 <2.5%，3DOF <5%**（3DOF 因动态响应本身极小、相对占比抬高）。
频率牵引效应 (\|ω\|/ω₁)² < 1.5e-4，可忽略。
