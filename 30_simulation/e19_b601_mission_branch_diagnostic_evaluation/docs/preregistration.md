# e19 预注册：四支路隔离诊断

## 唯一问题

在不新增物理权威、不修改 accepted URDF、且不串联任务状态的前提下，e18 的四类非发布输入能否由现有数值算法独立消费并形成可复现、守恒闭合、单位明确的诊断输出？

## 预注册判据

1. M01 与 M07 arm-only 轨迹逐点复现五次解析式、端点连续、限位与 provisional 速加速度边界，并在显式 REORG 路径适配后的 sim_05 刚性自由漂浮模型中满足总动量残差不超过 `1e-12`。
2. M05 Sim13 分支完成 1000 步常角速运动学，四元数范数与解析解误差均不超过 `1e-12`；静态分支的旋转矩阵为右手正交阵，抓取点和质心变换残差不超过 `1e-12 m`。
3. M06 的 20 个唯一网格案例满足半正弦端点、峰值、`Fpeak*Tc/J=pi/2` 与数值积分相对误差小于 `1e-8`。
4. M07 Sim15 当前代码重算的基线文件哈希必须与已绑定基线一致；四个 22 kg 案例的线、角动量残差小于 `1e-11`，刚塑过程不增能，组合惯量对称正定。
5. 所有释放、公共历元/帧、物理接触、锁定、锁定变换、发布质量属性、附着目标恢复和生产字段保持 `null/HOLD/false`；四支路不发生状态传递。

诊断判据全过时，`diagnostic_execution_verdict` 可以为 `PASS`，但总 Gate 必须保持 `HOLD`、`released_segments=0`、`next_stage_authorized=false`。
