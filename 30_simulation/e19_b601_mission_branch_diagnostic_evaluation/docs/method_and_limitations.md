# 方法与限制

## REORG 路径适配

历史 sim_05 的算法源码仍使用迁移前的根级 `cad/` 与 `docs/` 默认路径。e19 不修改该模块，而是在构造模型时把依赖显式注入到现行的 `20_engineering/cad/.../arm_b601_v1.urdf` 与 `20_engineering/stage1_spacecraft_layout/.../mass_inertia_budget_v1.csv`。输入、算法与适配器均进入哈希链。该做法仅恢复命名空间，不升级历史科学结论或质量属性权威。

sim_05 是刚性、无外力、规定关节轨迹的自由漂浮诊断模型；它不含柔性帆板、执行器、线束、碰撞、HDRM、释放冲击、接触或控制闭环。M01/M07 的基座反作用数值因此只能用于暴露设计风险和决定后续高保真建模优先级。

## 分支语义

- M05 Sim13 是常角速运动学。后端字段 `collision_detected=false` 不等于碰撞安全；ABORT 动作用于保证未执行抓取策略。
- M05 static 只做坐标代数，`capture_time_s=0` 不是任务历元。
- M06 的 `N` 是标量求解器波形幅值单位；缺少六维冲量、接触点、法向与材料参数，禁止接入物理接触求解器或解释为硬件载荷。
- Sim15 是瞬时理想刚塑捕获代数，输出冲量而非力；接触持续时间、力和压力保持空值。
- M07 arm-only 与 Sim15 捕获分支并不连接。没有 `T_gripper_target_locked`、选定质量惯量分支和恢复终端合同，故不传播附着目标。

## 不确定度

本轮输入是哈希绑定的诊断数值，不是测量。缺失的标准不确定度保留为 `null`，不得写成 0，也不得把两个模型分支的差异冒充测量不确定度。
